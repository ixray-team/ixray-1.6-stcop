# ExtendedEntityesLogic

Единая область расширенной логики мутантов. Здесь находятся подключение к движку, компоненты, общие службы и реализации категорий.

Текущие файлы:

- `EntryPoint.h/.cpp` — единственные внешние вызовы модуля; кадр, события, очистка; [MAIN/ENTITY].
- `CELBaseAdapter.h/.cpp` — реализует IELAdapter; общая база адаптеров владельца; [ENTITY].
- `CELSharedPerceptionBudget.h/.cpp` — реализует IELBudget; общая служба; [ENTITY].
- `CELSharedSettings.h/.cpp` — общие неизменяемые настройки, профили и версия режима; [INIT/READ].

Статус: перенос в процессе, сборку выполняет пользователь. Готовность и оставшиеся механики: [архитектура](../../../../doc/extended-entityes-architecture.md).

Игровые обновления и события подключаются через EntryPoint.h; регистраторы команд и игровых типов подключаются напрямую. Обработчики проверяют аргументы и режимы внутри модуля; снаружи остаются события и краткий возврат при обработке. Регистрация команд — прямой CELSharedDebugCommands::Register до загрузки user.ltx, без связи рендера с игровой DLL. В EntryPoint не добавлять условные прослойки ради объединения регистраторов. Подробная карта внешних точек — в архитектуре. Новые параметры LTX сопровождать русскими комментариями и одновременно обновлять реальные секции и empty_example.ltx.
