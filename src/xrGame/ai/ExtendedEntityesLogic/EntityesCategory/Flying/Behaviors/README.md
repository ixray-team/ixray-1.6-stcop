# EntityesCategory/Flying/Behaviors

Общие приёмы воздушных схем и менеджер переходов. Проверяет выполнение, ожидание расчётов и отсутствие прогресса через единый контракт поведения.

Текущие файлы:

- `CELFlyingBehaviorBase.h/.cpp` — реализует IELBehavior; [ENTITY].

Статус: перенос в процессе, сборку выполняет пользователь. Готовность и оставшиеся механики: [архитектура](../../../../../../../doc/extended-entityes-architecture.md).

`CELFlyingBehaviorManager` выбирает крейсерский курс, реакцию на шум или переданную дочерним компонентом схему; только он хранит активную воздушную схему и передаёт ей FrameUpdate. `CELFlyingCruiseBehavior` общий для категорийных подгрупп, поэтому расположен здесь. Общий lifecycle повторно использует `CELSharedBehaviorManager`, алгоритмы категорий не копируются.
