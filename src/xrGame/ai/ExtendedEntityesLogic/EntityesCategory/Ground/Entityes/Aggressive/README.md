# EntityesCategory/Ground/Entityes/Aggressive

Общая основа боевых наземных компонентов. Схемы боя и поиска отделены от реализации движения и доставки сведений.

Текущие файлы:

- `CELGroundAttackBase.h` — наследует CELGround; [ENTITY].

Статус: перенос в процессе, сборку выполняет пользователь. Готовность и оставшиеся механики: [архитектура](../../../../../../../../doc/extended-entityes-architecture.md).

В `Entityes/` находятся короткие CEL-компоненты по видам; `Psi/` содержит пси-виды. Они наследуют `CELGroundAttackBase`, а не игровые vanilla-классы. Пока используются общие схемы, конструктор наследуется в заголовке; пустой .cpp не нужен. Индивидуальное поведение добавляется в этот видовой компонент и остаётся внутри модуля. Общий ECS-компонент и ванильный final не изменяются.
