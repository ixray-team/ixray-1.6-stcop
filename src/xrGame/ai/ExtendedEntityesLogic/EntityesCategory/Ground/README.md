# EntityesCategory/Ground

Категория наземных компонентов расширения. Использует штатных монстров через адаптеры; общие память и сарафан остаются в корневых службах.

Текущие файлы:

- `CELGround.h/.cpp` — наследует CELComponentBase; [ENTITY].
- `CELGroundAdapter.h` — наследует CELBaseAdapter; наземные возможности; [ENTITY].
- `CELGroundMovement.h/.cpp` — реализует IELMovement; [ENTITY].

Статус: перенос в процессе, сборку выполняет пользователь. Готовность и оставшиеся механики: [архитектура](../../../../../../doc/extended-entityes-architecture.md).

CanPursue в CELGroundAdapter проверяет потенциальную высотную досягаемость летуна, не меняя отношения или личную память. Учитываются габариты, местная опора графа и штатные melee/jump-настройки. Общий выбор и native EnemyMemory исключают недосягаемую воздушную цель; после снижения она снова доступна. CELGroundAttackBase передаёт допустимую атаку/прыжок штатной FSM. Физическое попадание, геометрия прыжка и особые дальние атаки остаются ответственностью соответствующего исполнителя; высотный фильтр их не заменяет.
