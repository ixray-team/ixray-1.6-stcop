# Navigation

Общая инфраструктура расчётов маршрутов для всех категорий. Исполнение движения принадлежит самим сущностям и их IELMovement.

Текущие файлы:

- `CELNavigationBase.h/.cpp` — реализует IELNavigation; общий запрос/отмена/прогресс; [REQUEST/WORKER].
- `CELSharedNavigationBudget.h/.cpp` — реализует IELBudget; общий лимит расчётов; [WORKER].
- `CELSharedNavigationScheduler.h/.cpp` — очереди, квоты и порционное выполнение; [WORKER].

Статус: перенос в процессе, сборку выполняет пользователь. Готовность и оставшиеся механики: [архитектура](../../../doc/extended-entityes-architecture.md).

CPU-поиск по снимку использует heap открытых узлов, включая учёт устаревших элементов в бюджете. Вместимость очередей и снимков ограничивается общими настройками; Ground и Flying не создают отдельных копий общего мира. Нативный наземный исполнитель получает готовые соседние точки, не запускает второй полный поиск до далёкой цели одновременно со снимком.
