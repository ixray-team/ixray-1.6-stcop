# EntityesCategory/Ground/Entityes/Aggressive/Entityes/Psi

Пси-группа наземных боевых компонентов. Использует общие службы памяти, доставки сообщений и бюджеты. Передача через препятствия и живое слежение задаются независимо профилем вида.

Специальные реализации этой области пока не перенесены; пустые C++-обёртки не создаются.

Статус: перенос в процессе, сборку выполняет пользователь. Готовность и оставшиеся механики: [архитектура](../../../../../../../../doc/extended-entityes-architecture.md).
