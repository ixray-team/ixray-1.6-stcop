# Perceptions

Переиспользуемые механизмы восприятия для Ground, Flying и будущих категорий. Это общие реализации через композицию, а не базовые классы для наследования категориями. Знания и сроки памяти остаются индивидуальными.

Текущие файлы:

- `CELSharedAnomalies.h/.cpp` — локальные наблюдения полей, снимки для worker и проверки пересечения.
- `CELSharedSight.h/.cpp` — общая проверка видимости и периферийное внимание без изменения backend.

- `CELSharedEnemySharing.h/.cpp` — общая доставка и ограничения обмена; [ENTITY].
- `CELSharedHearing.h/.cpp` — общая обработка звуков, используется через композицию; [ENTITY].
- `CELSharedMemory.h/.cpp` — общая реализация памяти без наследования; знания индивидуальны; [ENTITY].
- `CELSharedPerceptionProfiles.h/.cpp` — независимые правила передачи и слежения; [INIT/READ].
- `CELSharedSoundEvents.h/.cpp` — очередь игровых шумов и метаданные без xrSound-изменений; [MAIN/ENTITY].
- `CELSharedTargets.h/.cpp` — общие операции с индивидуальными целями; композиция; [ENTITY].

Статус: перенос в процессе, сборку выполняет пользователь. Готовность и оставшиеся механики: [архитектура](../../../doc/extended-entityes-architecture.md).

Слух: `CELSharedPerceptionProfiles` читает списки `monster_noise_interest_types` и `monster_noise_fear_types` через запятую в две маски. `CELSharedHearing` одинаково классифицирует звуки для всех категорий, проверяет радиусы и накапливает внимание; сама смена поведения принадлежит менеджеру категории. Пустой список запрещает реакцию, пересечение разрешается в пользу испуга. Без списков остаются прежние флаги. Новые типы добавляются в общий перечень и документацию, без условий по конкретным монстрам и правок backend.

Свет: после проверки видимости фонарика событие `Light` передаёт только координаты источника в накопление интереса `CELSharedHearing`. Используются общие шаг, порог, спад, интервал, вероятность немедленной реакции, приоритет и задержка шумового интереса. Свет не зависит от радиуса слуха и списков звуков, не вызывает испуг и не записывает владельца в память врагов. Подтверждение противника, след и последняя видимая позиция остаются в штатном зрительном пути расширения. При выключенном расширении сохраняется ванильная реакция на фонарик.

Отладка света: `monster_debug_3d_shapes` показывает жёлтую отметку точки источника; `monster_debug_3d_text` показывает «СВЕТ», текущий интерес и порог либо исследование точки. Идентификатор игрока в событие не передаётся; отметка света не является отметкой обнаруженного врага.
