# Справка по новым свойствам артефактов

## Область применения

Документ описывает новые свойства артефактов и их работу в рантайме.
Все эффекты берутся только с артефактов на поясе и масштабируются от состояния артефакта.

Формула масштабирования от состояния:

value_effective = value_config x artifact_condition

artifact_condition в диапазоне от 0.0 до 1.0.

## Список свойств

1. jump_height_modifier
2. movement_speed_modifier
3. sleepiness_restore_speed
4. equipment_durability_modifier
5. inventory_weight_modifier

## 1. jump_height_modifier

Назначение:
Меняет силу прыжка актора.

Формула:

jump_final = jump_base x (1.0 + sum_modifier_condition_scaled)

Где:
sum_modifier_condition_scaled это сумма всех артефактов на поясе с учетом condition.

Пределы:

jump_final ограничивается минимумом 0.0.

Нейтральное значение:

0.0

Примеры:

0.25 дает примерно плюс 25 процентов к компоненте скорости прыжка.
0.0 не дает изменений.
Отрицательные значения уменьшают прыжок.

## 2. movement_speed_modifier

Назначение:
Меняет базовое ускорение движения актора для цепочки ходьба бег спринт.

Формула:

walk_accel_final = walk_accel_base x (1.0 + sum_modifier_condition_scaled)

После этого применяются обычные множители бега, спринта, приседа и стрейфа.

Пределы:

walk_accel_final ограничивается минимумом 0.0.
Жесткого верхнего ограничения в этом пути нет.

Нейтральное значение:

0.0

Примеры:

0.20 дает примерно плюс 20 процентов к базовому ускорению.
Отрицательные значения уменьшают ускорение.

Защита от ложного урона на высокой скорости:

Если эффект movement_speed_modifier не равен нулю, включается дополнительный фильтр collision урона.
Фильтр убирает ложный урон от быстрого горизонтального движения.
Реальный урон от падения и сильного движения вниз сохраняется.
Дополнительно применяется короткое окно подавления повторных микро ударов.

## 3. sleepiness_restore_speed

Назначение:
Меняет параметр сна со временем.

Формула на тик:

delta_sleepiness = sleepiness_restore_speed x artifact_condition x dt

Применяется только если включена опция движка EnableSleepiness.

Тиковая модель:

Обновление эффектов артефактов выполняется в периодическом цикле актера с базовым шагом около 0.1 секунды.

Пределы:

Сам параметр сна в системе состояний актора ограничен диапазоном 0.0 до 1.0.

Нейтральное значение:

0.0

Примеры:

Положительное значение увеличивает параметр сна.
Отрицательное значение уменьшает параметр сна.

## 4. equipment_durability_modifier

Назначение:
Меняет скорость износа экипировки от входящих попаданий.

Агрегация на актере:

modifier_actor = 1.0 + sum((value_config - 1.0) x artifact_condition)

Затем:

modifier_actor ограничивается диапазоном 0.0 до 10.0.

Применение в логике брони:

hit_power_after_immunity = hit_power_after_immunity x modifier_actor
condition_change = -hit_power_after_immunity

Важное поведение:

Это свойство никогда не чинит экипировку.
Оно только масштабирует скорость износа.

Нейтральное значение:

1.0

Примеры:

0.75 это медленнее износ примерно на 25 процентов.
1.0 это без изменений.
1.30 это быстрее износ примерно на 30 процентов.

## 5. inventory_weight_modifier

Назначение:
Меняет вес предметов в инвентаре как процентный множитель.
Не меняет лимиты переносимого веса.

Агрегация на акторе:

modifier_actor = 1.0 + sum((value_config - 1.0) x artifact_condition)

Затем:

modifier_actor ограничивается диапазоном 0.0 до 10.0.

Применение:

item_weight_effective = item_weight_base x modifier_actor
total_weight = sum(item_weight_effective для всех предметов инвентаря)

Важное поведение:

Свойство влияет на вклад веса предметов.
Свойство не меняет логику additional_inventory_weight.
Лимиты веса остаются под управлением существующих систем max weight и additional weight.

Нейтральное значение:

1.0

Примеры:

0.75 превращает предмет с 4.0 кг в примерно 3.0 кг.
1.0 это без изменений.
1.20 увеличивает вес предметов примерно на 20 процентов.

## Рекомендуемые безопасные диапазоны

Это практические рекомендации, не жесткие лимиты движка.

1. jump_height_modifier от -0.30 до 0.50
2. movement_speed_modifier от -0.20 до 0.40
3. sleepiness_restore_speed малые значения в масштабе тика
4. equipment_durability_modifier от 0.70 до 1.50
5. inventory_weight_modifier от 0.70 до 1.30

Для полноценного использования необходимо:
1. Файлы локализации
2. По желанию уникальные иконки
