Build dependencies

The automatic downloader obtains OptiX 9.0.0 headers and CUDA 13.4.3 Windows
components directly from NVIDIA, with pinned SHA-256 checksums. Build tools,
SDK headers and dependency archives are not part of the application package.
Do not publish the build's _deps/nvidia directory as a standalone SDK package.
Explicitly supplied SDKs retain their own versions and accompanying licenses.
