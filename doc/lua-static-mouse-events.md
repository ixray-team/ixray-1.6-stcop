# События мыши в Lua UI

Основная документация: [Lua UI: окна, статики и события мыши](lua-ui-api.md#4-события-мыши).

На самом контроле доступна подписка без имени и `Register`:

```lua
control:AddSelfCallback(ui_events.MOUSE_LEFT_CLICK, function(control)
    log1("Static clicked")
end)
```

| Событие | Значение |
| --- | --- |
| `MOUSE_LEFT_CLICK` | Нажатие ЛКМ внутри контрола |
| `MOUSE_RIGHT_CLICK` | Нажатие ПКМ внутри контрола |
| `MOUSE_ENTER` | Вход курсора; алиас `WINDOW_FOCUS_RECEIVED` |
| `MOUSE_LEAVE` | Выход курсора; алиас `WINDOW_FOCUS_LOST` |
| `MOUSE_DRAG` | Движение внутри с зажатой ЛКМ или ПКМ |
| `MOUSE_MOVE` | Движение внутри, включая перетаскивание |
| `MOUSE_WHEEL_UP` | Прокрутка вверх |
| `MOUSE_WHEEL_DOWN` | Прокрутка вниз |
| `WINDOW_FOCUS_RECEIVED` | Вход курсора; то же значение, что `MOUSE_ENTER` |
| `WINDOW_FOCUS_LOST` | Выход курсора; то же значение, что `MOUSE_LEAVE` |
| `WINDOW_UPDATE` | Существующее обновление контрола; только для явной собственной подписки |

Все имена находятся в `ui_events`. Для `drag` нажатие может начаться вне контрола.
Второе нажатие двойного клика также даёт `MOUSE_LEFT_CLICK`.
Исходные имена `on_mouse_*` сохранены как алиасы для обратной совместимости.

Обработчик получает контрол-источник. Подписки освобождаются при уничтожении
контрола; отдельная отмена регистрации не требуется. Несколько обработчиков
одного события вызываются в порядке подписки.

Прежний `window:AddCallback(name, event, handler[, object])` остаётся доступным
и требует имени и `window:Register(control, name)`. Смешивать сигнатуры методов
не нужно: прямой метод называется `AddSelfCallback`.

`WINDOW_UPDATE` не добавляет тики и не регистрирует таймер. Без такой подписки
Lua-обработчик обновления не вызывается.

Клики и колесо требуют маршрутизации ввода в окно. `AddDialogToRender` не делает
окно получателем ввода; для интерактивного диалога используется `ShowDialog`.
Проверка наведения выполняется отдельно при обновлении, пока курсор виден.
Коллбеки не перемещают контрол и не захватывают мышь автоматически.

Подробности подписки, аргументов коллбеков, перекрытия контролов, совместимости
и текущего статуса проверки приведены в основной документации.
