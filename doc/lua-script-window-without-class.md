# Скриптовые окна без Lua-класса

Основная документация: [Lua UI: окна, статики и события мыши](lua-ui-api.md#2-окно-без-lua-класса).

```lua
local holder = GetCurrentDialogHolder()
assert(holder, "No active UI holder")

window = CreateScriptWindow()
window:SetWndPos(vector2():set(0, 0))
window:SetWndSize(vector2():set(300, 40))
window:SetStopAnyMove(false)
holder:AddDialogToRender(window)
```

Фабрика создаёт обычный C++ `CUIDialogWndEx`, доступный в Lua как `CUIScriptWnd`.
Она не добавляет окно в отрисовку автоматически: для этого отдельно вызывается
`holder:AddDialogToRender(window)` или `window:ShowDialog(false)`.
Не требуется объявлять `class` и вызывать `super()`. Пустое окно не имеет
собственного изображения: добавьте текст или текстуру через дочерний контрол.

`Register`, `GetStatic`, существующие коллбеки и новый
`AddCallback(name, event, function)` доступны без класса.
Для подписки непосредственно на окно используется
`window:AddSelfCallback(event, handler)` без имени и `Register`.
На существующее обновление можно подписаться через
`window:AddSelfCallback(ui_events.WINDOW_UPDATE, handler)`; отдельные тики
при этом не создаются. Без подписки Lua-обработчик обновления не вызывается.
Прежнее наследование от `CUIScriptWnd` сохранено для Lua-переопределений
виртуальных `Update`, `OnKeyboard`, `Dispatch` и других методов.
Фабрика использует для них реализацию C++.

`get_hud()` используется при доступном игровом HUD. В главном меню можно
использовать `GetCurrentDialogHolder()`. Отрисовка не означает захват ввода:
для интерактивного окна вместо `AddDialogToRender` используется `ShowDialog`.

Для удаления сначала вызовите `RemoveDialogToRender`, затем обнулите Lua-ссылку.
Добавлено автоматическое снятие регистраций при уничтожении окна и очистка
очередей HUD при уничтожении текущего актора, остановке уровня и выгрузке HUD.
Это работает независимо от выгрузки Lua, в том числе при `keep_lua`.
Живые Lua-окна скрываются и отключаются; глобальные ссылки не обнуляются.
Ручная очистка из `actor_on_net_destroy` остаётся совместимой и освобождает ссылки.

Полный пример окна с текстом, обновлением, коллбеками и выгрузкой
приведён в основной документации. Полный сценарий выгрузки с модом ещё требует
проверки в игре после пересборки всех использующих `CUIWindow` модулей.
