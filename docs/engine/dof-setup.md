# DOF setup

Единое окно настройки глубины резкости: общая камера, физические пресеты NDOF, привязки событий и классические параметры HUD, оружия и анимаций.

Открытие: **Game → DOF setup**, непосредственно в меню Game. Требуется сборка с `DEBUG_DRAW`. `Alt` переключает захват курсора; `Ctrl+Alt` скрывает или показывает панель ImGui. Окно можно закрепить в общей области редакторов. Настраивать конфиги можно без загруженного уровня; для предпросмотра нужен уровень.

## Как окно хранит изменения

Окно не правит исходные конфиги игры. Все изменения профилей, привязок событий и полей HUD/оружия записываются в один файл рядом с `system.ltx`: `configs\mod_system_zz_dof_setup.ltx`. Это обычный DLTX-мод: игра подхватывает его при запуске, его можно открыть в текстовом редакторе, перенести в другой мод или удалить, чтобы вернуться к значениям игры.

- Галочка слева от поля означает: значение задаёт этот файл. Без галочки показано значение игры (или общей камеры, если поля в профиле нет).
- Изменение поля ставит галочку само. Снятие галочки убирает поле из файла и возвращает значение игры. Если поле было сохранено в прошлом запуске игры, значение игры появится после **Save**; окно сообщает об этом.
- Изменение родительского профиля доходит до наследующих его профилей после **Save**.
- Параметры вкладки **General** — консольные команды: они действуют сразу, а **Save** записывает их в пользовательский конфиг штатным `cfg_save`.

## Порядок работы

1. На **General** проверьте главный переключатель и режим: `autofocus`, `manual` или `static`. Включение главного переключателя пересобирает шейдеры.
2. На **NDOF presets** выберите профиль или создайте новый. **Duplicate** создаёт независимую копию полей выбранного профиля. Имена новых секций: строчные латинские буквы, цифры, `_`, `-`, `.`; имя должно быть непустым и уникальным.
3. Настройте поля и нажмите **Preview profile**, чтобы принудительно увидеть выбранную физическую камеру на R4. Для static используйте **Preview static group** на вкладке HUD / Weapons. Превью обновляется при каждом изменении поля.
4. На **Events** назначьте профиль нужному событию. При необходимости добавьте локальную ссылку в HUD, предмет, прицел или конкретную анимацию.
5. **Stop preview** возвращает обычные игровые события.
6. **Save** записывает файл окна и пользовательский конфиг, перечитывает конфиги и применяет их к игре. До **Save** игра использует прежние значения профилей и оружия; затем проверьте настоящее событие: например, прицеливание или перезарядку.

Числовые поля поддерживают перетаскивание и точный ввод через `Ctrl+клик`; значение принимается сразу и ограничено допустимым диапазоном. Для static обязательно `near ≤ focus ≤ far`: если три значения группы стоят не по порядку, под ними появляется красное предупреждение, а игра использует для этой группы значения по умолчанию, пока порядок не исправлен. Вектор из четырёх значений с нарушенным порядком или отрицательным временем не принимается.

## Пример: свой пресет для перезарядки

Цель — создать физический пресет `ndof_my_reload`, назначить его событию `reload` и проверить на оружии. Пример рассчитан на R4 и загруженный уровень. Числа ниже — начальная точка для настройки под конкретную модель оружия и поле зрения.

### 1. Создать пресет

1. Откройте **General**, включите DOF и выберите общий режим `autofocus`.
2. Перейдите в **NDOF presets**, введите уникальное имя `ndof_my_reload` в поле имени нового профиля и нажмите **Create**. Новый профиль не наследует другие профили: поля, которых в нём нет, берутся из общей камеры. Чтобы начать с готового профиля, выберите его и нажмите **Duplicate**.
3. Задайте значения из таблицы.

| Поле | Значение | Назначение |
| --- | --- | --- |
| `enabled` | `true` | Разрешить профиль при обычном выборе событий |
| `ndof_mode` | `manual` | Удерживать заданную дистанцию фокуса |
| `focus_distance` | `0.675` м | Начальная дистанция до рук и оружия |
| `f_number` | `2.4` | Диафрагма; меньшее число усиливает размытие вне фокуса |
| `manual_focal_length` | `false` | Вычислять фокусное расстояние из поля зрения |
| `focus_time` | `0.5` с | Время изменения фокуса |
| `transition_time` | `0.5` с | Время перехода параметров профиля |

Остальные поля оставьте без галочки.

### 2. Добавить привязку к событию

**Events** содержит фиксированные 13 событий. Здесь можно добавить или заменить привязку пресета к существующему событию. Создать новый игровой триггер с произвольным именем через окно или добавлением строки LTX нельзя — это требует изменения движка.

1. Откройте **Events** и найдите `reload`.
2. Выберите `ndof_my_reload` в качестве профиля.
3. Через **Edit profile** можно вернуться к настройке выбранного пресета.

После **Save** файл окна содержит:

```ini
![ndof_events]
reload = ndof_my_reload

[ndof_my_reload]
enabled = true
f_number = 2.4
focus_distance = 0.675
focus_time = 0.5
manual_focal_length = false
ndof_mode = manual
transition_time = 0.5
```

Если эффект нужен только конкретному оружию, используйте **HUD / Weapons**, выберите его HUD или item-секцию и назначьте `ndof_profile_reload = ndof_my_reload`. Такая локальная привязка имеет приоритет над глобальной. Для отдельной анимации применяется ссылка на её точный alias, например `ndof_profile_anm_reload`, если оружие действительно использует `anm_reload`.

### 3. Проверить

1. В **NDOF presets** нажмите **Preview profile**. Проверьте резкость рук и размытие фона. Подстройте `focus_distance` и `f_number`. Превью подтверждает внешний вид камеры, но не правильность привязки к перезарядке и не её тайминги.
2. Нажмите **Stop preview**, затем **Save**. Убедитесь, что отметка принудительного превью исчезла.
3. Вернитесь к управлению игрой через `Alt`, выстрелите и запустите обычную перезарядку. В строке состояния ожидаются событие `reload` и профиль `ndof_my_reload`. После окончания действия камера должна вернуться к следующему подходящему событию или общей настройке.
4. Если выбран другой профиль, проверьте источник привязки в строке состояния. В **HUD / Weapons** проверьте локальные ссылки HUD/item и конкретной анимации. Если выбрано другое событие, устраните его условие: например, закройте инвентарь или PDA, завершите диалог, выйдите из DOF-зоны.
5. Если профиль выбран, но картинка не меняется, проверьте R4 и главный переключатель DOF. Общий режим должен быть `autofocus` или `manual`, чтобы работали физические события. Убедитесь, что значения подходят дистанции до оружия.
6. Перезапустите игру, загрузите уровень и повторите действие. Это подтверждает, что результат восстановился из файла.

## Кнопки

Верх окна показывает рендерер, действующий режим, выбранное игровое событие, профиль и источник привязки, а также есть ли несохранённые изменения. При принудительном предпросмотре появляется отдельная заметная надпись.

- **Save** записывает файл окна, сохраняет пользовательский конфиг, перечитывает конфиги с диска и применяет их. Текущие анимации не запускаются заново.
- **Reload from disk** отбрасывает всё, что изменено после последнего **Save** (в том числе параметры **General**), и перечитывает конфиги. При несохранённых изменениях запрашивается подтверждение.
- **Copy LTX** копирует текст файла окна в буфер обмена. **Copy profile LTX** копирует все значения выбранного профиля, **Copy section DOF LTX** — поля выбранной секции, заданные окном.

Превью использует тот же принудительный DOF, что и камера Cinema Editor: во время превью обычные события не выбираются, а при воспроизведении сцены Cinema с DOF превью нужно остановить. Изменение выбранного объекта или группы прекращает превью. Оно также прекращается при закрытии окна, скрытии панели ImGui, выгрузке уровня, выключении главного переключателя, **Save** и **Reload from disk**. Консольный режим DOF превью не меняет. Сворачивание окна не выключает предпросмотр.

## Вкладки

**General** содержит общий переключатель, режим, физическую камеру R4, разрешение bokeh и classic-настройки. Размер размытия один: `r2_dof_kernel` задаёт static-размытие, а наибольший радиус bokeh физической камеры равен четырём его значениям (от 1 до 40 пикселей). Высота сенсора фиксирована (24 мм), общая точка автофокуса — центр экрана; точку можно задать только в профиле события (`focus_point`). Дистанции указаны в метрах, фокусное расстояние — в миллиметрах, времена — в секундах. Скорости static-переходов — в обратных секундах; ноль удерживает текущее значение. Физические параметры действуют в R4 autofocus/manual, classic-параметры — в static и поддерживающих их старых рендерах. Активный профиль события может переопределять поля общей камеры.

**NDOF presets** позволяет искать, создавать и дублировать профили. Профилем считается секция, имя которой начинается с `ndof_`, секция с полями физической камеры, секция, на которую ссылается событие, и секция, созданная окном. Наследование существующих профилей (например, `[ndof_inventory]:ndof_hands_events`) работает как прежде, но родителей окно не меняет: это делается в тексте конфигов.

Физический профиль содержит `enabled`, режим, f-number, выбор ручного фокусного расстояния, его значение, дистанцию фокуса, экранную точку autofocus и времена переходов. Ручное фокусное расстояние используется только при включённом соответствующем флажке; иначе оно вычисляется из поля зрения. Экранная точка используется autofocus; ручная дистанция также служит начальным запасным значением при отсутствии подходящей глубины.

**Events** показывает все 13 физических событий в установленном игровом порядке: talk; zone и pickable; inventory; pda и hud_animator; reload и weapon_action; варианты aim; effector. Приоритеты в окне не переставляются. Выигрывает первое подходящее включённое событие. `enabled = false` подавляет привязки того же события, но позволяет сработать другим событиям с меньшим приоритетом. Предпросмотр принудительно показывает камеру выбранного профиля, независимо от его `enabled`; обычные события продолжают учитывать этот флаг.

**HUD / Weapons** содержит поиск по всем секциям конфигов и быстрые переходы к предмету в руках, его HUD, установленному прицелу и HUD-аниматору. Раздел физических ссылок позволяет назначить профиль событию или анимационному alias `anm_*`. Локальные ссылки HUD/item имеют приоритет над глобальной таблицей, а профиль конкретной анимации — над ссылкой события. Для линзы учитывается ссылка прицела. **Edit profile** переходит к выбранному пресету.

Группы static объединяют обычное, альтернативное и подствольное прицеливание, линзу, PDA, настройки анимации и legacy-поля. Кнопки **Global defaults** и **Zone offsets** открывают глобальные секции; группа Inventory defaults также относится к глобальным настройкам. **Copy group / Paste group** копируют значения и имена ключей между секциями. Это перенос выбранной группы, а не перевод между разными группами или alias.

Для анимации положительный offset отсчитывается от её начала, отрицательный — назад от конца, ноль оставляет DOF на всю длительность. Legacy-вектор из четырёх значений принимает неотрицательное время освобождения. Static-превью удерживает выбранную камеру сразу, без плавного входа, и не воспроизводит анимацию или её таймер освобождения; проверять тайминги нужно настоящим действием после **Save**.

## Ограничения

- Изменяется только активная конфигурация игры; другие пакеты `gamedata_*` не синхронизируются.
- Файл окна загружается последним среди `mod_system_*.ltx` с именами до `zz`; мод с более поздним по алфавиту именем может перекрыть его значения.
- Окно показывает итоговое значение поля, но не файл и строку, откуда оно пришло, и не различает собственное значение секции и унаследованное от родителя.
- Удалить ключ из исходной секции игры (чтобы она унаследовала значение родителя) окно не может; это делается в тексте конфигов.
- Если папка конфигов недоступна для записи, **Save** сообщает об ошибке; используйте **Copy LTX**.
- Физическое превью доступно только на R4; static-превью имеет смысл на рендерерах с classic DOF. Превью недоступно при выключенном главном переключателе.
- Окно показывает выбранную целевую камеру, а не измеренную на GPU дистанцию фокусировки. Сглаживание фокуса и линзы продолжает работать. Существующие ограничения bokeh, маски линзы, видимости HUD и смешивания глубин описаны в [rendering.md](rendering.md#r4-bokeh-depth-of-field).

## Проверка после сборки

Проверять в Debug на загруженном уровне. Компиляция сама по себе не подтверждает изображение.

1. Открыть Game → DOF setup, проверить docking, Alt, Ctrl+Alt, закрытие и работу без уровня. Список профилей содержит все секции `ndof_*`; значения полей совпадают с `configs/misc/ndof.ltx`.
2. **General**: менять autofocus/manual/static, half/quarter и числа — действует сразу, без кнопок; `r2_dof` с near больше focus не принимается. Включить главный переключатель: шейдеры пересобираются, превью становится доступным.
3. Изменить `f_number` у `ndof_neutral` перетаскиванием и точным вводом: галочка ставится сама, строка состояния показывает несохранённые изменения. Снять галочку: значение игры возвращается сразу.
4. **Create** `ndof_my_reload`, **Duplicate** в `ndof_my_reload2`: оба в списке, у копии те же поля. Повторное имя и имя с заглавной буквой или пробелом отклоняются с сообщением.
5. **Preview profile**: надпись превью, картинка меняется при перетаскивании `focus_distance` и `f_number`; `r4_ndof_mode` в консоли не меняется. **Preview static group** при режиме `autofocus`: виден static DOF группы; после **Stop preview** режим и картинка прежние. Проверить остановку при смене объекта, закрытии окна, скрытии панели, выгрузке уровня.
6. В группе Normal aim поставить near больше focus: красное предупреждение, превью показывает значения по умолчанию; исправить — предупреждение исчезает.
7. **Save**: появляется `configs\mod_system_zz_dof_setup.ltx` с `![ndof_neutral]`, `[ndof_my_reload]` и изменёнными ключами; статус сообщает путь. Назначить `reload = ndof_my_reload` в **Events**, **Save**, перезарядить оружие: строка состояния показывает событие `reload` и профиль. Анимация при **Save** не начинается заново, DOF освобождается после неё.
8. Изменить `f_number` у `ndof_neutral`, **Save**: профиль, который его наследует и не задаёт своё значение (например, `ndof_talk`), показывает новое число.
9. Перезапустить игру: значения и привязки на месте, галочки стоят у сохранённых полей. Снять галочку у сохранённого поля: сообщение о значении после **Save**; после **Save** поле показывает значение игры и исчезло из файла.
10. Изменить поле и параметр **General**, **Reload from disk**: запрос подтверждения, оба значения возвращаются. **Copy LTX** даёт тот же текст, что был бы записан.
11. Удалить файл окна и перезапустить игру: значения игры, галочек нет.
12. На R1/R2 проверить доступные classic-настройки и отсутствие физического превью. Проверить сохранение при кириллице в пути папки игры.

## Совместная проверка с Cinema Editor

Воспроизвести сцену Cinema с DOF (classic и physical lens) при открытом окне DOF setup без превью: DOF сцены работает, после остановки сцены возвращаются обычные параметры. Включить превью и затем воспроизвести сцену: DOF задаёт тот, кто выставил его последним в кадре; остановить превью, остановить сцену — обычные параметры вернулись.
