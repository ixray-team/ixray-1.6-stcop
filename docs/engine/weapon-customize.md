# Weapon Customize

Откройте настройку оружия из его контекстного меню в инвентаре. Потяните за область модели, чтобы повернуть её, и нажмите на значок слота, чтобы посмотреть совместимые детали. Для установленной детали доступна команда **Detach**.

Слоты задаются параметром `customize_bones` в ltx-секции предмета. Списки совместимых деталей задаются ключами с именами костей, а расположение слотов берётся из модели. Конфиги `attachments/<секция>.json` могут задавать смещение и поворот установленных деталей. Доступность деталей определяется инвентарём персонажа. Режим бессмертия позволяет установить деталь, которой нет в инвентаре. В предпросмотре отображается до 64 моделей.

## Проверка после сборки

- На загруженном уровне открыть окно для оружия с настроенными слотами, повернуть модель и проверить расположение значков.
- Из меню слота установить и снять деталь, проверить обновление модели и инвентаря. Повторить со вложенной деталью, у которой есть собственный слот.
- Проверить, что отсутствующая в инвентаре деталь недоступна при выключенном режиме бессмертия.
