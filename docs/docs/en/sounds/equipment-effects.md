# Equipment sound effects
> [!IMPORTANT]
> **Status**: Supported <br>
> **Minimal version**: 1.3

## D_CUSTOM_DEVICE (flashlight, compass, detectors, etc.)

Added support for new device sounds:

```ini
sound_activate = device\torch_click   ; sound on activation
sound_deactivate = device\torch_click ; sound on deactivation
snd_click = device\torch_click        ; toggle sound 
snd_draw = device\torch_click         ; equip sound
snd_holster = device\torch_click      ; holster sound
```
