# Base namespace
## Overview

> [!IMPORTANT]
> **Status**: Supported <br>
> **Minimal version**: 1.0

Extension of stock Lua functionality by using third-party libraries **not related to the X-Ray Engine API**.

## LuaJIT

* [ffi](https://luajit.org/ext_ffi_semantics.html)
* jit
* [bit](https://docs.gamesense.gs/docs/api/bit/)
