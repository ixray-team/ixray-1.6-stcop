# Adjusting Model Clipping
## Renderable

> [!IMPORTANT]
> **Status**: Supported <br>
> **Minimum Version**: 1.1

Added the ability to set a value for geometry clipping by SSA **(optional)**. Use this if the object starts to partially disappear.

```ini
ssa_dyn_factor = 0.001
ssa_d_cam      = 300.0
```
