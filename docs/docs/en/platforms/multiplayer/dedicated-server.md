# Dedicated server
> [!IMPORTANT]  
> **Status**: Supported <br>
> **Minimal version**: 1.3

## Dedicated Server
> Dedicated Server runs game modes other than Single Player.

![image](https://github.com/user-attachments/assets/4719f23f-6d64-4096-ab2e-f47d81bd26a5)

## Key changes 
* Split out of xrEngine
* Moved to `xrRender_DS0` (no GPU needed for server)
* Added FreeMP mode
* Switched from `dplay8` to `SteamNetworking`

## FreeMP
> FreeMP is a mode with A-Life support.

### Implemented
* Mutants 
* Gear repair
* Personal stash boxes
* Trading
* Voice chat
