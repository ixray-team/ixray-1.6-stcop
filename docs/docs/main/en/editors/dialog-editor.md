# Dialog Editor

> [!IMPORTANT]  
> **Status**: Supported <br>
> **Minimal version**: IX-Ray Platform 1.3

![image](https://github.com/user-attachments/assets/9be6acb7-7dd9-4445-93d9-215a502bdeac)

## Overview

Dialog Editor is implemented with a node system.  
To open it, go to `configs/gameplay/` in the **Content Browser** and open a dialog file:

![image](https://github.com/user-attachments/assets/66aa365f-9441-4ec5-b158-f77a912c7d4a)

> The editor reads `system.ltx` to get the list of supported files.

With no node selected, the `Properties` window shows global properties of the current dialog.

![image](https://github.com/user-attachments/assets/9456fd2d-7d87-4f33-877a-6492f4cb9d51)
