# IXR Framework components

> [!IMPORTANT]
> **Status**: Supported<br>
> **Minimum version**: IX-Ray Platform 1.4.0

## Overview

Components are available as Lua scripts independently of IXR Framework module initialization.

| Directory | Scripts |
| --- | --- |
| `gamedata/scripts/ixr_framework/public_components/` | `ixr_logs.script`, `ixr_tracy_profiler.script` |
| `gamedata/scripts/ixr_framework/system_components/` | `ixr_callback_binder.script`, `ixr_npc_info.script` |
