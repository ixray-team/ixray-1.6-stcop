# Third-Person View
> [!IMPORTANT]  
> **Status**: Supported <br>
> **Minimum Version**: 1.0

## Activating Third-Person Mode

The key to activate the EacLookAt camera now toggles between "first-person / third-person" cameras

```ini
bind cam_2 KEY ; Switch between EacLookAt and EacFirstEye
```

## Camera Position

The head tilt keys change the behavior in third-person mode and shift the camera to the right/left shoulder

```ini
offset_right = -0.4,0.2,0.0 ; Camera position relative to right shoulder
offset_left = 0.314,0.2,0.0 ; Camera position relative to left shoulder
```
