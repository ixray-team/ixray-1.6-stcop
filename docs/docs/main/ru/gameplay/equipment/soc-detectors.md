# Детекторы аномалий Тени Чернобыля

> [!IMPORTANT]
> Для детекторов с конфигурацией ТЧ необходимо указывать `class = D_SOCDET`.
> `D_SIMDET` выбирает ручной простой детектор артефактов ЧН и ЗП. При переносе конфигов ТЧ обновите класс пользовательских секций детекторов.

Детектор ТЧ работает в слоте инвентаря или на поясе и выключается в рюкзаке. Он обнаруживает включённые аномалии по **классу** указанной секции зоны, в том числе наследующиеся от неё секции. Зона с `visible_by_detector = off` не подаёт звуковой сигнал и не получает метку на карте.

```ini
[my_detector]:identity_immunities
class = D_SOCDET
slot = 8
radius = 10
ef_detector_type = 1
zone_class_1 = zone_mosquito_bald
zone_sound_1_ = detectors\DA-2_beep1
zone_min_freq_1 = 0.1
zone_max_freq_1 = 40
; Необязательные метка на карте и частица для ПНВ:
; zone_map_location_1 = anomaly_zone_location
; night_vision_particle = damage_fx\heli_burn
```

Остальные обязательные поля инвентарного предмета также должны присутствовать. Нумеруйте зоны подряд, начиная с 1; для каждой укажите звук и минимальную и максимальную частоты. Частоты задаются в герцах и увеличиваются при приближении к зоне. Необязательная частица отображается на ближайших включённых зонах при использовании ПНВ, как в ТЧ.

В скриптах для проверки `object:clsid()` используйте `clsid.device_detector_soc`; `clsid.device_detector_simple` соответствует классу `D_SIMDET`. Не задавайте числовой Lua ID класса вручную. Имена существующих секций предметов не меняются. После изменения класса предметов проверьте существующие сохранения и пользовательские спавны.
