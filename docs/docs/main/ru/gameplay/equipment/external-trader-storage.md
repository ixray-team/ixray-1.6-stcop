# Внешнее хранилище товаров торговцев

Появилась возможность сделать так, чтобы у торговца товары хранились в отдельных инвентарных ящиках, а не в рюкзаке НПС. Это позволяет сделать ассортимент торговца доступным для игрока в обход окна торговли с НПС, что делает возможным простую реализации новых геймплейных механик, например воровство у торговцев.


> [!IMPORTANT]  
> Фича не будет работать, если не будут включены движковые строковые Story ID!

## Создание внежнего хранилища

Для начала, нужно сделать секцию желаемого ящика (или взять готовую trade_storage_box_base из mod_system_ixray.ltx). Если делается новая секция, то нужно чтобы секция ящика имела class ID равный O_TRDBOX или наследуемый от него.
Нужный ящик нужно разместить на уровне в СДК, и прописать ему Story ID.

Далее, нужно в секцию торговца в spawn_sections_*.ltx добавить ключ ExternalStorageSect и по нему прописать имя секции, где будут находиться все Story ID ящиков, которые НПС будет использовать для хранения товаров.

```ini
[my_trader]
...
ExternalStorageSect = my_trader_storage

[my_trader_storage]
storage_general ; Story ID ящиков
storage_arts
```

## Фильтры на фщики

Если есть потребность в том, чтобы в ящик попадали только предметы определённых секций, то на ящик можно добавить фильтр.
Для этого нужно в секции ящика добавить ключ filter_section и по нему указать имя секции, где будут указаны все разрешённые секции.

> [!IMPORTANT]  
> Важно, чтобы существовал ящик "по умолчанию", куда бы попадали все предметы, которые не подходят ни в какой другой по фильтрам!


```ini
[storage_arts]
...
filter_section = storage_arts_filter

[storage_arts_filter]
af_meduza ; добавить секции всех нужных предметов
$trade_group_arts_all ; есть поддержка групп объектов для торговли
```
