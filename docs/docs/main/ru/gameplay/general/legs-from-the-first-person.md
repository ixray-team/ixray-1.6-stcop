# Ноги от 1 лица
> [!IMPORTANT]
> **Статус**: Поддерживается <br>
> **Минимальная версия**: 1.1

## Настройка конфига

Реализована система ног от первого лица. Для отображения ног необходимо в секцию худа рук (`actor_hud_*`) добавить следящее:

```ini
[actor_hud_01]
legs_visual = actor\stalker_legs\trenchcoat_outfit ; Визуал ног для данной комбинации рук
legs_shift_delta = -0.67                           ; Смещение ног относительно направления актёра (опционально, значение по умолчанию -0.55)
```

## Настройка модели

Для правильной работы данной системы требуется специальная модель, представляющая из себя модель персонажа без головы и рук, при этом туловище должно быть привязано к кости `bip01_pelvis`

![image](https://github.com/user-attachments/assets/c8a52ae3-2f27-47bd-923e-43ae03e14283)

Анимации для работы ног требуются. Текущая реализация требует одинакового скелета у модели ног и модели персонажа.
