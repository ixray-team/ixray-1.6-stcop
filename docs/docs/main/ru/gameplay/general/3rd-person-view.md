# Вид от 3 лица
> [!IMPORTANT]  
> **Статус**: Поддерживается <br>
> **Минимальная версия**: 1.0

## Активация режима "от третьего лица"

Бинд включения камеры EacLookAt теперь переключает камеры "от первого/ третьего лица" между собой

```ini
bind cam_2 KEY ; Переключение между EacLookAt и EacFirstEye
```

## Позиция камеры

Клавиши наклона головы меняют поведение в режиме "от третьего лица" и смещают камеру на правое/ левое плечо

```ini
offset_right = -0.4,0.2,0.0 ; Позиция камеры относительного правого плеча
offset_left = 0.314,0.2,0.0 ; Позиция камеры относительного левого плеча
```
