# Инвентарь мутантов

## Обзор

> [!IMPORTANT]  
> **Статус**: Поддерживается <br>
> **Минимальная версия**: 1.0

Данная функция позволяет мутантам иметь инвентарь и носить в нем предметы, аналогично механике из оригинальных игр «Тень Чернобыля» (ТЧ) и «Чистое Небо» (ЧН)

## Включение функционала

Для активации системы инвентаря у мутантов необходимо изменить глобальный параметр в конфигурации движка.

**Пример использования:**

Откройте файл `engine_external.ltx` и в секции `[gameplay]` установите параметр `EnableMonstersInventory` в значение `true`.

```ini
[gameplay]
; ... другие параметры ...
EnableMonstersInventory = true ; true - включить инвентарь, false - выключить
```

## Настройка спавна предметов

Чтобы мутант мог носить предметы в инвентаре, в его конфигурационный файл необходимо добавить специальные параметры

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `Spawn_Inventory_Item_Section` | string | Секция предмета, который будет заспавнен в инвентарь. Поддерживает мультиспавн через запятую |
| `Spawn_Inventory_Item_Probability` | float | Вероятность (от 0.0 до 1.0) того, что предмет будет заспавнен |

**Пример использования:**

```ini
; Конфиг мутанта (например, m_boar.ltx)
[m_boar_e]
...
Spawn_Inventory_Item_Section = mutant_boar_leg
Spawn_Inventory_Item_Probability = 1
```

## Настройка фантомов пси-собак

Добавлена возможность определять кастомную секцию для фантомов пси-собак через параметр `phantom_section`. Это позволяет переопределять стандартного фантома на собственную секцию

**Параметры:**

| Параметр | Тип | Описание | По умолчанию |
| :--- | :--- | :--- | :--- |
| `phantom_section` | string | Секция, из которой спавнятся фантомы | `psy_dog_phantom` |

**Пример использования:**

Чтобы пси-собака спавнила фантомы из вашей собственной секции, укажите её имя в конфиге мутанта.

**Пример использования:**

```ini
[psy_dog]
phantom_section = my_custom_phantom ; Использование кастомной секции для фантомов
```

## Настройка игнорирования аномалий

Добавлена возможность определённой секции мутантов сделать возможность игнорировать определённые аномалии и аномальные поля. Фича очень полезна в случае, если у мутанта есть OUT рестриктор, но при этом он полностью покрыт аномальным полем, который обычно является IN рестриктором для моба, из-за чего у моба будет сломана навигация.

**Пример использования:**

Можно сделать пси-зону, в которую не будут заходить мутанты, но зато внутри которой сможет жить уникальный контроллёр, которому будет назначен OUT рестриктор меньше пси-зоны.

```ini
[controller_unique]:m_controller_normal
Anomaly_Detect_Ignore_List = controller_unique_ignore_list ; Кастомная секция со списком игнорируемых CLASS_ID аномалий, применяется только к этой секции

[controller_unique_ignore_list]
ZS_RADIO ; Игнорируемый CLASS_ID
; Если надо несколько - просто пишем их в столбик
```

## Улучшенная псевдосмерть зомби-гражданского

Добавлена возможность активировать улучшенную псевдосмерть зомби-гражданского - зомби будет падать через ragdoll, и будет продолжать лежать пока игрок на него смотрит, чтобы напасть со спины. При этом его падение очень будет похоже на падение при смерти. Такой результат позволит сделать этого мутанта ещё более опасным, нежели в оригинальном исполнении.

Для активации этой фичи нужно открыть файл `engine_external.ltx` и в секции `[gameplay]` установить параметр `EnableRagdolledZombiePseudodeath` в значение `true`.

```ini
[gameplay]
; ... другие параметры ...
EnableRagdolledZombiePseudodeath = true ; true - включить инвентарь, false - выключить
```
