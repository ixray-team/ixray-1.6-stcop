# Используемые предметы

## Свои действия в меню инвентаря

В секции предмета `default_use_text` заменяет подпись стандартного действия использования. У обычных расходуемых предметов есть собственный текст `use_text` с резервом `st_use`. Для аптечек, антирада и бутылок меню выбирает свои стандартные подписи, если `default_use_text` отсутствует.

Для каждого дополнительного действия укажите текст и имя Lua-функции. Поддерживаются четыре пары: `use1_text` и `use1_functor`, `use2_text` и `use2_functor`, `use3_text` и `use3_functor`, `use4_text` и `use4_functor`. Значение `*_text` — ключ локализации. Функция получает `game_object` предмета и возвращает `true`, чтобы после её вызова меню запустило обычное использование, либо `false`, чтобы завершить действие без этого шага.

```ini
use1_text = st_open
use1_functor = my_item.on_open
```

Если `my_item.on_open` сама выполняет нужное действие, верните из неё `false`.

## Порции, вес и последняя анимация

В секции расходуемого предмета `eat_portions_num` имеет приоритет над `max_uses`. Резерв `max_uses` равен `1`. Затем загрузчик делит число применений на `eat_condition` и сохраняет целую часть. Используйте положительный `eat_condition`, по умолчанию `1`. `remove_after_use` управляет удалением после исчерпания порций, по умолчанию `true`. `empty_weight` задаёт массу пустого предмета, резерв `0.0`.

Если у предмета есть `animator_sect`, ключ `last_use_section` указывают внутри секции этого аниматора. Он задаёт секцию анимации для последней порции многопорционного предмета.
