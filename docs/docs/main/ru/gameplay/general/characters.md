## Случайный ранг у НПС

Необходимо открыть профиль НПС и прописать минимальное и максимальное значение для тега `rank`

```xml
   <rank min="0" max="100" />
```

## Случайная репутация у НПС

Необходимо открыть профиль НПС и прописать минимальное и максимальное значение для тега `reputation`

```xml
   <reputation min="-100" max="100" />
```

## Случайный лут
Добавлена система случайного лута у НПЦ. 
Для этого требуется прописать `spawn_loadout` в профиле NPC, таких секций может быть сколь угодно много в каждом из профилей главное чтобы секция начиналась с фразы `spawn_loadout`

**Пример:**
```ini
[spawn_loadout] \n
wpn_vintorez = 1 \n
wpn_groza = 1 \n
wpn_pkm = 1 \n

[spawn_loadout3] \n
wpn_pm = 1 \n
wpn_walther = 1 \n
```

В секции spawn_loadout* первое значение после имени секции предмета указывает не на колличество предметов к спавну а колличество пачек патронов к заспавненному оружию

Для лодаутов и ванильного спавна теперь поддерживаются новые параметры:

```ini
(поддерживается только ванильным спавном и режимом лодаутов EnableSpawnFullRandomLoadout):
prob= ; Дробное значение от 0 до 1 указывающее на шанс спавна предмета

(ванильный спавн и все лоадут режимы):
scope ;добавить прицел \n
scope= ;добавить конкретный прицел по индексу с конфига \n
scope_prob= ;добавить прицелу шанс установки не задан то 100% \n
silencer ;добавить глушитель \n
silencer_prob= ;добавить глушителю шанс установки если не задан то 100% \n
launcher ;добавить гранатомёт \n
launcher_prob= ;добавить гранатомёту шанс установки если не задан то 100% \n
```

Примеры установки доп свойств при спавне:
```ini
wpn_ak74 = 1, scope=3, scope_prob=0.5 ;Установка 3-го прицела из конфига с шансом 50%
wpn_lr300 = 1, silencer, silencer_prob=0.3 ;Установка глушителя с шансом 30%
wpn_g36 = 1, launcher, launcher_prob=0.2 ;Установка гранатамета с шансом 20%
wpn_an94 = 1, scope=3, scope_prob=0.5, silencer, silencer_prob=0.3, launcher, launcher_prob=0.2 ;Установка прицела с шансом 50% + Глушителя с шансом 30% + гранатамета с шансом 20%
```

Режим работы лодаутов переключается в engine_external.ltx
```ini
[spawn_supplies]
;вкл выкл использование лодаутов у нпц (работает как дополнение к ванильному спавну а не заменяет его)
EnableLoadoutsSupplies = true | false

; Выбрать один из параметров ниже (одновременное использование не предусмотрено)

;Cпавн всех секций одного случайного лодаута из файла у нпц
EnableSpawnFullRandomLoadout = true | false

;Cпавн по одному случайному предмету из всех лодаутов добавленных в нпц
EnableSpawnOnceRandomItemPerEachLoadouts = true | false

;Cпавн одного случайного предмета среди всех лодаутов добавленных в нпц
EnableSpawnOnceRandomitemByRandomLoadout = true | false
```

## Улучшение схем поведенения 

- Улучшена схема поведения при бое в помещении: NPC больше не будут смотреть в пол или потолок, если враг находится на другом этаже
- Улучшена схема обнаружения NPC противников, исправлена проблема с преждевременным обнаружением врагов
- Добавлена схема обхода машин для NPC
- Добавлена возможность включить реакцию NPC на аномалии (`EnableAiDieInAnomaly`)
- Добавлена возможность включить слежение NPC за главным героем в определенном радиусе (`NPCLookAtActor`)
