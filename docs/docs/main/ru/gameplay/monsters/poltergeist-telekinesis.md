# Телекинез полтергейста — mod_system_ixray.ltx

Секция: `![m_poltergeist_normal_tele]`

## Стрельба с захваченного оружия

| Параметр | Тип | Значение | Описание |
|----------|-----|----------|----------|
| `Tele_Shooting_From_Weapon_Enable` | bool | off | Разрешает стрельбу с захваченного оружия по врагу. `on`/`off` |
| `Tele_Max_Pickuped_Weapons` | int | 3 | Максимальное количество стреляющего оружия, которое полтергейст может захватить одновременно |
| `Tele_Delay_Before_First_Shoot` | int (мс) | 0 | Задержка перед первым выстрелом захваченного оружия |

## Гранаты

| Параметр | Тип | Значение | Описание |
|----------|-----|----------|----------|
| `Tele_Activate_N_Throw_Grenade` | bool | on | Разрешает выдёргивать чеку у гранат и бросать их во врага. `on`/`off` |

| Параметр | Тип | Значение | Описание |
|----------|-----|----------|----------|

| `Tele_Object_Min_Mass` | float | 0 | Минимальная масса предмета для захвата телекинезом |

## Урон от броска предметов

Формула расчёта урона:
```
final_damage = hit_factor - (strike_protection * condition костюма)
```
Если результат `< 0`, урон = 0 (предмет не пробивает броню).

| Параметр | Тип | Значение | Описание |
|----------|-----|----------|----------|
| `Novice_Difficulty_Throwed_Object_Hit_Factor` | float | 0.25 | Множитель урона на «Новичке». Значение = % от MaxHP (0.25 = 25% HP за удар) |
| `Stalker_Difficulty_Throwed_Object_Hit_Factor` | float | 0.35 | Множитель урона на «Сталкере» (0.35 = 35% HP) |
| `Veteran_Difficulty_Throwed_Object_Hit_Factor` | float | 0.45 | Множитель урона на «Ветеране» (0.45 = 45% HP) |
| `Master_Difficulty_Throwed_Object_Hit_Factor` | float | 0.55 | Множитель урона на «Мастере» (0.55 = 55% HP) |

> Урон также зависит от `strike_immunity` костюма и артефактов на поясе с защитой от `strike`.
> Диапазон значений: `[0.0 .. 1.0]`. Значение `0.0` отключает урон от предметов полностью.

**Примеры расчёта:**

| factor | Костюм | strike_protection | Итоговый урон |
|--------|--------|-------------------|---------------|
| 0.25 | Новичок | 0.1 | 0.25 - 0.1 = **0.15** (15% HP) |
| 0.35 | Сталкер | 0.15 | 0.35 - 0.15 = **0.20** (20% HP) |
| 0.45 | Экзо | 0.4 | 0.45 - 0.4 = **0.05** (5% HP) |
| 0.25 | Экзо | 0.4 | 0.25 - 0.4 = **-0.15** → **0** (не пробито) |

## Авто-наведение захваченного оружия

### Скорость наведения (°/с)

Оружие поворачивается к цели с ограниченной скоростью, а не мгновенно.

| Параметр | Тип | Значение | Описание |
|----------|-----|----------|----------|
| `Novice_Difficulty_Angular_Speed` | float | 180.0 | Скорость поворота оружия к цели на «Новичке» (°/с) |
| `Stalker_Difficulty_Angular_Speed` | float | 200.0 | Скорость поворота оружия к цели на «Сталкере» (°/с) |
| `Veteran_Difficulty_Angular_Speed` | float | 240.0 | Скорость поворота оружия к цели на «Ветеране» (°/с) |
| `Master_Difficulty_Angular_Speed` | float | 280.0 | Скорость поворота оружия к цели на «Мастере» (°/с) |

> Диапазон: `(0 .. 360]`. Значение `360` = мгновенное наведение (турельный режим).

### Погрешность наведения (°)

Угол отклонения оси оружия от направления на цель, при котором разрешён выстрел.

| Параметр | Тип | Значение | Описание |
|----------|-----|----------|----------|
| `Novice_Difficulty_Error_Angle` | float | 30.0 | Погрешность наведения на «Новичке» (°) |
| `Stalker_Difficulty_Error_Angle` | float | 20.0 | Погрешность наведения на «Сталкере» (°) |
| `Veteran_Difficulty_Error_Angle` | float | 15.0 | Погрешность наведения на «Ветеране» (°) |
| `Master_Difficulty_Error_Angle` | float | 8 | Погрешность наведения на «Мастере» (°) |

> Диапазон: `(0 .. 180]`.
> - `1°` — оружие стреляет только при идеальном наведении в центр модели врага.
> - `180°` — оружие стреляет даже когда смотрит в противоположную сторону.
> - На низких сложностях большая погрешность + медленное наведение = перерасход патронов.
