# Ключи запуска

> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: 1.0

## Обзор

Передавайте ключи исполняемому файлу в командной строке или в поле аргументов ярлыка. `-ltx` выбирает файл консольных команд. Ключи запуска передаются отдельно. У ключей `-fsltx`, `-ltx`, `-overlaypath` и `-demomode` значением служит один токен без пробелов.

## Синтаксис

```powershell
.\xrEngine.exe -fsltx fsgame.ltx -ltx user.ltx -r4
```

## Игра и файловая система

| Ключ | Действие |
| --- | --- |
| `-fsltx <файл>` | Выбирает конфигурацию файловой системы при старте. |
| `-ltx <файл>` | Выбирает стартовый файл консольных команд. |
| `-overlaypath <каталог>` | Перенаправляет корни `$app_data_root$` и `$logs$`. Укажите каталог. |
| `-auto_load_arch` | Разрешает автоматически подключать игровые архивы. |
| `-nolog` | Отключает создание файла лога в игровом локаторе. |
| `-start <аргументы>` | Передаёт строку команде консоли `start` при запуске. |
| `-load <сохранение>` | Передаёт строку команде консоли `load` при запуске. |
| `-demomode <файл>` | Читает список демосценариев при старте. Укажите имя файла после ключа. |
| `-noprefetch` | Пропускает предварительную загрузку игровых ресурсов в `IGame_Persistent`. |
| `-nosound` | Запускает игру без обычной звуковой подсистемы. |
| `-designer` | Включает специальный режим сервера и ограничивает переход некоторых ALife-объектов онлайн. |


Укажите `-start` или `-load` в конце строки. Движок передаёт консоли весь остаток аргументов после ключа.

## Рендерер и отладка

| Ключ | Действие |
| --- | --- |
| `-r4`, `-r2` | Выбирают R4 или R2 из доступных рендереров. Если указать оба, стартовая проверка сначала выбирает R4. Без них используется настройка `renderer` из стартового LTX. |
| `-no_center_screen` | При создании окна пропускает центрирование. |
| `-perfhud_hack` | Заполняет список рендереров через ветку PerfHUD. |
| `-dxdebug` | Запрашивает отладочный режим устройства D3D11. |
| `-disasm` | Включает дизассемблирование шейдеров. |
| `-nonvs` | Отключает NVIDIA depth/stencil в R2. В R4 этот режим уже выключен. |
| `-noshadows` | Выставляет флаг отключения теней в R2 и R4. |
| `-nodistort` | Выключает проход искажений в R2 и R4. |
| `-no_occq` | Отключает запросы окклюзии в обслуживающем их классе рендерера. |
| `-renderdoc` | Сохраняет отладочные имена ресурсов D3D11 в поддерживающих этот ключ путях. Захват запускается через RenderDoc. |
| `-xclsx` | Отключает вывод красного диагностического текста. |
| `-nes_texture_storing` | Записывает список используемых текстур при выгрузке уровня. |
| `-skinw` | Выставляет опцию `forceskinw` в R1 и R2. |
| `-tsh` | Выставляет опцию `Tshadows` в R2. |
| `-no_debug_panel` | Отключает инициализацию панели отладки ImGui. |
| `-debug_ge` | Выставляет флаг отладки игровых событий. |
| `-silent_error_mode` | В Windows-обработчике `terminate` завершает процесс с кодом `-1` до обработки аварии. |
| `-no_call_stack_assert` | В Windows пропускает окно ошибки из ветки формирования отчёта об assert. |

## Lua

| Ключ | Действие |
| --- | --- |
| `-keep_lua` | Пропускает повторную инициализацию Lua в `restart_all()` при перезапуске ALife. |
| `-use_callstack` | Включает вывод стека вызовов при ошибках Lua. |
| `-ldbg` | Включает обработку LDBG в сборках с поддержкой Lua-отладчика. |

## Автотесты

Доступны с IX-Ray Platform 1.4.

| Ключ | Действие |
| --- | --- |
| `-autotest` | Запускает автоматический прогон с замером кадров и отчётом. |
| `-autotest_frames N` | Количество измеряемых кадров, по умолчанию `120`. |
| `-autotest_warmup N` | Количество кадров прогрева, по умолчанию `150`. |
| `-autotest_timeout S` | Таймаут в секундах, по умолчанию `300`. |
| `-autotest_out <путь>` | Путь к отчёту. По умолчанию `$logs$/autotest.csv`. |
| `-autotest_hash` | Добавляет CRC изображения кадра в отчёт. |
| `-autotest_shot [N]` | Сохраняет TGA каждые `N` измеренных кадров. Без `N` сохраняет каждый кадр. |
| `-autotest_post_cmd <команда>` | Выполняет одну консольную команду в первом кадре после прогрева. Укажите до `-autotest_cmd`. |
| `-autotest_cmd <команды>` | Выполняет стартовые консольные команды через точку с запятой. Занимает всю оставшуюся строку аргументов. |

```bat
xrEngine.exe -r4 -autotest -autotest_frames 120 -autotest_cmd start server(jupiter/single/alife/new) client(localhost)
```

В автотесте код выхода `0` означает, что достигнуто число кадров и не зарегистрировано строк с `[error]`. В остальных случаях код выхода `1`.

## SDK и утилиты

| Приложение | Ключи и справочник |
| --- | --- |
| `LevelEditor.exe` | `-ltx <файл>` выбирает стартовый LTX редактора. Общие флаги ядра `-build` и `-ebuild` включают режим сбора копий файлов при сборке. |
| `xrLevelBuilder.exe` | `-fsltx <файл>` выбирает конфиг файловой системы. Параметры геометрии, света и AI задаются в интерфейсе [компиляторов](../utilities/compilers.md). В загрузчике AI `-clear_temp_files` удаляет исходный `build.aimap` после чтения. |
| `xrCompress.exe` | Отдельный синтаксис [упаковки, распаковки и diff](../utilities/compressor.md). |
| `xrServerCLI.exe` | Отдельный запуск [выделенного сервера](../platforms/multiplayer/dedicated-server.md). Аргументы включают настройки `-fsltx`, `-ltx`, `-start` и серверный конфиг `-svcfg`. |
