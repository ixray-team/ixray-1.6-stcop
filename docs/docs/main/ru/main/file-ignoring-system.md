# Система игнорирования файлов

> [!IMPORTANT]
> **Статус**: Поддерживается <br>
> **Минимальная версия**: 1.1

## Обзор

`.xrignore` - файл из корневой директории, отвечающий за пропуск чтения различных файлов

## Использование

```sh
# Работает по принципу нахождения в пути
# Если игнорируем desk.dds, то будет работать сортировка по принципу *desk.dds

Thumbs.db
.svn

# Temp trash
/.git/
/.vs/
/temp/
```
