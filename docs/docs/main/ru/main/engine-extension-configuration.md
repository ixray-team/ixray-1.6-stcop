# Конфигурация расширений движка

## Обзор

Конфигурационный файл позволяет настраивать различные аспекты игры и движка через систему секций и параметров. Файл использует INI-формат с группировкой настроек по функциональным категориям

## Основные секции

### [general]

**Основные настройки движка**

| Параметр | Значения | Описание |
|----------|----------|----------|
| **Platform** | `cop`, `cs` | Режим платформы. cop - Зов Припяти, cs - Чистое Небо |
| **title** | текст | Название модификации |
| **SaveImageSize** | 128,128 | Размер изображений сохранений |

### [shaders_options]

**Настройки шейдеров и графики**

| Параметр | Значения | Описание |
|----------|----------|----------|
| USE_LEGACY_LIGHT | 0/1 | 1 - устаревший пайплайн, 0 - PBR пайплайн |
| USE_BGRA_SKYCOLOR | 0/1 | Формат цвета неба BGRA |
| USE_LEGACY_SKY_TONEMAP | 0/1 | Оригинальный формат ToneMapping для неба |
| USE_CGIM_SKY_TWEAK | 0/1 | Совместимость с CGIM2 |
| USE_CGIM_WHITE_TWEAK | 0/1 | Настройки белого цвета для CGIM2 |

### [ui]

**Пользовательский интерфейс**

| Параметр | Значения | Описание |
|----------|----------|----------|
| **DisableCharacterInfo** | true/false | Отключить информацию о персонаже |
| **DisableInventoryGrid** | true/false | Использовать альтернативную сетку инвентаря |
| **WeaponIconScale** | 0.65-0.9 | Масштаб иконок оружия (CoP: 0.8, CS: 0.65, SoC: 0.9) |
| **ShowLoadingStages** | true/false | Показывать стадии загрузки из CS/SoC |
| **DisableMotionIcon** | true/false | Отключить иконку движения |
| **PdaRearrangeTabButtons** | true/false | Кнопки в стиле CS с размером зависящим от текста |
| **UseSavedGameStatic** | true/false | Использовать статичные изображения сохранений |

### [physics]

**Физика и взаимодействия**

| Параметр | Значения | Описание |
|----------|----------|----------|
| **DeadBodyRagdoll** | true/false | Включить ragdoll физику для тел |

### [gameplay]

**Игровой процесс и механики**

#### Основные механики

| Параметр | Значения | Описание |
|----------|----------|----------|
| **EnableThirst** | true/false | Включить механику жажды |
| **EnableSleepiness** | true/false | Включить механику усталости |
| **EnableAiDieInAnomaly** | true/false | Гибель ИИ в аномалиях |
| **EnableNPCLookAtActor** | true/false | NPC смотрят на игрока |
| **EnableAutoreload** | true/false | Автоматическая перезарядка оружия |
| **EnableMonstersInventory** | true/false | Инвентарь у монстров |

#### Система оружия

| Параметр | Значения | Описание |
|----------|----------|----------|
| **EnableWeaponInertion** | true/false | Инерция оружия (стиль Gunslinger) |
| **EnableWeaponCollision** | true/false | Коллизия оружия (стиль Shoker) |
| **EnableImproveWeaponMisfire** | true/false | Улучшенная система осечек (стиль Gunslinger) |
| **EnableDelayedWeaponActions** | true/false | Отложенные действия с оружием (стиль Gunslinger) |

#### Дополнительные возможности

| Параметр | Значения | Описание |
|----------|----------|----------|
| **EnableActorStepWallmarks** | true/false | Следы от шагов на поверхностях (стиль AIW) |
| **EnableAlternateZoomFovCalc** | true/false | Альтернативный расчет FOV при зуме (стиль Gunslinger) |
| **EnableInventoryPistolSlot** | true/false | Отдельный слот для пистолетов (как в CS/SoC) |

#### Диалоги и движение

| Параметр | Значения | Описание |
|----------|----------|----------|
| **DialogFovScale** | число | Сила увеличения FOV во время диалогов |
| **TalkDof** | числа | Степень размытия фона в диалоге |
| **EnableBlockSprintInReload** | true/false | Блокировка спринта во время перезарядки |
| **DisableSprintWhileOverweight** | true/false | Отключить спринт при перевесе |
| **SprintFovFactor** | число | Сила увеличения FOV во время бега |

### [render]

**Визуальные эффекты и рендеринг**

| Параметр | Значения | Описание |
|----------|----------|----------|
| **DisableLoadScreenTips** | true/false | Отключить советы на экране загрузки |
| **UseDynamicSnowMask** | true/false | Использовать процедурный снег |
| [FontAtlasSize](/interface/fonts#cинографическая-семья-письменностей) | 4096 | Размер текстурного атласа шрифтов (степень двойки) |

### [environment]

**Окружающая среда**

| Параметр | Значения | Описание |
|----------|----------|----------|
| **ReadSunConfig** | true/false | Регулировать положение солнца через конфиги|

## Расширенные секции

### [player_hud]

### [step_wallmark]

**Следы шагов** (требует `EnableActorStepWallmarks`)

| Параметр | Описание |
|----------|----------|
| **materials** | Материалы, на которых отображаются следы |
| **left_mark** | Секция для следа левой ноги |
| **right_mark** | Секция для следа правой ноги |

## Рекомендации

- ⚠ **Предупреждения**:  
  Секция `[step_wallmark]` требует активации `EnableActorStepWallmarks` <br>
  `EnableAlternateZoomFovCalc` ломает оригинальную систему оружия  <br>
  Настройки оружия из разных модов могут конфликтовать  <br>
  Изменение `Platform` влияет на совместимость с модами <br>

- ✖ **Не рекомендуется**:  
  Изменять `FontAtlasSize` без необходимости (только для специальных шрифтов)  <br>
  Использовать закомментированные опции без понимания их назначения <br>
