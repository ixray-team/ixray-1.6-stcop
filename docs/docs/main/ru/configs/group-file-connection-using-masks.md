# Подключение ресурсов по маске

> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: IX-Ray Platform 1.2

## Обзор

Маски позволяют подключить несколько ресурсов одной строкой. LTX и XML используют директиву `#include`. Модели OGF могут ссылаться на несколько файлов анимаций OMF через маску в списке ссылок.

## Синтаксис

| Формат | Пример | Откуда читается |
| --- | --- | --- |
| LTX | `#include "weapons\w_*.ltx"` | От каталога текущего LTX |
| XML | `#include "ui\hud_widgets\*.xml"` | От файлового раздела, из которого загружается XML |
| OGF | `dynamics\weapons\wpn_hand\*.omf` | Из `$game_meshes$` и `$level$` |

## Примеры

### Конфиги оружия

```ini
#include "weapons\w_*.ltx"
```

Маска проверяется по пути относительно `weapons`, включая имена вложенных каталогов.

Чтобы подключить все LTX из `weapons` и его подкаталогов, используйте:

```ini
#include "weapons\*.ltx"
```

Указывайте базовый каталог без звёздочки. Для `#include "weapons\*\*.ltx"` LTX-парсер пытается открыть каталог `weapons\*\`.

### Виджеты HUD

```xml
<w>
  #include "ui\hud_widgets\*.xml"
</w>
```

XML-парсер подставляет содержимое подключённых файлов на месте директивы. В этом примере каждый файл содержит дочерние элементы `w`.

### Анимации OMF

```text
dynamics\weapons\wpn_hand\*.omf
```

Ссылка OGF загружает OMF из `wpn_hand` и его подкаталогов. Маска `dynamics\weapons\*\*.omf` выбирает файлы внутри подкаталогов `weapons`. Чтобы подключить также файлы из самого `weapons`, используйте `dynamics\weapons\*.omf`.

## Рекомендации и ограничения

- Для группового XML-подключения используйте маску с подстрокой `*.xml`. Обычный XML можно подключить по точному имени.
- Если порядок подключения влияет на результат, перечислите файлы явно.
- В одной маске OMF держите наборы, совместимые со скелетом модели.
