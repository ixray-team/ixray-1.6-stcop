# **Движковые перепаковщик патронов**

> [!IMPORTANT]  
> **Статус**: Поддерживается <br>
> **Минимальная версия**: IX-Ray Platform 1.5

## **Обзор**

Имеется поддержка движкового перепаковщика патронов. При включённой опции при подъёме боеприпасов (из оружия, контейнера или с земли) они будут пытаться объединиться с уже существующими стаками патронов. Таким образом, например, если игрок видит перед собой 6 коробок 5.45х39 по 10 патронов, в то время как одна коробка вмещает по 60 патронов, то после поднятия всех их у игрока будет одна полная коробка на 60 патронов в инвентаре, а не 6 по 10 патронов. Перепаковка работает только для патронов одного типа (то есть тех, которые имеют одинаковую секцию в конфигах), поэтому для двух коробок разных типов перепаковщик не будет их обрабатывать.

Включить эту опцию можно в engine_external.ltx в секции system, прописав ключ EngineAmmoRepacker равным true:

```ini
[system]
EngineAmmoRepacker = true
```
