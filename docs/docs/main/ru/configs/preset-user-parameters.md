# Предустановленные пользовательские параметры

> [!IMPORTANT]  
> **Статус**: Поддерживается <br>
> **Минимальная версия**: IX-Ray Platform 1.3

## **Обзор**

Теперь поддерживается возможность задавать пользовательские настройки, которые будут автоматически применяться при каждом запуске игры

**Зачем это нужно:**

Если модификация использует специфические параметры освещения, блюма, тонмаппинга и других графических опций — теперь не требуется модифицировать движок, писать скрипты (как это делалось в AtmosFear 3) или редактировать пресеты графики.
Кроме того, это удобно для отладки: можно создать вспомогательный аддон с заранее заданными параметрами — например, нужными опциями, читами или логированием.

## **Использование**

Создайте в папке **configs** подкаталог **ixray_settings**, а в нём файл `default_settings_MODNAME.ltx`. В этом файле необходимо перечислить все параметры, которые следует применять при каждом запуске игры. Структура файла полностью аналогична **user.ltx**.

## **Рекомендации**

- ✔ Используйте для задания базовых графических настроек, например освещения для погодных модификаций;
- ✔ Учтите, что движок загружает все файлы по маске `default_settings_*.ltx` в алфавитном порядке;
- ⚠ Настройки из других аддонов также могут переопределять значения;
- ✖ Не используйте для переопределения клавиш управления — это может испортить пользовательский опыт.
