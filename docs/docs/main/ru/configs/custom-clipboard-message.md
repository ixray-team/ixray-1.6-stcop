# **Поддержка кастомный сообщений в буфере обмена при вылете**

> [!IMPORTANT]  
> **Статус**: Поддерживается <br>
> **Минимальная версия**: IX-Ray Platform 1.5

## **Обзор**

Ещё в оригинале есть особенность движка, когда при критической ошибке он сохраняет часть лога в буфер обмена, в результате чего сразу после вылета можно открыть любой текстовый документ в вставить часть лога. Однако, в IX-Ray часто важная для понимания причины вылета информация лежит в полном логе и не попадает в буфер обмена, из-за чего игроки, отправляя багрепорт "по привычке", не отправляют всю важную информацию.
Для того, чтобы разгрузить техподдержку модов от таких случаев, была добавлена возможность задать своё сообщение об ошибке в буфер обмена вместо стандартного поведения.

## **Активация**

1) В engine_external.ltx в секцию system необходимо выставить значение по ключу CustomMessageInClipboardOnCrash равным true:

```ini
[system]
CustomMessageInClipboardOnCrash = true
```

2) В файлах локализации для поддерживаемых языков прописать текст для ключа st_clipboard_error_message:

```xml
<string_table>
  <string id="st_clipboard_error_message">
    <text>Пожалуйста, предоставьте полный лог в багрепорте, расположенный в папке с логами в _appdata_ixray_ (самый свежий файл)</text>
  </string>
</string_table>
```
