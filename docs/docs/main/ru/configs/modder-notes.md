# Заметки для мододелов

## Первая секция ltx-файла не читается (UTF-8 BOM)

**Симптом:** игра не видит первую секцию файла (например, её нет в `g_spawn`), хотя все секции после неё работают.

**Причина:** файл сохранён в кодировке «UTF-8 с BOM». В начале файла стоят невидимые байты `EF BB BF`, и первая строка на деле выглядит как `<BOM>[section]`. Парсер ltx не распознаёт её как заголовок секции.

**Проверка:**

```bash
head -c 16 file.ltx | od -c
```

Если вывод начинается с `357 273 277`, в файле есть BOM.

**Решение:** пересохраните файл без BOM:

- Notepad++: «Кодировка → Преобразовать в UTF-8 (без BOM)» или в ANSI/windows-1251;
- VS Code: кодировка в статус-баре → «Save with Encoding» → «UTF-8».

Обходной путь: оставить первую строку файла пустой или сделать её комментарием `;`.

См. также: [Кодировка файлов](/configs/file-encoding).
