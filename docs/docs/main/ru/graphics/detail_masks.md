## Общее

**Detail Procedural Perlin Noise Mask** - Процедурные маски для травы на основе шума перлин

### Консольные команды
```ini
r__detail_use_perlin_noise              [0 | 1 | true | false] ;// (Вкл выкл) перлин шум на ростительности 
r__detail_perlin_noise_frequency        [0.001f ~ 1.0f] ;// Плотность шума он же скейл (чем выше значение тем плотнее шум)
r__detail_perlin_noise_amplitude        [0.001f ~ 10.0f] ;// Интерполяция сглаживания шума (чем выше тем резче края маски) 
r__detail_perlin_noise_random_height    [0.0f ~ 1.0f] ;// Случайные добавочные отклонения от маски по высоте в процентах для большей естественности роста ростений
r__detail_rnd_scale_min                 [0.0f, infinty] ; Минимальная высота травы (не должна превышать максимальную высоту)
r__detail_rnd_scale_max                 [0.0f, infinty] ; Максимальная высота травы (не должна быть ниже минимальной)
```
