# Опции шейдеров

> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: IX-Ray Platform 1.2

## Обзор

Секция `[shaders_options]` в `gamedata/configs/engine_external.ltx` задаёт глобальные макросы компиляции шейдеров. Движок читает файл при инициализации. После изменения перезапустите игру.

## Синтаксис

```ini
[shaders_options]
USE_LEGACY_LIGHT = 1
USE_LEGACY_SKY_TONEMAP = 1
IBL_MAX_LOD = 10
```

Движок пропускает строки без значения, отключает макрос со значением ровно `0` и передаёт остальные значения как текст макроса. Для условия `#ifdef` важно наличие макроса, поэтому используйте `1` для включения и `0` или отсутствие строки для отключения. Числовые макросы вроде `IBL_MAX_LOD` используются в вычислениях. Строки с `;` в начале являются комментариями.

Рендереры R1, R2 и R4 получают глобальные макросы. Эффект конкретного имени зависит от шейдеров выбранного рендерера. Используйте точное написание имени из исходников шейдеров.

## Глобальные параметры

| Макрос | Где применяется и что меняет |
| --- | --- |
| `USE_LEGACY_LIGHT` | В R4 выбирает legacy-освещение вместо PBR-ветки и отключает экранные и внеэкранные отражения, которые выставляются в этой ветке. |
| `USE_SOC_LIGHTING` | Совместимость с форматом lightmap ТЧ. |
| `USE_DIFFUSE_SKY_COLOR` | Использует рассеянный цвет неба в расчёте окружающего света. Есть потребители в шейдерах R2, R4 и редактора. |
| `USE_BGRA_SKYCOLOR` | Меняет порядок каналов цвета неба на BGRA в поддерживающих этот макрос шейдерах. |
| `USE_LEGACY_SKY_TONEMAP` | Использует оригинальное преобразование цвета неба. |
| `USE_NORMAL_HEMI_DISTRIBUTION` | Учитывает нормаль поверхности при расчёте полусферического освещения в R4. |
| `USE_CGIM_SKY_TWEAK` | Меняет вычисление полусферического освещения в R4, в том числе в проходе интерьера. |
| `USE_CGIM_WHITE_TWEAK` | Меняет коэффициенты `tonemap` и `detonemap` в R4. |
| `USE_CGIM_COLOR_TWEAK` | Применяет `CGIMTonemap` в финальном проходе R4 после цветовых поправок и перед LUT. |
| `USE_CGIM_BLOOM_TWEAK` | Применяет `BrokeBloom` в финальном проходе R4, когда выключен `r2_new_bloom_tonemap`. |
| `IBL_FAKE_IRRADANCE` | Подмешивает диффузную карту окружения в зеркальную выборку PBS по шероховатости. Имя в коде пишется `IRRADANCE`. |
| `IBL_REMAP_IRRADANCE` | Переназначает направление выборки диффузного окружения в PBS. |
| `IBL_REMAP_REFLECTIONS` | Переназначает направление выборки зеркальных отражений окружения в PBS. |
| `IBL_REMAP_POSITIVE_Y` | Отражает отрицательные направления Y в положительную полусферу при зеркальной выборке. |
| `IBL_MAX_LOD` | Задаёт множитель для выбора mip-уровня окружения по шероховатости. |
| `USE_FULL_SKY_SPHERE` | Меняет выборку неба и отражения воды для полной текстуры неба в R4. |
| `DISABLE_MOTION_VECTORS` | Отключает векторы движения в R4. Опция считывается при инициализации рендерера. |
| `ALLOW_WBOIT_TRANSPARENCY` | Включает WBOIT в поддерживающих этот режим проходах прозрачности R4. |

Имена из секции также можно использовать в шейдерах мода. Одного добавления имени в LTX достаточно для передачи макроса компилятору. Визуальный результат появится, когда имя будет использовано в шейдере или прочитано кодом рендерера.

## THM override для отдельной текстуры

Файл рядом с THM задаёт макросы для отдельных материалов. Путь, пример и правила приоритета описаны в [THM override](thm-override.md).

## Lua-функции шейдеров R4

Эти функции глобальны в Lua VM рендерера R4, из которой загружаются шейдерные `.lua`-скрипты. В игровых `.script` они недоступны.

| Вызов | Действие |
| --- | --- |
| `GetShaderOption(name)` | Возвращает `boolean`. Проверяет, есть ли ключ в глобальной таблице опций из `engine_external.ltx`. |
| `AddShaderOption(name, value)` | Добавляет макрос со строковым значением в текущий набор макросов рендерера. Вызывайте до компиляции прохода, которому нужен макрос. |
| `ClearAllShaderOptions()` | Очищает текущий набор макросов рендерера. Глобальная таблица `engine_external.ltx` сохраняется. |

```lua
if GetShaderOption("MY_SHADER_TWEAK") then
    AddShaderOption("MY_SHADER_TWEAK", "1")
end
```
