# THM override

> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: 1.4

## Обзор

THM override задаёт макросы шейдера для отдельной базовой текстуры. Движок берёт bump, detail и материал из THM, а макросы загружает из одноимённого LTX. Можно добавить эффект к одному материалу без изменения глобальных настроек рендерера.

## Синтаксис

Для `gamedata/textures/prop/window.dds` и `gamedata/textures/prop/window.thm` создайте файл `gamedata/textures/prop/window.ltx`.

```ini
[shaders_options]
USE_PARRALAX_INTERIOR = 1
```

Загрузчик ищет пары THM и LTX в одном каталоге внутри `$game_textures$` или `$level$`. Поддерживаются THM типов Image, Terrain и Normal Map. Макросы передаются проходам, которые компилируются через `uber_deffer` и используют эту текстуру как базовую. Локальное значение заменяет одноимённое значение, уже добавленное к проходу.

## Примеры

### Интерьер за окном

Укажите `USE_PARRALAX_INTERIOR = 1` для текстуры окна, запустите R4 и откройте сцену, где материал использует HQ-вариант `uber_deffer`. Наличие макроса добавляет интерьерный проход. Для сравнения снимите один ракурс с параметром и после удаления строки, перезапуская игру между прогонами.

### Параллакс через textures.ltx

Старый формат метаданных отдельно поддерживает поле `parallax[yes]` в `[specification]` общего `gamedata/textures/textures.ltx`.

```ini
[specification]
prop\wall = bump_mode[use:prop\wall_bump], material[1.0], parallax[yes]
```

Движок загружает `textures.ltx` до THM. Если для текстуры прочитан подходящий THM, его спецификация заменит запись из `textures.ltx`.

## Рекомендации и ограничения

- Строки без значения пропускаются с записью в лог. Локальное `0` оставляет макрос в наборе. Для `#ifdef` и проверки наличия этого достаточно для активации. Чтобы убрать локальное определение, удалите или закомментируйте строку.
- Глобальные опции, прочитанные движком при инициализации, например `DISABLE_MOTION_VECTORS`, настраиваются в `engine_external.ltx`.
- Запись только в `[association]` может задавать detail-текстуру. Локальным макросам нужен поддерживаемый THM и одноимённый LTX.
- Используйте написание `USE_PARRALAX_INTERIOR` из исходников.
