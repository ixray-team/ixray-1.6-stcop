## Капли дождя в погодном кадре

> **Минимальная версия**: 1.4

Эти опции задаются в секции времени погодного цикла, например `[12:00:00]`. Они читаются отдельно от глобальных параметров области генерации дождя.

| Ключ | Тип и резерв | Действие |
| --- | --- | --- |
| `rain_type` | строка `default` | `drizzle` уменьшает скорость капель, `dense` использует меньший радиус их появления, `spherical` распределяет капли в верхней полусфере. Остальные значения используют обычную схему. |
| `rain_angle` | число `0` | Участвует в расчёте наклона капель вместе с ветром. |
| `rain_angle_rotation` | число `0` | Азимут направления капель в градусах. При чтении переводится в радианы. |
| `rain_length`, `rain_width` | числа `5.0`, `0.3` | Длина и ширина отображаемой полосы капли. |
| `rain_speed_min`, `rain_speed_max` | числа `40.0`, `80.0` | Границы случайной скорости капли. Для `drizzle` нижняя граница умножается на `0.5`, верхняя — на `0.7`. |

Например, допишите в существующую секцию времени:

```ini
rain_type = drizzle
rain_length = 3.0
rain_width = 0.2
rain_speed_min = 40
rain_speed_max = 80
```

Для чтения старых погодных конфигов `env_ambient` задаёт имя секции фоновых звуков, а `thunderbolt` — коллекцию молний. Загрузчик новой схемы использует `ambient` и `thunderbolt_collection`. Если коллекция молний задана, `bolt_period` и `bolt_duration` имеют приоритет над `thunderbolt_period` и `thunderbolt_duration`. Старый `sun_dir` содержит два угла в градусах и используется при отсутствии `sun_altitude`.

## Фоновое окружение

В секции окружения `sound_channels` имеет приоритет над `snd_channels`, а оба ключа — над старым `sounds`. `snd_channels` и `sound_channels` содержат имена секций каналов через запятую. При использовании одного `sounds` параметры канала берутся из самой секции окружения.

`effect_period` задаёт пару интервалов между эффектами в секундах. `min_effect_period` и `max_effect_period` по отдельности заменяют элементы этой пары. В звуковом канале `sound_dist` задаёт пару дистанций, которые можно заменить через `min_distance` и `max_distance`. `sound_period` принимает два или четыре целых интервала в секундах. При двух значениях одна пара используется дважды. Без `sound_period` ключи `period0`, `period1`, `period2`, `period3` читаются в миллисекундах.
