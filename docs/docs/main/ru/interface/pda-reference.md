# Вкладка «Справка» ПДА

## Обзор

Справка собирает статьи сама, из того, что уже есть в конфигах игры: название, описание, иконка, цена и свойства предмета. Писать статью вручную нужно только тогда, когда стандартного описания мало.

Вкладка работает на том же движке, что и [«Записи»](pda-records.md): разделы — это группы, статья — карточка записи. Включается кнопкой с `id="eptReference"` в `pda*.xml`, раскладка задаётся в `pda_reference*.xml`. Ванильная энциклопедия (`eptEncyclopedia`) остаётся отдельной вкладкой и не меняется.

## Что видит игрок

1. Слева разделы: «Артефакты», «Оружие», «Снаряжение», «Мутанты», «Зона». Щелчок по заголовку раздела сворачивает и разворачивает его.
2. В разделах только то, с чем игрок уже сталкивался. Предметы попадают в справку, когда оказываются в инвентаре. Мутант — после первого убийства. Статьи «Зоны» видны сразу или после нужной info-порции.
3. Новая статья подсвечена, пока её не откроют.
4. Карточка: путь вида `#/Артефакты/Медуза`, название, цена справа, описание, иконка предмета и свойства. Плюсы зелёные, минусы красные.

## Что берётся автоматически

| Раздел | Откуда | Свойства |
| --- | --- | --- |
| Артефакты | класс `ARTEFACT`, `SCRPTART` | защита из `hit_absorbation_sect` (с учётом пределов из `actor_condition`), восстановление, переносимый вес |
| Оружие | класс `WP_*` | калибр по первому патрону из `ammo_class`, урон, скорострельность, магазин |
| Снаряжение | класс `E_STLK`, `E_HLMET` | защита `*_protection`, переносимый вес, слоты для артефактов |
| Мутанты | убийства игроком | описание и число убитых |

Для всех предметов: `inv_name`, `description`, иконка из `inv_grid_*`, `cost`, `inv_weight`.

## Своя статья

Секция `pda_reference_<секция предмета>` дополняет автостатью: текст добавляется после свойств, картинка показывается сверху карточки.

```ini
[pda_reference_af_medusa]
text = st_ref_af_medusa_long
image = ui\reference\medusa
```

Для мутантов секция называется `pda_reference_mon_<вид>`.

Статьи без предмета перечисляются в `[pda_reference_articles]`, каждая описывается своей секцией:

```ini
[pda_reference_articles]
my_article

[pda_reference_my_article]
group = zone
name = st_my_article
text = st_my_article_text
image = ui\my_mod\picture
icon = ui_my_icon
info = my_info_portion
```

`group` — раздел, по умолчанию `zone`. С `info` статья появится после получения этой info-порции.

Порядок разделов задаёт `groups` в `[pda_reference]`. Иконки мутантов — секция `[pda_reference_mutants]`: `вид = текстура`.

## pda_reference.xml

Устроен как `pda_records.xml`, без вкладок категорий: `main_wnd` задаёт `category="reference"`. Что важно для справки:

| Узел | Атрибут | Что делает |
| --- | --- | --- |
| `group_header` | `collapsible`, `prefix_open`, `prefix_closed` | Сворачиваемые разделы и метки `[-]` / `[+]` |
| `record_item:icon`, `details:icon` | `keep_aspect` | Иконка вписывается в рамку с сохранением пропорций |
| `details:icon` | `push_body="0"` | Иконка не сдвигает текст вниз и стоит сбоку |
| `details` | `auto_heading="0"` | Заголовок не добавляется сам: провайдер ставит путь и заголовок строками `path` и `heading` |
| `details:subtitle` | | Цена в правом верхнем углу |

Стили строк в HD HUD: `path`, `heading`, `text`, `stat`, `caption`, `hint`, `info`.

## Ограничения

1. Предметы, которые игрок видел только у торговца или на земле, в справку не попадают, пока не окажутся в инвентаре.
2. При первом открытии справки со старым сохранением в неё попадает текущий инвентарь, без отметки «новое». Убитые раньше мутанты не учитываются.
3. Свойства оружия упрощены: урон — первое значение `hit_power` × 100.
4. Свёрнутые разделы не сохраняются между сессиями.

## Проверка после сборки

1. Вкладка «Справка» открывается, без кнопки `eptReference` ПДА выглядит как раньше.
2. Подобранный артефакт появляется в «Артефактах» с отметкой «новое», в карточке путь, цена, иконка без растяжения и свойства с цветом.
3. Щелчок по заголовку раздела сворачивает его, повторный — разворачивает.
4. После убийства мутанта он появляется в «Мутантах» с числом убитых.
5. Статья с секцией `pda_reference_<предмет>` показывает дополнительный текст и картинку.
6. Статьи «Зоны» видны сразу.
