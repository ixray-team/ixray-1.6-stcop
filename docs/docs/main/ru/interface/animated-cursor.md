# Анимированный курсор и состояния SEQ

## Обзор

Начиная с версии 1.5, UI-курсор можно настраивать через секцию `[ui_cursor]` в `configs/system.ltx`: независимо задавать область исходной текстуры и размер её отображения, включать растяжение, смещать изображение относительно точки клика и связывать действия с именованными секциями `.seq`.

Без `[ui_cursor]` или при `enabled = false` сохраняется оригинальное поведение из `configs/ui/backend/cursor.xml`. Новые параметры относятся к двумерному курсору интерфейса. Секция `[hud_cursor]`, используемая экранным прицелом, не изменяется.

Механизм именованных секций SEQ общий: его можно использовать для других анимированных текстур через C++ и Lua. Полное описание: [именованные секции текстурных SEQ](../scripting/texture-sequence-sections.md).

## Подключение через DLTX

Создайте `configs/mod_system__dd_cursor.ltx` внутри аддона. Обычный заголовок `[ui_cursor]` добавляет новую секцию в итоговый `system.ltx`; для переопределения уже существующей секции другим DLTX-файлом используйте `![ui_cursor]`.

```ini
[ui_cursor]
enabled = true
cursor_texture = ui\ui_ani_cursor

cursor_source_texture_size = 256, 256
cursor_target_size = 64, 64
stretch_cursor_texture = true
cursor_hotspot_offset = 0, 0

drag_enabled = true
drag_section = cursor_grab
drag_hold_delay = 1000
drop_enabled = true
drop_section = cursor_release
scroll_drag_enabled = true
scroll_drag_section = cursor_scroll_grab
scroll_drop_enabled = true
scroll_drop_section = cursor_scroll_release

click_lmb_enabled = true
click_lmb_section = cursor_click_lmb
click_rmb_enabled = true
click_rmb_section = cursor_click_rmb

context_enabled = true
context_section = cursor_context_menu

scroll_up_enabled = true
scroll_up_section = cursor_scroll_up
scroll_down_enabled = true
scroll_down_section = cursor_scroll_down

select_enabled = true
select_section = cursor_select
clickable_enabled = true
clickable_section = cursor_clickable
hover_slot_drop_enabled = true
hover_slot_drop_section = cursor_hover_slot_drop

idle_enabled = true
idle_section = cursor_idle_stretch
idle_interval = 15000, 35000
```

Это пример с включёнными поведениями. Указанные секции и их текстуры необходимо подготовить в рабочем `.seq`. Имена `cursor_*` приведены для примера: соответствие действия и секции читается из конфига, а не зашито в коде. Для анимаций других подсистем выбирайте собственные префиксы.

Конфиг читается при создании курсора из уже загруженного `system.ltx`. Для применения изменений LTX нужен перезапуск игры.

## Изображение и размер

| Параметр | Значение при отсутствии ключа | Назначение |
| --- | --- | --- |
| `enabled` | `false` | Общий выключатель всех переопределений и поведений курсора. |
| `cursor_texture` | Путь из XML | Имя ресурса без расширения относительно `textures`, например `ui\my_cursor`. Загрузчик использует одноимённый `.seq`, если он существует, иначе обычную текстуру. Пустое значение сохраняет путь из XML; шейдер сохраняется из XML. |
| `cursor_source_texture_size` | `0, 0` | Ширина и высота используемой области кадра в пикселях исходной текстуры. Начало области сохраняется из XML. |
| `cursor_target_size` | `0, 0` | Размер окна курсора в UI-единицах до штатной коррекции соотношения сторон. |
| `stretch_cursor_texture` | Значение `stretch` из XML | Масштабирование области текстуры в окно курсора. |
| `cursor_hotspot_offset` | `0, 0` | Точка внутри исходного кадра, совмещаемая с позицией мыши с учётом исходного смещения текстуры из XML. Координаты задаются в пикселях исходной текстуры. |

Пара размера с нулевым, отрицательным или не конечным компонентом не переопределяет соответствующий размер XML. В исходном `cursor.xml` используются окно 40×40 и область текстуры 45×45. Большая текстура может обрезаться именно этой областью, если не задать новое разрешение.

При `cursor_source_texture_size = 256, 256`, `cursor_target_size = 64, 64` и `stretch_cursor_texture = true` вся заданная область кадра уменьшается в окно 64×64 UI-единицы. Это не гарантирует ровно 64 физических пикселя при любом разрешении экрана: сохраняется штатное масштабирование UI. Для исходников 128×128 поменяйте только `cursor_source_texture_size`.

При `stretch_cursor_texture = false` текстура отображается в собственном размере: уменьшение `cursor_target_size` само по себе не уменьшает изображение.

`cursor_hotspot_offset` сдвигает только отрисовку текстуры. Координаты мыши, окно курсора, определение предмета под ним и точка клика остаются на прежнем месте. Например, для круга 256×256 задайте `128, 128`: при масштабировании в 64×64 смещение составит половину отображаемого размера по каждой оси. Значение `0, 0` сохраняет привязку к верхнему левому углу. Настройка не применяется к трёхмерной модели курсора.

Все кадры одной последовательности должны иметь согласованные размеры, формат и положение опорной точки. При уменьшении 256→64 мелкие детали теряются; проверяйте читаемость силуэта в конечном размере.

## Действия и состояния

Для каждого действия используются два ключа: `<action>_enabled` включает поведение, `<action>_section` задаёт имя секции SEQ. Если ключ включения отсутствует, поведение выключено. Если имя секции пустое, анимация не запускается.

| Действие | Префикс ключей | Когда применяется |
| --- | --- | --- |
| Захват | `drag` | Создан drag-объект предмета. |
| Отпускание | `drop` | Drag-объект уничтожен после отпускания или отмены переноса. |
| ЛКМ | `click_lmb` | Нажатие ЛКМ; состояние снимается при отпускании кнопки. |
| ПКМ | `click_rmb` | Нажатие ПКМ; состояние снимается при отпускании кнопки. |
| Контекстное меню | `context` | Открыт стандартный `CUIPropertiesBox` или его подменю. |
| Колесо вверх | `scroll_up` | Положительное направление прокрутки в интерфейсе. |
| Колесо вниз | `scroll_down` | Отрицательное направление прокрутки в интерфейсе. |
| Предмет | `select` | Предмет в ячейке либо занятый слот по всей его области, независимо от размера иконки. |
| Готовность отпустить | `hover_slot_drop` | Во время drag проверена допустимая цель размещения, замены или взаимодействия. |
| Разминка | `idle` | Истёк интервал без ввода; drag и контекстное меню не активны. Наведение на предмет/слот не мешает. |

Фактический drag отслеживается по созданию и уничтожению `CUIDragItem`. Дополнительно удержание ЛКМ на том же предмете в течение `drag_hold_delay` миллисекунд включает визуальный захват без движения мыши; по умолчанию 1000, значение 0 отключает этот способ. Визуальный захват сам не создаёт drag-объект и не перемещает предмет. При отпускании он также проигрывает отпускание. Наведение вычисляется по ячейкам после обновления списков и применяется один раз перед отрисовкой курсора; регистрация Lua-колбэков `OnItemFocusReceive`, `OnItemFocusLost` или `OnItemDropped` для работы курсора не требуется.

Стандартные слоты и предметы обслуживаются через `CUIDragDropListEx`. Для одиночного слота используется весь прямоугольник окна, включая поля вокруг иконки; занятый слот целиком считается предметом. В обычных сетках используются логические ячейки, без проверки прозрачности текстуры. Пустое место рюкзака без drag оставляет исходный курсор.

`DRP` требует допустимой цели: свободное место с достаточной площадью под предмет, совместимый слот (включая замену), штатное взаимодействие или связь из `highlight_related_sections` переносимого предмета с секцией цели. Поддержаны переносы между инвентарём, тайником и трупом с проверкой типов списков и доступных нативных ограничений. Сам переносимый предмет, его исходная позиция без перемещения и несовместимая занятая ячейка не дают `DRP`. Проверка не вызывает обработчик фактического drop, установку аддона/фильтра или перемещение предмета.

Для штатных взаимодействий проверяются установка аддонов, допустимое объединение стеков, фильтры и элементы питания. `highlight_related_sections` используется из уже загруженного списка, в том же направлении, что и подсветка: переносимый предмет перечисляет секции целей. Такая запись декларирует визуальную готовность, но сама не реализует игровое действие. Произвольный Lua-обработчик всё ещё может отклонить перенос при отпускании; вызывать его с побочными эффектами на каждом наведении нельзя. Нестандартный UI может задать свою нативную `CursorDropQuery` или управлять секциями через общий Lua API.

Приоритет обычных состояний: контекстное меню → отпускание → прокрутка → клик → готовность отпустить → захват → предмет → default. Разминка временно перекрывает обычное наведение после периода без ввода; drag и контекстное меню блокируют её запуск. Когда временное состояние заканчивается, контроллер выбирает актуальное состояние под ним. Переход от захвата к готовности отпустить ожидает завершения захвата. Скрытие курсора снимает его активное состояние.

После завершения отпускания выбирается текущее состояние, без обязательного промежуточного default: отмена переноса над несовместимым предметом даёт отпускание → наведение на предмет. Открытие контекстного меню немедленно прерывает отпускание; закрытие меню выбирает актуальное состояние, не возобновляя старое отпускание. Новый клик или новый drag также прерывает прежнее отпускание. Default выбирается только тогда, когда нет подходящего активного состояния. Это выбор анимаций, без смешивания изображений через прозрачность.

Прокрутка, отпускание и разминка используют длительность загруженной цепочки SEQ. Если длительность определить не удалось, контроллер использует одну секунду; для этих эффектов рекомендуется конечная цепочка с `next = default`. Повторный сигнал уже активного временного эффекта не перезапускает секцию и не продлевает её срок.

Выбор разделён на `select` (предметы и занятые слоты, тестовый код `SEL`) и `clickable` (доступные UI-кнопки и элементы с зарегистрированным кликом, код `CLC`). У каждого состояния свои `_enabled` и `_section`.

При наведении учитываются верхний модальный диалог, окна поверх активного диалога, порядок отрисовки дочерних окон, видимость и доступность. Перекрытый предмет или слот не включает `SEL` или `DRP`. При переносе предмета захват мыши drag-объектом не мешает проверке видимых целей. Захват ползунка прокрутки включает отдельное состояние `scroll_drag` (`cursor_scroll_grab`, код `SGR`); отпускание — `scroll_drop` (`cursor_scroll_release`, код `SRL`), затем актуальное состояние. У обоих состояний собственные флажки включения. Они не используют анимации захвата и отпускания инвентарного предмета. Этот захват не является переносом инвентарного предмета и сам не даёт `DRP`.

Пустой слот без переносимого предмета оставляет default, как и пустая сетка рюкзака. Отдельного состояния `hover_slot` нет. Во время переноса допустимая цель включает `DRP`, недопустимая сохраняет `GRB`. После отпускания над пустым слотом анимация отпускания завершается в default.

## Альтернативные курсоры из Lua

Начиная с версии 1.5, `set_cursor_texture("ui\\computer_cursor")` подменяет текстуру и одноимённый SEQ, сохраняя настройки размера, растяжения, hotspot и действий. `reset_cursor_texture()` возвращает текстуру конфига либо XML. `pause_cursor_sections(true)` освобождает автоматическую секцию для ручного управления; `pause_cursor_sections(false)` возвращает выбор по актуальной ситуации. Пауза не останавливает воспроизведение кадров. Пример карандаша для карты и правила очистки ручных состояний: [Lua API](../scripting/new-functions.md#текстура-курсора-и-управление-автоматическими-секциями).

При нескольких активных секциях общего реестра выше приоритет у секции, расположенной выше в SEQ. Это отдельно от приоритетов действий контроллера курсора: сам контроллер активирует только одно выбранное имя.

## Случайная разминка

`idle_interval` задаёт минимальный и максимальный интервал в миллисекундах, обе границы включены. При `15000, 35000` выбирается задержка от 15 до 35 секунд. Неподвижное наведение на предмет (`SEL`) или пустой слот (default) не блокирует разминку. Её запуск блокируют только drag и открытое контекстное меню. После завершения восстанавливается актуальное состояние наведения и выбирается новый интервал ожидания. Движение мыши, нажатие кнопки или другой обрабатываемый ввод сбрасывают ожидание и прерывают уже запущенную разминку.

Значение по умолчанию — `15000, 35000`. Минимум ограничивается диапазоном от 1 до 1 000 000 000 мс, максимум — от полученного минимума до 1 000 000 000 мс. Для отключения только разминки достаточно `idle_enabled = false`.

## Секции SEQ

Исходная часть файла остаётся прежней: необязательное `cycled`, затем FPS и список текстур. Новая секция начинается с заголовка `[имя]`; только внутри секций длительности задаются в миллисекундах.

```ini
60
ui\cursor\idle_1
ui\cursor\idle_2

[cursor_grab]
frames = ui\cursor\grab_{1..24}, 80

[cursor_release]
frames = ui\cursor\release_{1..16}, 60
next = default

[cursor_idle_stretch]
frame = ui\cursor\stretch_1, 180
frames = ui\cursor\stretch_{2..12}, 80
next = default
```

`{1..24}` разворачивается в обычные номера от 1 до 24 включительно, без дополнения нулями. Последнее число после запятой — длительность каждого кадра. Необязательный шаг: `{0..20..2}`. Строки `frame` и `frames` можно смешивать и повторять.

Без `next` последний кадр секции удерживается до внешней команды. `next = default` возвращает исходную последовательность; `next = имя` переходит к указанной секции. Ссылка секции на саму себя создаёт цикл. Деактивация не воспроизводит кадры в обратном порядке: анимированный выход описывается отдельной секцией, например `cursor_release`.

Рабочий `.seq` должен иметь имя ресурса, используемого курсором: например, `textures/ui/ui_ani_cursor.seq` для `cursor_texture = ui\ui_ani_cursor`. Если ключ отсутствует или пустой, используется имя из XML. Текстуры из примера нужно подготовить отдельно. Файл с расширением `.seq.example` является только шаблоном.

## Управление из Lua и C++

```lua
activate_seq_section("cursor_grab")
activate_seq_section("cursor_release", true) -- дождаться текущего прохода
deactivate_seq_section("cursor_grab")

-- Немедленный повторный запуск:
activate_seq_section("cursor_scroll_up", false, true)
```

```cpp
bool ActivateSequenceSection(const char* Name, bool WaitForEnd = false, bool Restart = false);
bool DeactivateSequenceSection(const char* Name, bool WaitForEnd = false);
```

Методы действуют на все анимации, содержащие указанную секцию. Другие анимации игнорируют имя. Реестр хранит активные имена; из активных выбирается секция, объявленная выше остальных в SEQ. После деактивации выбирается следующая по приоритету активная секция или `default`. Новая загруженная текстура подхватывает уже активное состояние.

`WaitForEnd = false` переключает сразу; `true` — после текущего прохода. Уже удерживаемый последний кадр считается завершённым проходом. Повторная активация без `Restart` не перезапускает секцию; `Restart = true` запускает её заново. Возвращаемое значение сообщает об изменении реестра, а не о наличии секции в конкретной текстуре.

`next = default` завершает визуальное воспроизведение, но не удаляет имя из общего реестра: другие текстуры могут иметь другую длительность. Состояние снимает его владелец через деактивацию. Объекты, использующие один ресурс текстуры, разделяют состояние воспроизведения.

## Загрузка и производительность

Файл `.seq` читается один раз при загрузке текстуры. Секции, диапазоны и тайминги сохраняются в памяти; активация, деактивация и воспроизведение не перечитывают файл. Повторное чтение происходит только после выгрузки и новой загрузки ресурса.

Выбор активной секции пересчитывается по команде или при регистрации ресурса. В кадре проверяется наличие новой команды и выбирается изображение по прошедшим миллисекундам с сохранением остатка времени. При просадках FPS промежуточные изображения могут пропускаться, но движение не растягивается по длительности.

Уникальные изображения всех секций загружаются вместе с последовательностью; одинаковые пути внутри файла используются повторно. Выключатель отдельного поведения не освобождает текстуры секций, уже записанных в `.seq`. Подготавливайте размер и сжатие кадров с учётом памяти.

Старые файлы без секций сохраняют прежнее воспроизведение. Расширенные файлы требуют движка с поддержкой версии 1.5: старый загрузчик будет воспринимать строки секций как имена текстур.

Раздельные состояния:

| Событие | Ключ конфига | Секция SEQ | Тест |
| --- | --- | --- | --- |
| Выбор предмета / занятого слота | `select` | `cursor_select` | SEL |
| Выбор доступной UI-кнопки | `clickable` | `cursor_clickable` | CLC |
| Захват ползунка прокрутки | `scroll_drag` | `cursor_scroll_grab` | SGR |
| Отпускание ползунка | `scroll_drop` | `cursor_scroll_release` | SRL |

Для каждого ключа задаются `_enabled` и `_section`. Захват/отпускание предметов по-прежнему используют `drag`/`drop` (GRB/REL). Разминка блокируется обоими видами захвата.

Каждое событие имеет собственные `_enabled` и `_section`. Можно назначить нескольким событиям одно имя SEQ: переход между ними не перезапускает уже выбранную секцию. Значение `_section = default` выбирает исходные кадры вне секций и подавляет нижестоящие автоматические состояния на время этого события; `_enabled = false` отключает участие события в выборе. Повторный сигнал активного временного эффекта или событие с тем же именем секции сохраняет текущие кадры и исходный срок завершения.

`CLC` определяется не только классом `CUIButton`: обычный UI-элемент с зарегистрированным обработчиком клика также использует `clickable_section`. Учитываются `AddSelfCallback`, скриптовый `AddCallback` диалога и нативный `CUIWndCallback`, включая регистрацию по имени элемента. События: `BUTTON_CLICKED`, `STATIC_MOUSE_LEFT_CLICK`, `STATIC_MOUSE_RIGHT_CLICK`, `STATIC_MOUSE_DOUBLE_CLICK`, `LIST_ITEM_CLICKED`. Регистрация движения, колеса или обновления без клика не включает CLC. Обработчик при наведении не вызывается. Скрытые, недоступные и перекрытые элементы не выбираются.

Подсветка и индикаторы состояния стандартных слотов — декоративные окна, исключённые из проверки перекрытия курсора отдельным признаком SetCursorPickTransparent. Этот признак сохраняется после Show(true), который повторно включает обычный флаг Enabled. Они не перекрывают выбор предмета. Проверка: занятые слоты брони, шлема, оружия и детектора должны давать SEL по всей ячейке, включая центр и края, даже при включённой подсветке. Окно количества/другой диалог поверх этих слотов по-прежнему блокирует SEL и DRP.

### Повторение секций

`loop = true` повторяет кадры секции по кругу. `loop = false` (по умолчанию) проигрывает один проход: без `next` удерживает последний кадр, с `next` переходит в указанную секцию. `loop = true` нельзя сочетать с переходом в другую секцию или default. Старый способ `next = имя_этой_же_секции` также создаёт цикл. Исходный блок вне секций не изменён.

```ini
[cursor_select]
loop = true
frames = ui\hand_select_{1..4}, 120

[cursor_grab]
loop = false
frames = ui\hand_grab_{1..8}, 80

[cursor_release]
loop = false
frames = ui\hand_release_{1..8}, 80
next = default
```

Движок выбирает активную секцию по событиям, а её повторение задаёт SEQ. Захват может удерживать последний кадр до отпускания; смена события может прервать секцию. Конечные временные эффекты курсора по завершении возвращают актуальное состояние. Циклические временные эффекты не обрываются таймером через секунду: они продолжаются до нового ввода/события. Ручные секции снимает вызывающий скрипт. В цветовом стенде loop=false указан явно; для проверки повторения можно изменить нужную секцию на loop=true, убрав next=default, и перезапустить игру.

Дополнительные slot_dragdrop из actor_menu.xml и actor_menu_16.xml используют общий выбор SEL/DRP. Количество определяется XML в пределах LAST_SLOT, без отдельного списка номеров в курсоре. Декоративная панель actor_state_info не перекрывает выбор слотов. Проверка: занятый дополнительный слот даёт SEL по всей области, пустой — DEF, допустимая цель переноса — DRP. Настоящий диалог поверх продолжает блокировать наведение.
