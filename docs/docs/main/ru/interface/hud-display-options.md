# Контекстный HUD и экран паузы

> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: 1.4

## Обзор

Контекстный HUD показывает здоровье и выносливость при изменении этих показателей, а блок оружия — при смене оружия, стрельбе, перезарядке или изменении боезапаса и режима огня. Скорости появления и исчезновения задаются в XML. Оформление экрана паузы лежит в отдельном XML.

## Синтаксис

Включите контекстный режим командой `hud_contextual_status 1`. Настройки виджета добавляются внутрь существующего узла `hud_states` в `gamedata/configs/ui/maingame.xml` или его версии для текущего соотношения сторон.

```xml
<contextual_display show_speed="4" hide_speed="3"
                    hide_delay="2.5" health_threshold="0.002"/>
```

| Атрибут | По умолчанию | Действие |
| --- | --- | --- |
| `show_speed` | `4` | Скорость роста непрозрачности в секунду. Минимум `0.1`. |
| `hide_speed` | `3` | Скорость падения непрозрачности в секунду. Минимум `0.1`. |
| `hide_delay` | `2.5` | Задержка в секундах после последнего события блока. Минимум `0.1`. |
| `health_threshold` | `0.002` | Величина изменения здоровья или выносливости, которую нужно превысить, чтобы показать блок. |

Без `contextual_display` применяются значения из таблицы. Команда `hud_contextual_status 0` возвращает обычное отображение. Контекстный режим также включает автоскрытие панели быстрых слотов.

## Примеры

### Изменить оформление паузы

Откройте `gamedata/configs/ui/backend/pause.xml` и измените `pause_static`. Ниже вариант с белым текстом поверх экрана.

```xml
<w>
    <pause_static x="0" y="0" width="1024" height="768">
        <text font="graffiti50" r="255" g="255" b="255" a="220"
              align="c" vert_align="c">st_game_paused</text>
    </pause_static>
</w>
```

Размеры задаются в координатах UI. Если файл не загрузился, HUD рисует стандартную надпись. Главное меню и некоторые туториалы могут скрывать индикатор паузы.
