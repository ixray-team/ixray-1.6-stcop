# Вкладка «Записи» ПДА

## Обзор

Вкладка для сведений, которые игрок хочет помнить: наводки на тайники, разговоры, достижения, заметки и любые категории модов. Сверху категории, слева список записей с группами, справа карточка с картинкой, текстом и кнопками.

Движок только рисует записи. Данные отдаёт Lua: каждая категория — это провайдер, который при открытии вкладки заполняет список. Записи модов можно хранить готовым API, формат сейва при этом не меняется.

Вкладка включается кнопкой с `id="eptRecords"` в `pda*.xml`. Если кнопки нет, окно не создаётся. Раскладка задаётся в `pda_records*.xml`.

## Что видит игрок

1. Категории с числом новых записей, переключаются A и D.
2. Список с группами, отметкой новых записей и прицелом для записей с целью на карте.
3. Карточка: картинка, заголовок, строки текста разных стилей, кнопки «Показать на карте», «Отслеживать» и кнопка действия, если её задал мод.
4. «Отслеживать» ставит на цель личную метку с названием записи и включает на неё навигацию. Если метка на этом месте уже есть, используется она.
5. Выбор записи снимает отметку «новая».

## Управление

| Действие | По умолчанию | Геймпад | Что делает |
| --- | --- | --- | --- |
| `pda_records_category_prev` | A | крестовина влево | Предыдущая категория |
| `pda_records_category_next` | D | крестовина вправо | Следующая категория |
| `pda_records_prev` | ↑ | крестовина вверх | Предыдущая запись |
| `pda_records_next` | ↓ | крестовина вниз | Следующая запись |
| `pda_records_show_on_map` | M | X | Показать на карте |
| `pda_records_track` | F | Y | Отслеживать |
| `pda_records_action` | E | A | Действие мода |

Своя группа конфликтов, как у вкладки заданий. Alt+Q / Alt+E и курки тоже переключают категории. Бинды по умолчанию: `configs/ixray_settings/mod_default_controls_*.ltx`, группа в настройках: `mod_ui_keybinding_*.xml`.

## Lua API

### Хранимые записи

Модуль `pda_records` хранит записи в данных актора, моду не нужен свой save/load.

```lua
pda_records.add("my_mod.note_01", {
	category = "notes",
	title = "st_my_note_title",
	subtitle = "st_my_note_short",
	icon = "ui_my_note_icon",
	image = "ui\\my_mod\\note_01",
	group = "jupiter",
	group_caption = "st_my_group_jupiter",
	level = "jupiter",
	map_level = "jupiter",
	position = vector():set(100, 0, 200),
	trackable = true,
	lines = {
		{"hint", "st_my_note_hint"},
		{"text", "st_my_note_text"},
	},
	action = "read",
	action_caption = "st_my_note_read",
	callback = "my_mod.on_note_action",
})

pda_records.update("my_mod.note_01", {state = "done", subtitle = "st_my_note_done"})
pda_records.set_new("my_mod.note_01", true)
pda_records.remove("my_mod.note_01")
pda_records.exists("my_mod.note_01")
local record = pda_records.get("my_mod.note_01")
```

| Поле | Что это |
| --- | --- |
| `category` | Id категории, как у кнопки в `category_tabs`. По умолчанию `notes`. |
| `title`, `subtitle` | Заголовок и короткая подпись в строке списка. Можно id строки. |
| `icon`, `image` | Иконка строки и картинка карточки. |
| `state` | Произвольное состояние. Цвет названия берётся из `record_item:colors:<state>`. |
| `group`, `group_caption` | Ключ группы и её заголовок. Записи одной группы идут подряд. |
| `level` | Уровень записи, по нему ищется картинка экрана загрузки. |
| `map_level`, `position`, `trackable` | Цель на карте. С `trackable = true` доступна кнопка «Отслеживать». |
| `lines` | Строки карточки: пары `{стиль, текст}`. |
| `action`, `action_caption`, `callback` | Кнопка действия. При нажатии вызывается `callback(id, action)`. |
| `new` | Отметка новой записи, по умолчанию `true`. |
| `time` | Время в игровых минутах от начала игры, по умолчанию текущее. Новые записи выше. |

Хранимые записи сортируются по группе, затем от новых к старым.

### Провайдеры

Провайдер собирает записи из живых данных игры при каждом обновлении вкладки. Ничего не хранит, поэтому подходит для того, что уже есть в игре: тайники, задания, статистика.

```lua
function collect(list)
	local entry = list:add("my_mod.item_01")
	entry:set_title("st_my_title")
	entry:set_subtitle("st_my_state")
	entry:set_state("known")
	entry:set_icon("ui_my_icon")
	entry:set_image("ui\\my_mod\\picture")
	entry:set_group("zaton", "st_my_group_zaton")
	entry:set_level("zaton")
	entry:set_new(true)
	entry:set_map("zaton", vector():set(100, 0, 200))
	entry:set_trackable(true)
	entry:add_line("text", "st_my_text")
	entry:set_action("open", "st_my_open")
end

function on_select(id)
end

function on_action(id, action)
end

function on_game_start()
	pda_records.register_provider("my_category", {collect = collect, on_select = on_select, on_action = on_action})
end
```

Записи идут в том порядке, в каком их добавил провайдер. Хранимые записи той же категории добавляются после них. `pda_records_talk_partner()` возвращает id собеседника актора, если идёт разговор, иначе 65535.

Прочие методы записи:

| Метод | Что делает |
| --- | --- |
| `set_icon_rect(x, y, w, h)` | Участок текстуры иконки, например портрет из атласа. |
| `set_time(minutes)`, `time()` | Время записи в игровых минутах от начала игры. Входит в хэш, поэтому смена времени перерисовывает вкладку. |
| `id()` | Id записи. |
| `set_scroll_end(true)` | Карточка открывается прокрученной в конец. |
| `set_item_icon(section)` | Иконка предмета из его секции (`inv_grid_*`, `icons_texture`). |
| `set_image("none")` | Карточка без картинки. Если у записи есть иконка, вместо картинки показывается узел `details:icon`. |

`list:get(index)` возвращает запись по индексу от 0, `list:count()` — их число. `pda_records_fill_contacts(list, max_lines)` добавляет в список карточки контактов (см. ниже), `max_lines` ограничивает число реплик в карточке, 0 — без ограничения.

## pda_records.xml

| Узел | Что это |
| --- | --- |
| `main_wnd` | Окно. `provider`, `on_select`, `on_action` задают Lua-функции, по умолчанию из `pda_records`. `refresh_ms` — частота обновления, по умолчанию 2000. Вложенные `auto_static`, `auto_frameline` служат оформлением. |
| `category_tabs` | Кнопки категорий, `id` кнопки — id категории. `counters="1"` дописывает число новых записей. Без узла вкладка показывает одну категорию из атрибута `category` у `main_wnd`. |
| `category_hint_prev`, `category_hint_next`, `hotkeys_hint` | Полосы подсказок клавиш. |
| `record_list` | Список. |
| `group_header` | Заголовок группы. Без узла групп нет. С `collapsible="1"` группа сворачивается щелчком, `prefix_open` и `prefix_closed` добавляют метку перед заголовком. |
| `record_item` | Строка: `selection`, `new_mark`, `icon`, `title`, `subtitle`, `btn_focus`, цвета `colors:<state>`, `colors:new`, `colors:normal`. |
| `t_empty` | Пустой список: `text` и `text_<категория>`. |
| `details` | Карточка. |

Карточка: `empty`, `image` (с `crop_rect`), `icon` (портрет для записей без картинки, `gap` — отступ до тела), необязательные `title` и `subtitle`, `body`, атрибуты иконки `keep_aspect` (сохранять пропорции) и `push_body="0"` (не сдвигать тело), атрибут `auto_heading="0"` у `details` (не добавлять заголовок строкой), кнопки `btn_map`, `btn_track`, `btn_action` с плашкой клавиши `hint` внутри. Атрибуты `image_level_intro` и `image_default` работают как во вкладке заданий. Если узла `title` нет, заголовок выводится первой строкой тела по шаблону `line_heading` и двигается вместе с телом.

Строки тела рисуются по шаблонам `line_<стиль>`, неизвестный стиль берёт `line_text`. В HD HUD есть `heading`, `text`, `hint`, `info`, `status`, `caption`, `item`, а для контактов `day`, `npc`, `actor`.

Узлы `record_item:icon_<категория>` и `details:icon_<категория>` задают для одной категории свои позицию и размер иконки строки и портрета в карточке (`x`, `y`, `width`, `height`). Остальные настройки берутся из узла `icon`. В HD HUD так сделано для `achievements`: иконки достижений вертикальные.

## Контакты

Категория `contacts` собирается из истории диалогов, которую игра уже хранит для окна разговора. Новых данных в сейве нет, кроме отметок «прочитано».

1. Одна запись на собеседника: портрет, имя, время последнего разговора. Сегодняшние разговоры показывают время, более ранние — день.
2. Группы по дням последнего разговора, свежие сверху.
3. Карточка: портрет, «Последний разговор: День N, ЧЧ:ММ», затем реплики по порядку с разделителями дней. Реплики собеседника и игрока разного цвета. Карточка открывается на последней реплике.
4. Реплика игрока относится к собеседнику, который ответил следующим. Перерыв больше 5 игровых минут начинает новый разговор.
5. Собеседник с новыми репликами после последнего просмотра отмечается как новый. При первом запуске с установленным модом все контакты считаются прочитанными.
6. В карточке последние 150 реплик, число задаётся `MAX_LINES` в `pda_records_contacts.script`.

## Достижения

Категория `achievements` в HD HUD строится по секции `achievements` в `system.ltx`: название, иконка, описание и награда берутся оттуда. Провайдер раз в 5 секунд опрашивает условия достижений, поэтому они выдаются и без отдельной вкладки статистики.

1. Группы: «В работе», «Получено», «Не начато», «Путь закрыт», в каждой число достижений. Полученные идут от новых к старым.
2. Строка: иконка, название, справа прогресс вида `2/3`, «получено» или «закрыто».
3. Карточка: иконка, название, состояние (прогресс, время получения или «Путь закрыт»), цель и награда. Награда скрыта, пока не сделан первый шаг.
4. Время получения запоминается с этой версии. Достижения, полученные раньше, помечены «Получено раньше, чем был установлен журнал».
5. Новое полученное достижение отмечено как новое, пока карточку не откроют.

## Тайники

Категория `stashes` в HD HUD собирается из ванильного `treasure_manager`, сам он не меняется:

1. Название: ближайшее именованное место из `smart_names`, например «Тайник: Скадовск».
2. Наводка: расстояние и направление от этого места, например «Скадовск — около 120 м на северо-восток».
3. Источник: имя собеседника в момент выдачи наводки или «Координаты из КПК», со временем. Для наводок из старых сохранений: «Координаты получены ранее».
4. Состояние: новая, не вскрыт, частично, опустошён, пусто (здесь кто-то побывал раньше), устарела (тайник снова закрылся).
5. После вскрытия карточка показывает, что было внутри.
6. Группы по локациям со счётчиком «найдено X из Y известных».

Свои данные для отдельного тайника задаются секцией `pda_records_stash_<id тайника>`:

```ini
[pda_records_stash_zat_hiding_place_7]
place = st_my_place_name
hint  = st_my_stash_hint
image = ui\my_mod\stash_photo_07
```

## Ограничения

1. Записи модов хранятся в данных актора и переживают сохранения, но не переносятся между прохождениями.
2. «Отслеживать» создаёт личную метку, поэтому подчиняется лимиту личных меток.
3. Провайдер вызывается при каждом обновлении, поэтому он должен работать быстро.
4. Наводки, выданные до установки, показываются без источника и без найденных предметов.
5. Контакты видят только то, что осталось в истории диалогов: её объём ограничен игрой, старые реплики со временем пропадают. Системные сообщения разговора (передача предметов и т. п.) не попадают в карточку.
6. Собеседники с одинаковым именем и портретом объединяются в один контакт.
7. Для достижений, полученных до этой версии, время получения неизвестно.
8. В HD HUD нет вкладки `notes`. Записи с этой категорией, в том числе записи `pda_records.add` без поля `category`, не видны, пока мод не добавит кнопку с `id="notes"` в `category_tabs`.

## Проверка после сборки

1. Без кнопки `eptRecords` ПДА выглядит как раньше.
2. Вкладка «Записи» открывается, A и D переключают «Тайники», «Контакты» и «Достижения».
3. Новая наводка на тайник появляется в категории со счётчиком, источником и наводкой-направлением.
4. M открывает карту на тайнике, F ставит метку и включает навигацию.
5. После вскрытия тайника карточка показывает найденные предметы, а группа — обновлённый счётчик.
6. Запись, добавленная через `pda_records.add`, появляется в своей категории и сохраняется.
7. Действия видны в настройках управления в группе «ПДА: записи».
8. После разговора с NPC в «Контактах» появляется его портрет с отметкой новой записи, карточка открыта на последней реплике, реплики игрока подписаны «Вы».
9. Повторный разговор с тем же NPC в другой день добавляет разделитель дня, контакт поднимается наверх списка.
10. «Достижения» показывают группы со счётчиками, иконки не растянуты ни в строке, ни в карточке.
11. Только что полученное достижение отмечено как новое, в карточке видно время получения, после открытия карточки отметка снимается.
12. Достижение, условие которого выполнено, выдаётся в течение нескольких секунд, даже если ПДА не открывали.
