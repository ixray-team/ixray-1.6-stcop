# 3D иконки
> [!IMPORTANT]
> **Статус**: Поддерживается <br>
> **Минимальная версия**: 1.4

## Обзор

3D иконки позволяют отображать внутриигровые модели предметов в инвентаре, а также избавляют от необходимости рисовать отдельные иконки под каждый предмет.

## Активация

Для активации 3D иконок необходимо открыть файл `engine_external.ltx` и сменить значение параметра `Enable3DIcons` с `false` на `true`.

## Ingame настройка

Для настройки предмета в инвентаре необходимо ввести консольную команду `3d_icons_adjust 1`. Шаг изменения значений регулируется консольной командой `3d_icons_adjust_value`. Текущий предмет для настройки зависит от положения курсора.

Управление в инвентаре следующее:

| Клавиша | Назначение |
|:---|---:|
| Z | Поворот по оси X |
| X | Поворот по оси Y |
| C | Поворот по оси Z |
| V | Изменение размера |
| B | Запись итоговых значений в лог |
| Левый Ctrl | (при зажатии) Обратное направление |

### ImGui-редактор

Вместо консольных команд и горячих клавиш можно использовать встроенный ImGui-редактор. Откройте главное меню ImGui (клавиша `Alt`) и выберите `Game` → `3D Icons Adjust`.

Возможности окна:

- список всех предметов инвентаря с фильтром по секции/названию и столбцом расположения (слот, пояс, рюкзак) — предмет можно выбрать кликом, не наводя курсор; изменённые предметы подсвечиваются в списке;
- выбор предмета наведением курсора на его иконку в инвентаре (галочка `Follow cursor`);
- включение режима настройки и шага изменения (аналогично `3d_icons_adjust` / `3d_icons_adjust_value`);
- редактирование модели (`3d_static_visual_name`), поворота (X, Y, Z в градусах) и размера (`3d_static_scale`) с мгновенным применением;
- сброс значений к конфигурации предмета;
- вывод значений в лог, копирование готового блока в буфер обмена и сохранение всех изменённых секций в `$app_data_root$\3d_icons\adjusted.ltx`.

Горячие клавиши `Z`, `X`, `C`, `V`, `B` и `Левый Ctrl` работают и при открытом ImGui-окне, если включён режим настройки.

## Конфигурация предмета

Для каждого предмета в инвентаре существуют следующие параметры:

```ini
3d_static_visual_name = dynamics\devices\dev_binoculars\dev_binoculars.ogf ; Название модели для 3D иконки. Если парамер отсутствует, будет использоваться мировая модель предмета (из visual)
3d_static_rotate = 0.0, 90.0, 0.0 ; Вращение предмета по осям X, Y, Z. Измеряется в градусах.
3d_static_scale = 1.0 ; Размер предмета в инвентаре. 
```

Смежный материал: [обзор UI](ui-advanced-features.md).
