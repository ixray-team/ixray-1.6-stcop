# Объём инвентаря

> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: 1.4

## Обзор

Система сравнивает объём предметов в рюкзаке с вместимостью актёра. Включите `EnableInventoryVolume = true` в секции `[gameplay]` файла `gamedata/configs/engine_external.ltx`. Штатный переключатель выключен во всех четырёх комплектах ресурсов. В репозитории `configs/volume_system.ltx` входит в комплект ЗП. Для ТЧ, ЧН и CoC можно добавить собственный файл с той же схемой.

## Параметры volume_system.ltx

| Секция | Ключ | Тип | Резерв в коде | Штатно в ЗП | Действие |
| --- | --- | --- | --- | --- | --- |
| `[volume_system]` | `base_actor_volume` | `float` | `0` | `10` | Базовая вместимость. При значении около нуля или ниже используется `[inventory] max_ruck`, если ключ задан. |
| `[volume_system]` | `default_weight_volume_multiplier` | `float` | `1` | `1` | Множитель веса при расчёте объёма без явной записи в `[item_volumes]`. |
| `[volume_system]` | `hard_overload_limit` | `float` | `1.4` | `1.4` | Порог перегруза относительно вместимости. Например, `1.4` соответствует 140%. Для плавной шкалы задавайте значение больше `1`. |
| `[volume_system]` | `block_pickup_at_hard_limit` | `bool` | `true` | `true` | Запрещает добавление предмета в рюкзак актёра, если суммарный объём превысит предел. Проверка пропускает коробки боеприпасов и предметы, уже лежащие в рюкзаке. |
| `[volume_system]` | `recursive_container_volume` | `bool` | `false` | `true` | Добавляет объём вложений, доступных через компоненты прикрепления, если объём самого предмета рассчитывается по весу. Глубина обхода ограничена восемью уровнями. |
| `[soft_penalties]` | `stamina_power_penalty` | `float` | `0.25` | `0.25` | Максимальная добавка к нагрузке при расчёте расхода выносливости. |
| `[soft_penalties]` | `max_walk_weight_penalty` | `float` | `0` | `0` | Максимальная величина, вычитаемая из предельного веса для ходьбы. |
| `[soft_penalties]` | `aim_sway_penalty` | `float` | `0` | `0` | Максимальная прибавка к множителю разброса актёра, включая режим прицеливания. |
| `[soft_penalties]` | `sprint_block_factor` | `float` | `1.2` | `1.2` | Запрещает спринт при достижении заданного отношения объёма к вместимости. Проверяется при перегрузе свыше 100%. |

При перегрузе выше 100% штрафы плавно растут до `hard_overload_limit`. Проверка подбора использует прогнозируемый объём после добавления предмета, а штрафы движения — текущий объём.

## Объём предметов и вместимость экипировки

В `[item_volumes]` ключом служит точное имя секции предмета, а значением — его объём. Для экипировки `[container_profiles]` задаёт именованные значения вместимости. Секции `[outfit_sections]` и `[container_sections]` сопоставляют костюмы и рюкзаки с этими профилями.

Порядок расчёта вместимости следующий. Сначала применяется базовое значение, затем профиль костюма и его запись в `[outfit_capacity_overrides]`, затем профиль рюкзака и его запись в `[container_capacity_overrides]`. Каждая найденная запись заменяет предыдущую вместимость целиком.

## Пример для ЗП

После включения функции создайте `gamedata/configs/mod_volume_system_example.ltx`. Патч рассчитан на штатный `volume_system.ltx` ЗП.

```ini
![volume_system]
base_actor_volume = 35
hard_overload_limit = 1.4

![soft_penalties]
sprint_block_factor = 1.2

![outfit_capacity_overrides]
novice_outfit = 45

![item_volumes]
bandage = 0.2
```

Без экипировки вместимость равна 35. Костюм новичка задаёт 45, если рюкзак не переопределяет это значение. Бинт занимает 0.2 единицы объёма.
