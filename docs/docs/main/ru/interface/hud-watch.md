# Модель часов на руках HUD

> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: 1.4

## Обзор

Движок может рисовать отдельную модель часов вместе с моделью рук. Часы следуют за указанной костью рук при проигрывании HUD-анимаций.

## Синтаксис

Добавьте ключи в активную LTX-секцию рук игрока, рядом с `visual`. Пример пути и имени кости замените на данные ваших моделей.

```ini
visual_watches = dynamics\devices\hud_watch.ogf
watches_bone = bip01_l_hand
watches_pos = 0, 0, 0
watches_rot = 0, 0, 0
watches_scale = 1.0
```

| Ключ | По умолчанию | Действие |
| --- | --- | --- |
| `visual_watches` | отсутствует | Имя скелетной модели часов. Наличие ключа включает загрузку модели. |
| `watches_bone` | обязательный при `visual_watches` | Имя кости в модели **рук**. |
| `watches_pos` | `0, 0, 0` | Локальное смещение относительно кости. |
| `watches_rot` | `0, 0, 0` | Локальный поворот в градусах, в порядке heading, pitch, bank. |
| `watches_scale` | `1.0` | Одинаковый множитель масштаба по трём осям. |

## Примеры

### Подогнать положение часов

Сначала проверьте привязку со смещением и поворотом `0, 0, 0`. Затем скорректируйте `watches_pos`, `watches_rot` и `watches_scale`. Проверьте, что часы следуют за запястьем при движении и перезарядке. В сборке с редактором HUD значения можно подобрать в инструменте HUD Adjust.
