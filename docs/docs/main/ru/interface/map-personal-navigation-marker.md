# Навигационная личная метка

## Обзор

Навигационная личная метка это пользовательская точка на карте ПДА, которую можно назначить текущей целью навигации.

## Как это работает

1. Метка хранится как `CMapLocation` пользовательского типа.
2. Активная цель хранится в `CMapManager`.
3. В контекстном меню карты доступны действия:
   1. установить навигационную личную метку как активную цель
   2. снять активную цель
4. При удалении метки активная цель очищается автоматически.

## Применение

1. Откройте карту ПДА.
2. Выберите пользовательскую метку.
3. Вызовите контекстное меню.
4. Выберите установку или снятие навигационной цели.
