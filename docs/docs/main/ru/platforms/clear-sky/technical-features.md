# Clear Sky (1.5.10)
> [!IMPORTANT]  
> **Статус**: WIP <br>
> **Минимальная версия**: 1.4
## Общие особенности

* Используется единый с ЗП модуль `xrGame.dll`, благодаря чему большинство возможностей движка из ЗП доступны в ЧН и наоборот.
* Для файла конфигурации ножа (файл `gamedata\configs\weapons\w_knife.ltx`) используются параметры из ЗП.
* Обнаружение аномалий определяется теперь по секциям, а не по классам (файл `gamedata\configs\misc\radiation_counter.ltx`).
* Используется система обнаружения артефактов у детектора "Велес" из ЗП (файл `gamedata\configs\ui\ui_detector_artefact.xml`).
* Портированы из ЗП скрипты `level_weathers.script`, `ph_door.script`, `sr_no_weapon.script` и `xr_sound.script`.
* Благодаря использованию `xrGame.dll` из ЗП можно теперь использовать ЗП UI.
* В мультиплеере используется множество правок UI из ЗП.
* Изменены значения `eat_portions_num` у пищи с `-1` на `1`, чтобы еда не была бесконечной.
* Перенесён шейдер тесселяции из ЗП для совместимости с ЗП моделями (файл `gamedata\shaders.xr`)
* Подсказки в UI (файл `gamedata\configs\ui\hint_item.xml`) взяты из ЗП.
* Добавлены фиксы состояний НПС в файле `gamedata\scripts\state_mgr_direction.script`.
* Теперь режим сесть/встать сделан через галочку в опциях, а не через отдельную клавишу, как в ЗП.
* В файл `gamedata\configs\ui\game_tutorials.xml` добавлен текст `Нажмите любую клавишу для перехода в игру`.
* Теперь поведение огня у сталкеров регулируется через секцию `fire_queue_params`, как в ЗП.
* В инвентаре теперь отображается состояние предметов, как в ЗП.
* Добавлено переключение языка через главное меню (файл `gamedata\configs\ui\ui_mm_main.xml`).
* Перенесено отображение характеристик предметов из ЗП (файлы `gamedata\configs\ui\actor_menu_item.xml`, `gamedata\configs\ui\af_params.xml` и `gamedata\configs\ui\booster_params.xml`).

## Стандартные значения в `engine_external.ltx`

Папка gamedata от Чистого Неба, в отличие от её ЗП аналога, имеет отличия в стандартных параметрах файла конфигурации движка `engine_external.ltx`. Вот список отличий:

```ini
[general]
Platform = cs ; Используемая платформа, в данном случае cs (Чистое Небо)
title = st_ixray_title_cs ; Отображаемое имя в Discord Rich Presence, в данном случае уникальное для ЧН

[ui]
WeaponIconScale = 0.65 ; Размер иконки патронов в maingame.xml. В ЗП по умолчанию стоит значение 0.8, в ЧН - 0.65, а в ТЧ - 0.9.
ShowLoadingStages = true ; Стадии загрузки, например "Клиент: Синхронизация"
DisableMotionIcon = true ; Отключение использования счётчиков шума и видимости, потому что в ЧН их нету
PdaRearrangeTabButtons = true ; Использование старой формулы расчёта размера вкладок в КПК по типу "Война группировок"

[gameplay]
EnableInventoryPistolSlot = true ; Использовать второй слот только для пистолетов
EnableLegacyUpgradeSystem = true ; Использовать старую систему улучшения, где нельзя одновременно поставить 2 улучшения в одной категории

[render]
DisableLoadScreenTips = true ; Отключение использования советов на загрузочном экране
```
