# 3D гильзы

Движок поддерживает два способа отображения гильз:
- **Частицы** — стандартный способ. Гильза — эффект частиц из `shell_particles`.
- **3D модель** — физически симулируемая 3D гильза, которая отскакивает от поверхностей.

Чтобы включить 3D гильзы, добавьте `shell_section` в секцию оружия.

---

## Параметры оружия

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `shell_section` | string | — | Секция определения 3D гильзы. Если задана — включает 3D гильзы вместо частиц |
| `shell_section_0` | string | — | Секция 3D гильзы для типа патрона 0 |
| `shell_section_1` | string | — | Секция 3D гильзы для типа патрона 1 |
| `shell_section_N` | string | — | Секция 3D гильзы для типа патрона N |
| `shell_point` | vector3 | `0, 0, 0` | Смещение точки вылета гильзы от оружия в локальных координатах (X, Y, Z) |
| `shell_dir` | vector3 | `1, 0, 0` | Направление выброса гильзы в локальных координатах оружия (X = вправо, Y = вверх, Z = вперёд) |
| `shell_ejection_speed` | float | 20.0 | Скорость выброса гильзы в метрах в секунду |
| `shell_ejection_dispersion_angle` | float | 30.0 | Разброс направления вылета гильзы в градусах (максимум 90). Чем больше значение — тем случайнее летит гильза. При 0 — всегда по направлению shell_dir, при 30 — разброс конусом на 30° |

### Приоритет поиска

- Если задан `shell_section` — используется для **всех** типов патронов
- Если нет — ищется `shell_section_0`, `shell_section_1`, ... для каждого типа патрона
- Если ничего не найдено — используются частицы из `shell_particles`

---

## Определение секции гильзы

Каждая 3D гильза — отдельная секция:

```ini
[shell_5.45x39]
class     = SHELL_S_
$spawn    = "physics\shell"
$prefetch = 8
visual    = dynamics\weapons\wpn_shells\5_45x39.ogf
```

| Параметр | Описание |
|----------|----------|
| `class` | Обязательно: `SHELL_S_` |
| `$spawn` | Обязательно: `"physics\shell"` |
| `$prefetch` | Количество предзагружаемых объектов в пуле |
| `visual` | Путь к 3D модели гильзы (`.ogf`) |

Секции могут наследоваться:

```ini
[shell_12g_blue]:shell_12g
visual = dynamics\weapons\wpn_shells\12g_blue.ogf
```

---

## Пример: оружие с 3D гильзами

```ini
; Секция оружия (для NPC и World)
[w_ak74]:wpn_ak74
shell_point = 0.017, 0.054, 0.17
shell_dir = 1.0, 0.0, 0.0
shell_section_0 = shell_5.45x39
shell_section_1 = shell_5.45x39

; Секция HUD (для игрока от первого лица)
[w_ak74_hud]:wpn_ak74_hud
shell_point = 0.017, 0.054, 0.17
```

> `shell_point` настраивается отдельно для HUD и World. HUD-позиция нужна для игрока от первого лица, World — для NPC.

## Пример: кастомная гильза

```ini
[shell_9x19_custom]
class     = SHELL_S_
$spawn    = "physics\shell"
$prefetch = 8
visual    = dynamics\weapons\wpn_shells\9x19.ogf

[w_pm]:wpn_pm
shell_section = shell_9x19_custom
```
