# 3D гильзы

Движок поддерживает два способа отображения гильз:
- **Частицы** — стандартный способ. Гильза — эффект частиц из `shell_particles`.
- **3D модель** — физически симулируемая 3D гильза, которая отскакивает от поверхностей.

Чтобы включить 3D гильзы, добавьте `shell_section` в секцию оружия.

---

## Параметры оружия

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `shell_section` | string | — | Секция определения 3D-гильзы. Если задана — вместо частиц **всегда** используется 3D-гильза, для всех типов патронов |
| `shell_section_0` | string | — | Секция 3D-гильзы для типа патрона с индексом 0 |
| `shell_section_1` | string | — | Секция 3D-гильзы для типа патрона с индексом 1 |
| `shell_section_N` | string | — | Секция 3D-гильзы для типа патрона с индексом N. Индексы идут с 0 в том же порядке, что и типы патронов в `ammo_class` |
| `shell_point` | vector3 | `0, 0, 0` | Точка вылета гильзы: смещение от начала координат оружия в его локальной системе, **в метрах** (X, Y, Z). Задаётся отдельно для мира и для HUD (см. «Где указывать параметры») |
| `shell_dir` | vector3 | `1, 0, 0` | Направление вылета в локальных осях оружия: X — вправо, Y — вверх, Z — вперёд. Нормализуется автоматически, поэтому достаточно задать ориентир, например `1, 0, 0`. Поворачивается вместе с оружием |
| `shell_ejection_speed` | float | 20.0 | Скорость вылета гильзы вдоль `shell_dir`, в метрах в секунду. Скорость движения оружия (и его носителя) прибавляется к этой скорости — гильза, выброшенная у бегущего бойца, уносится вместе с ним |
| `shell_ejection_dispersion_angle` | float | 30.0 | Случайный разброс направления вылета, в градусах: `0` — строго по `shell_dir`, `30` — конус 30°, `90` — максимально возможный разброс. Значения больше 90 автоматически обрезаются до 90 |
| `spawn_shell_on_last_shot` | bool | `true` | Выбрасывать ли 3D-гильзу на последнем выстреле — когда после него в магазине и патроннике не остаётся патронов. При `false` последний выстрел даёт только частицу из `shell_particles`, 3D-гильзы нет: используется для помпового оружия и винтовок с продольно-скользящим затвором, где гильза должна «ждать» перекатки затвора |
| `shell_time` | float | `0.0` | Задержка выброса 3D-гильзы после выстрела, **в секундах** (значение дробное: `0.15` = 150 мс). При `0` — выброс в момент выстрела. Отложенный выброс отменяется, если раньше истечения задержки оружие перестало принадлежать персонажу (например, выброшено). На частицы `shell_time` не действует |

### Где указывать параметры

- `shell_section`, `shell_section_N`, `shell_dir`, `shell_ejection_speed`, `shell_ejection_dispersion_angle`, `spawn_shell_on_last_shot`, `shell_time` — читаются **только из секции оружия** (например, `[w_ak74]:wpn_ak74`). HUD-секция их не читает
- `shell_point` — задаётся независимо в двух местах: в секции оружия (мир: NPC, внешний вид) и в HUD-секции (игрок от первого лица). Значение между секциями не переносится — пропишите его в обеих, иначе в одном из режимов гильза будет вылетать из точки `0, 0, 0`

### Приоритет поиска

- Если задан `shell_section` — используется для **всех** типов патронов
- Если нет — ищется `shell_section_0`, `shell_section_1`, ... по индексу типа патрона
- Если для выстрела не нашлось своей секции, но другие `shell_section_N` заданы — по умолчанию берётся любая из заданных
- Если ничего не найдено — используется частица из `shell_particles`

Секция гильзы выбирается по типу патрона, которым произведён выстрел: сначала патронник, затем магазин, затем текущий тип оружия.

### Условия выброса

3D-гильза появляется, только если выполняются все условия:
- оружие не осеклось (нет misfire);
- задана хотя бы одна секция `shell_section`/`shell_section_N`.

Частицы из `shell_particles` проигрываются только в пределах 5 м от камеры, 3D-гильзы — на любом расстоянии.

### Отложенный выброс

- `shell_time` действует только на 3D-гильзы (когда задана `shell_section`/`shell_section_N`): частицы всегда выбрасываются в момент выстрела
- Задержка отсчитывается от момента выстрела, а не от фактического движения затвора — подбирайте значение под длительность анимации перекатки
- Если до истечения задержки оружие перестало принадлежать персонажу, отложенный выброс отменяется (гильза не появится)

## Определение секции гильзы

Каждая 3D гильза — отдельная секция:

```ini
[shell_5.45x39]
class     = SHELL_S_
$spawn    = "physics\shell"
$prefetch = 8
visual    = dynamics\weapons\wpn_shells\5_45x39.ogf
```

| Параметр | Описание |
|----------|----------|
| `class` | Обязательно: `SHELL_S_` |
| `$spawn` | Обязательно: `"physics\shell"` |
| `$prefetch` | Количество предзагружаемых объектов в пуле |
| `visual` | Путь к 3D модели гильзы (`.ogf`) |

Секции могут наследоваться:

```ini
[shell_12g_blue]:shell_12g
visual = dynamics\weapons\wpn_shells\12g_blue.ogf
```

## Пример: оружие с 3D гильзами

```ini
; Секция оружия (для NPC и World)
[w_ak74]:wpn_ak74
shell_point = 0.017, 0.054, 0.17
shell_dir = 1.0, 0.0, 0.0
shell_section_0 = shell_5.45x39
shell_section_1 = shell_5.45x39

; Секция HUD (для игрока от первого лица)
[w_ak74_hud]:wpn_ak74_hud
shell_point = 0.017, 0.054, 0.17
```

> `shell_point` настраивается отдельно для HUD и World. HUD-позиция нужна для игрока от первого лица, World — для NPC.

## Пример: отложенный выброс (затвор/помпа)

Для винтовок с продольно-скользящим затвором и помповых дробовиков: гильза не вылетает в момент выстрела, а немного позже — визуально к моменту перекатки затвора.

```ini
[w_mp43]:wpn_mp43
shell_section = shell_12g
shell_point = 0.02, 0.05, 0.22
shell_dir = 1.0, 0.15, 0.0
shell_ejection_speed = 12.0
shell_time = 0.4 ; выброс через 0.4 с после выстрела — под анимацию перекатки
spawn_shell_on_last_shot = false ; последняя гильза при выстреле не выбрасывается
```

## Пример: кастомная гильза

```ini
[shell_9x19_custom]
class     = SHELL_S_
$spawn    = "physics\shell"
$prefetch = 8
visual    = dynamics\weapons\wpn_shells\9x19.ogf

[w_pm]:wpn_pm
shell_section = shell_9x19_custom
```
