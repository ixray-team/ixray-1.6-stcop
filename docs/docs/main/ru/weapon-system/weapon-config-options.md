# Темп стрельбы, эффекты камеры и вибрация

> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: 1.4

## Обзор

Настройки магазинного оружия разделены между LTX-секцией предмета, HUD-секцией и глобальным конфигом движка. По одному конфигу можно проверить темп, камерный эффект выстрела и отклик геймпада.

## Синтаксис

### Секция оружия

| Ключ | По умолчанию | Действие |
| --- | --- | --- |
| `rpm` | обязательный | Базовый темп в выстрелах в минуту. Движок вычисляет интервал как `60 / rpm`. |
| `singleshoots_time_delta` | `0.0` | Интервал в секундах для режима с очередью в один выстрел. Положительное значение имеет приоритет. |
| `base_dispersioned_bullets_count` | `0` | Количество начальных выстрелов по логике базового разброса. Ключ читается как `u8`. |
| `base_dispersioned_bullets_time_delta` | `0.0` | Интервал в секундах, пока счётчик выстрелов меньше `base_dispersioned_bullets_count`. Применяется при положительном значении, если не сработал интервал одиночного режима. |
| `vibration_time` | `0.1` | Длительность вибрации выстрела в секундах. |
| `vibration_factor_left`, `vibration_factor_right` | `1.0` | Интенсивность моторов геймпада. Задавайте от 0 до 1. |
| `trigger_effect_time` | `1.0` | Длительность эффекта правого адаптивного триггера при одиночном выстреле, в секундах. |

Параметр `[gameplay] EnableWeaponAlternateRPMSystem` в `engine_external.ltx` влияет на расчёт таймера. При `true` движок присваивает таймеру выбранный интервал. При `false` прибавляет интервал к текущему таймеру. Во всех четырёх штатных конфигах флаг равен `false`.

### HUD-секция оружия

Пути к камерным анимациям указываются в секции из поля `hud` предмета, относительно `$game_anims$`.

| Ключ | Штатный путь | Событие |
| --- | --- | --- |
| `cam_shoot` | `camera_effects\weapon\base_shoot.anm` | Выстрел без прицеливания. |
| `cam_aim_shoot` | `camera_effects\weapon\base_aim_shoot.anm` | Выстрел при прицеливании. |
| `cam_aim_in`, `cam_aim_out` | `camera_effects\actor_move\aim_in.anm`, `camera_effects\actor_move\aim_out.anm` | Вход в прицеливание и выход из него. |
| `cam_safemode_in`, `cam_safemode_out` | `camera_effects\actor_move\safemode_in.anm`, `camera_effects\actor_move\safemode_out.anm` | Вход в безопасный режим и выход из него. |

При отсутствии первого файла список для события остаётся пустым. После его загрузки движок ищет варианты с суффиксами `1`, `2` и далее, добавляя число к **штатному** имени вместе с расширением, например `base_shoot.anm1`. Для выстрела при прицеливании нужен непустой обычный список `cam_shoot`. Если список `cam_aim_shoot` пуст, используется обычный эффект. Парные переходы требуют загруженных файлов для входа и выхода.

### Длительности переходов оружейного HUD

Ключи читаются в HUD-секции оружия. Длительности задаются в секундах и переводятся движком в целые миллисекунды. Резерв для каждого ключа — `0`.

| Ключи | Переход |
| --- | --- |
| `to_crouch_time`, `from_crouch_time` | Вход в присед и выход из него. |
| `to_slow_crouch_time`, `from_slow_crouch_time` | Вход в низкий присед и выход из него. |
| `to_llookout_time`, `from_llookout_time` | Вход в наклон влево и выход из него. |
| `to_rlookout_time`, `from_rlookout_time` | Длительности правого наклона. В текущей реализации при входе вправо используется `to_llookout_time`. Выход вправо использует `from_rlookout_time`. |

Пример для общего `[hud_base]` через DLTX:

```ini
![hud_base]
to_crouch_time = 0.15
from_crouch_time = 0.15
to_llookout_time = 0.15
from_llookout_time = 0.15
to_rlookout_time = 0.15
from_rlookout_time = 0.15
```

### Перегрев стационарного пулемёта

Движок читает эти ключи из секции стационарного пулемёта. Нагрев увеличивается за каждый вызов `UpdateFire` во время работы пулемёта, а охлаждение вычитается при каждом обновлении. Эти величины измеряются в единицах нагрева за вызов.

| Ключ | Резерв в коде | Действие |
| --- | ---: | --- |
| `overheat_enabled` | `false` | Включает расчёт перегрева. |
| `overheat_time_quant` | `0.025` | Добавляет нагрев, пока пулемёт работает. |
| `overheat_decr_quant` | `0.002` | Вычитает нагрев при каждом обновлении, в том числе при стрельбе. |
| `overheat_threshold` | `110` | Максимум накопленного нагрева. При достижении порога стрельба блокируется. |
| `overheat_particles` | `damage_fx\burn_creatures00` | Имя эффекта, который запускается при нагреве `100`. |

Когда нагрев опускается ниже `100`, эффект прекращается и блокировка снимается. Для рабочего диапазона с видимым эффектом задайте `overheat_threshold` не меньше `100`. При меньшем значении нагрев ограничивается ниже точки включения эффекта и остановки стрельбы.

Чтобы воспроизвести штатную настройку CoC, задайте в секции `stationary_mgun`:

```ini
overheat_enabled = true
overheat_time_quant = 0.90
overheat_decr_quant = 0.20
overheat_threshold = 200
overheat_particles = industrial_particles\exhaust_workshop_1_small
```

## Примеры

В секции оружия задайте интервал одиночного режима и параметры вибрации.

```ini
rpm = 600
singleshoots_time_delta = 0.18
vibration_time = 0.1
vibration_factor_left = 0.7
vibration_factor_right = 0.35
trigger_effect_time = 0.8
```

Базовый интервал составляет 0.1 с. Для очереди из одного выстрела используется интервал 0.18 с.

## Контакт модели HUD с окружением

Ключи находятся в HUD-секции оружия, указанной через `hud`. Проверка использует ориентированный бокс и статическую геометрию. При прицеливании вклад этого эффекта уменьшается пропорционально текущему коэффициенту прицеливания.

| Ключ | Тип и резерв | Назначение |
| --- | --- | --- |
| `collision_box_pos` | вектор `0, 0, 0` | Центр бокса в локальных координатах HUD. |
| `collision_box_scale` | вектор `1, 1, 1` | Полуразмеры бокса по трём осям. |
| `collision_stifness` | число `400.0` | Жёсткость пружины, через которую меняется поза. В коде ключ пишется с одной `f`. |
| `collision_damping` | число `40.0` | Затухание пружины. |
| `collision_dist_min` | число `0.5` | Дистанция от камеры до контакта, при которой смещение полное. |
| `collision_dist_max` | число `0.8` | Дистанция, при которой смещение равно нулю. |

Задавайте `0 ≤ collision_dist_min < collision_dist_max ≤ 1`. Движок ограничивает полученную дистанцию интервалом `0…1` перед расчётом вклада контакта. Например, пара `0.35` и `0.7` задаёт плавный переход между полным смещением вблизи и нулевым на дальнем пороге.

## Подсветка и ЛЦУ предметов HUD

Эти ключи находятся в секции самого предмета. Для фонаря укажите `torch_installed` и обязательные строки кости и текстуры. Для ЛЦУ укажите `laser_installed` и его собственные кость и текстуру. Имена костей должны существовать в используемой модели.

### Фонарь

| Ключ | Тип и резерв | Назначение |
| --- | --- | --- |
| `torch_installed` | `bool / false` | Включает компонент фонаря для HUD-предмета. |
| `torch_light_bone` | `string / required` | Кость, в координатах которой задаётся источник света. |
| `torch_spot_texture` | `string / required` | Текстура пятна направленного источника. |
| `torch_render_type` | `u32 / SPOT` | Тип основного источника. Вспомогательный источник всегда точечный. |
| `torch_r2_range`, `torch_r2_omni_range` | `float / 15; 0.75` | Дальность основного и вспомогательного света. |
| `torch_render_shadow`, `torch_omni_shadow` | `bool / true; false` | Включают тени у соответствующих источников. |
| `torch_spot_angle` | `float / 75` | Угол конуса в градусах. |
| `torch_r2_color_r`, `torch_r2_color_g`, `torch_r2_color_b`, `torch_r2_color_a` | `float / 0.60; 0.55; 0.55; 0.80` | Компоненты RGBA основного света. |
| `torch_r2_omni_color_r`, `torch_r2_omni_color_g`, `torch_r2_omni_color_b`, `torch_r2_omni_color_a` | `float / 0.60; 0.55; 0.55; 0.80` | Компоненты RGBA вспомогательного света. |
| `torch_attach_offset_x`, `torch_attach_offset_y`, `torch_attach_offset_z` | `float / 0` | Смещение основного света для модели HUD. |
| `torch_aim_attach_offset_x`, `torch_aim_attach_offset_y`, `torch_aim_attach_offset_z` | `float / 0` | Смещение света при прицеливании. |
| `torch_world_attach_offset_x`, `torch_world_attach_offset_y`, `torch_world_attach_offset_z` | `float / 0` | Смещение основного света для мировой модели. |
| `torch_omni_attach_offset_x`, `torch_omni_attach_offset_y`, `torch_omni_attach_offset_z` | `float / torch_attach_offset_*` | Смещение вспомогательного света в HUD. |
| `torch_omni_world_attach_offset_x`, `torch_omni_world_attach_offset_y`, `torch_omni_world_attach_offset_z` | `float / torch_world_attach_offset_*` | Смещение вспомогательного света в мире. |
| `light_directions_by_bones`, `light_dir_bone` | `bool / false, string` | Включает вычисление направления по кости. При включении нужно задать имя кости. |
| `torch_cone_bones` | `list` | Список костей конуса фонаря через запятую. |
| `torch_breaking_params` | `vector / -1, -1, 0` | Начальное и конечное состояние для помех, затем начальная вероятность. |

### ЛЦУ

| Ключ | Тип и резерв | Назначение |
| --- | --- | --- |
| `laser_installed` | `bool` | При `true` загрузчик оружия создаёт компонент ЛЦУ. |
| `laserdot_attach_bone`, `laser_spot_texture` | `string / required` | Кость источника и текстура пятна. |
| `laser_light_distance` | `float / 15` | Дальность источника света. |
| `laser_wrok_distance` | `float / 0.5 × laser_light_distance` | Расстояние, после которого источник смещается по лучу. Движок ищет именно `wrok`. |
| `laser_max_distance` | `float / laser_wrok_distance` | Дальность запроса пересечения луча. |
| `laser_light_color` | `RGBA / 1, 0, 0, 0` | Цвет источника. |
| `laser_render_shadow` | `bool / true` | Включает тени. |
| `laser_spot_angle` | `vector2 / 2, 5` | Начальный и конечный углы конуса в градусах. В HUD угол меняется между рабочей и максимальной дистанцией. |
| `laserdot_attach_offset_x`, `laserdot_attach_offset_y`, `laserdot_attach_offset_z` | `float / 0` | Смещение источника на модели HUD. |
| `laserdot_world_attach_offset_x`, `laserdot_world_attach_offset_y`, `laserdot_world_attach_offset_z` | `float / 0` | Смещение источника на мировой модели. |
| `laserdot_attach_offset`, `laserdot_world_attach_offset` | `vector` | Трёхкомпонентное смещение. При наличии заменяет значения из отдельных ключей осей. |
| `laser_ray_bones` | `list` | Список костей эффекта луча через запятую. |
| `laser_breaking_params`, `laser_problems_level` | `vector / -1, -1, 0; float / 0` | Пороги состояния и начальная вероятность помех, затем отдельный уровень помех. |

Для настройки уже установленного ЛЦУ можно поменять только дальности. Например, `laser_wrok_distance = 10` и `laser_max_distance = 20` задают интервал от начала смещения источника до предела лучевого запроса.

## Поворотная инерция и отключение анимации осмотра

Эти ключи задаются в HUD-секции, выбранной через `hud`. При переходе в прицел движок смешивает значения между двумя колонками по коэффициенту прицеливания.

| Параметр | Обычная стойка | Прицеливание | Резерв |
| --- | --- | --- | --- |
| Инерция поворота влево и вправо | `hud_yaw_inertia_k` | `hud_zoom_yaw_inertia_k` | `0` |
| Инерция вертикального поворота | `hud_pitch_inertia_k` | `hud_zoom_pitch_inertia_k` | `0` |
| Наклон вокруг оси взгляда от горизонтального поворота | `hud_roll_inertia_k` | `hud_zoom_roll_inertia_k` | `0` |
| Скорость приближения к целевой инерции | `hud_inertia_speed` | `hud_zoom_inertia_speed` | `10` |

Скорости и коэффициенты дробные. Например, `hud_zoom_yaw_inertia_k = 0` убирает вклад этой оси при полном прицеливании. Булевый `disable_bore` отключает анимацию осмотра предмета при бездействии, резерв `false`.

## Lua-окно на модели HUD

В секции предмета `script_ui_functor` задаёт имя Lua-функции без аргументов, которая возвращает `CUIDialogWndEx`. Пока имя пустое, остальные три ключа не читаются. При непустом имени задайте `script_ui_bone` с именем кости, `script_ui_position` с локальным смещением и `script_ui_rotation` с поворотом в градусах в порядке heading, pitch, bank. Загрузчик строит матрицу из этих параметров.

```ini
script_ui_functor = my_device.create_display
script_ui_bone = display
script_ui_position = 0, 0, 0
script_ui_rotation = 0, 0, 0
```

В примере предполагается, что модель содержит кость `display`, а функция создаёт или возвращает окно дисплея.
