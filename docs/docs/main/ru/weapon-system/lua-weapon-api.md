# Оружие и обвесы в Lua

> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: 1.4

## Обзор

Скриптовый `game_object` магазинного оружия предоставляет методы работы с патронами, обвесами и прицелом. Перед вызовом получите живой объект оружия.

## Синтаксис

| Вызов | Результат |
| --- | --- |
| `weapon:weapon_get_ammo_section(ammo_type)` | Секция патронов по индексу с нуля или пустая строка. |
| `weapon:weapon_addon_attach(item)` | Прикрепляет существующий совместимый предмет-обвес. |
| `weapon:weapon_addon_detach(section, spawn_to_inventory)` | Снимает совместимый обвес. Второй аргумент управляет созданием предмета. |
| `weapon:addons_attach(mask, scope_idx)` | Заменяет маску обвесов и обновляет параметры и визуал. При установке съёмного прицела `scope_idx` должен быть допустимым индексом с нуля. Если индекс неверен, операция отменяется. |
| `weapon:weapon_get_scope()` | Текущий индекс прицела или `255` для объекта неподходящего типа. |
| `weapon:weapon_set_scope(scope_idx)` | Устанавливает допустимый индекс прицела с нуля. Для обновления параметров и визуала используйте `addons_attach`. |

В маске `0x01` соответствует прицелу, `0x02` — подствольному гранатомёту, `0x04` — глушителю.

## Примеры

### Установка первого прицела и глушителя

```lua
local function setup_attachments(weapon)
    weapon:addons_attach(0x01 + 0x04, 0)
end
```

Вызывайте функцию для магазинного оружия, у которого в конфиге есть съёмный прицел с индексом `0` и поддержка глушителя. Маска заменяет предыдущее состояние.

## Рекомендации и ограничения

- Для `weapon_addon_attach` передавайте существующий предмет. C++ разыменовывает аргумент без проверки на `nil`.
- При переключении съёмного прицела передавайте индекс из конфигурации оружия. Движок обращается к списку прицелов без проверки границ.
