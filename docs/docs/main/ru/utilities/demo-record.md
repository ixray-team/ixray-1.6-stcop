# Demo Record (Деморекорд)

> [!IMPORTANT]
> **Статус**: Поддерживается / В разработке (окно настроек) <br>
> **Минимальная версия**: 1.4 (окно настроек). Команда `demo_record` доступна с ранних версий

Demo Record — встроенный инструмент игры для:

- записи траектории полёта камеры (демо) с ключевыми кадрами;
- создания скриншотов, кубмапов и карт уровня;
- привязки камеры к костям моделей — как объектов мира, так и рук/оружия от первого лица.

---

## Запуск и завершение

### Как начать запись

Откройте консоль (клавиша `` ` ``) и введите:

```
demo_record <имя_файла>
```

- команда работает только на загруженном уровне;
- консоль и главное меню автоматически закроются;
- результат будет сохранён в папку сохранений игры с расширением `.xrdemo`.

Дополнительно можно переместить камеру в любую точку мира:

```
demo_set_cam_position <x> <y> <z>
```

### Что происходит при старте

- скрывается интерфейс от первого лица (руки, оружие);
- текущий угол обзора (FOV) запоминается и возвращается при выходе;
- камера начинается с того места и ракурса, где вы находились в момент запуска;
- скорости движения берутся из настроек игры (их можно менять в окне настроек Demo Record).

### Как завершить запись

Запись заканчивается автоматически, если:

- нажать `ESC`;
- погибнет персонаж;
- пройдёт 1 час (лимит времени записи).

При завершении всё возвращается на свои места: интерфейс, угол обзора, управление.

### Проигрывание демо

Записанные ключевые кадры можно проиграть: для этого игра запускается со специальным ключом `demomode` (см. раздел «Ключи запуска»).

## Режимы камеры

У камеры три режима, они взаимно исключают друг друга. Текущий режим показан в окне настроек.

### Свободный полёт

Режим по умолчанию: камера летает по сцене, как в свободной камере.

- **Мышь** — обзор;
- **W/A/S/D** (или привязки действий) — движение;
- **Q/E** — крен (наклон камеры вокруг оси взгляда).

Дополнительно можно «залочить» отдельные оси — тогда камера всегда будет держать горизонт ровно, смотреть горизонтально или сохранять исходное направление (настраивается в окне настроек, раздел «Lock Axes»).

### Взгляд на точку

Камера всегда повёрнута в сторону выбранной цели: либо точки в пространстве, либо кости модели.

- включение — клавиша `J` (или выбор режима в окне настроек);
- если в центре экрана находится модель с костями — камера будет следить за её костью;
- если под прицелом просто поверхность — зафиксируется точка на ней;
- отключение — снова `J`.

Поворот камеры при этом плавный (с инерцией), без резких «перескоков» на 180°.

### Привязка к кости

Камера полностью привязана к кости выбранной модели и движется вместе с ней. Привязываться можно к:

- объектам мира (навести прицел и нажать `U`);
- рукам от первого лица;
- оружию в левой или правой руке;
- предмету, проигрывающему анимацию.

Что можно делать в этом режиме:

- **W/A/S/D**, приседание/прыжок — сдвигать камеру относительно кости;
- **Q/E** — поворачивать камеру вокруг кости;
- **Мышь + Shift** — панорамировать вид вокруг кости;
- **Z** — сбросить все смещения.

Если модель исчезнет (уничтожена, убрано оружие и т.п.), камера автоматически отвяжется и вернётся в свободный полёт. Отвязаться вручную — клавиша `U`.

## Схемы ввода

Есть две схемы управления. По умолчанию активна **старая** схема; **новая** включается через систему расширений движка (`engine_external`) — в файле `engine_external.ltx` в папке `gamedata/configs`, в секции `[gameplay]`:

```ini
[gameplay]
NewDemoRecordInputSchema = true
```

Изменение вступает в силу после перезапуска игры. Во время записи между схемами можно переключаться и «на лету» — в окне настроек (раздел Input → New input schema).

### Новая схема

| Действие | Клавиша |
| --- | --- |
| Движение вперёд/влево/назад/вправо | `W`/`A`/`S`/`D` |
| Вниз / вверх | Приседание / Прыжок |
| Крен влево/вправо | `Q` / `E` |
| Обзор | Мышь |
| Увеличить / уменьшить FOV | `R` / `T` |
| Изменить скорость камеры | Колесо мыши (с `Shift` — крупнее шаг) |
| Записать ключевой кадр | `F` |
| Привязать/отвязать кость | `U` |
| Замок взгляда на точку | `J` |
| Отображение скелета | `K` |
| Сброс FOV | `Z` |
| Передать управление персонажу | `0` |
| Справка | `F1` |
| Карта уровня / карта в высоком качестве | `F11` / `Ctrl+F11` |
| Скриншот | `F12` |
| Кубмап | `Backspace` |
| Выход | `ESC` |
| Пауза | `Pause` |
| Консоль | `` ` `` |

Скорость движения одна на все направления и меняется колесом мыши или в окне настроек.

### Старая схема

| Действие | Клавиша |
| --- | --- |
| Движение | `W`/`A`/`S`/`D`, также `LMB` (вперёд) и `RMB` (назад) |
| Медленное движение | `Shift` (удерживать) |
| Быстрое движение | `Alt` (удерживать) |
| Ускорение | `Ctrl` (удерживать) |
| Крен | `Q` / `E` |
| Записать ключевой кадр | `Space` |
| Остальное | Как в новой схеме |

Скорости трёх уровней настраиваются в окне настроек; базовая скорость (без модификаторов) — фиксированная.

### Геймпад

| Управление | Действие |
| --- | --- |
| Левый стик | Движение |
| Правый стик | Поворот камеры |
| Триггеры | Вниз / вверх |
| `EAST` (B/кружок) | Выход из записи |
| Нажатие левого стика | Включить/выключить ускорение |
| Правый бампер (`RIGHT_SHOULDER`) | Записать ключевой кадр |

### Передача управления персонажу (клавиша `0`)

Полезный режим для записи демо с живым персонажем: весь ввод (клавиатура и мышь) передаётся игровому персонажу, как будто деморекорда нет, а камера продолжает писать демо. Повторное нажатие `0` возвращает управление камерой.

---

## Ключевые кадры

- запись: `F` (новая схема), `Space` (старая схема), правый бампер (геймпад);
- каждый ключевой кадр запоминает положение и ракурс камеры в момент нажатия;
- в мире появляется маркер: сфера с подписью `Keyframe #N`;
- последовательность кадров сохраняется в файл демо и проигрывается в `demomode`;
- количество кадров видно в справке `F1` и в окне настроек.

---

## Снимки экрана, кубмапы и карты уровня

Все эти операции происходят в несколько этапов по кадрам, поэтому при нажатии клавиши изображение может «моргнуть» — это нормально.

### Скриншот (`F12`)

Делает скриншот без интерфейса от первого лица: на один кадр HUD скрывается, затем возвращается.

### Кубмап (`Backspace`)

Последовательно снимает шесть кадров в шести направлениях (+X/−X/+Y/−Y/+Z/−Z) и сохраняет их набором файлов с номерами. Нужен для создания окружения (skybox/отражения) для объектов игры.

### Карта уровня (`F11`)

- игра временно переключается в специальный режим и рендерит весь уровень сверху;
- результат — изображение всей карты в файле `map_<имя_уровня>`;
- после съёмки всё возвращается в обычный режим.

### Карта уровня в высоком качестве (`Ctrl+F11`)

То же самое, но карта снимается по частям — 4 тайла (`map_<уровень>#0` … `#3`) — чтобы получить большее разрешение, чем позволяет одно изображение. Границы карты берутся из настроек уровня (параметр `bound_rect` секции `[level_map]`) или вычисляются автоматически по объектам уровня.

## Отображение скелета (`K`)

При включении на модели в центре экрана (или ближайшей к центру взгляда) рисуется её скелет: кости и связи между ними. Также показываются скелеты HUD-моделей — рук и оружия, если они видимы. Полезно, чтобы наглядно видеть, к какой кости привязать камеру.

## Окно настроек «Demo Record»

Открывается через меню в верхней панели игры: **Game → Demo record**. Если запись не идёт, окно покажет «No active demo recording».

### Global

- **Slider step** — точность ползунков окна. Меньше значение — точнее настройка. По ползунку можно кликнуть с зажатым `Ctrl` и ввести точное число.

### Options

- **Disable time factor influence** — если включено, движение камеры не зависит от замедления времени в игре (например, при слоу-мо или паузе);
- **Draw skeleton** — то же, что клавиша `K`.

### Input

- **New input schema** — переключение старой и новой схем управления (какая схема активна при старте — задаётся в `engine_external.ltx`);
- скорости движения: в новой схеме — один общий ползунок, в старой — три (медленно/быстро/ускорение). Рядом с каждым — кнопка `R` для сброса к значению по умолчанию;
- **Controls reference** — встроенная памятка по всем горячим клавишам активной схемы.

### Camera

- **Mode** — выбор режима камеры: свободный полёт / взгляд на точку / привязка к кости (те же действия, что клавиши `J` и `U`);
- **Smoothing** — плавность поворота и движения камеры (инерция). `0` — мгновенная реакция, чем ближе к `1` — тем плавнее и «мягче» камера;
- **Orientation** — прямой ввод углов поворота камеры (недоступен в режиме привязки к кости);
- **Bone View Offsets** — смещение и поворот камеры относительно кости в режиме привязки;
- **Lock Axes** — блокировка осей: камера всегда держит горизонт / смотрит горизонтально / сохраняет направление;
- **Field of View** — текущий угол обзора; кнопка `R` возвращает значение на момент начала записи;
- **Auto FOV change speed** — если включено, скорость изменения FOV клавишами `R`/`T` зависит от скорости движения камеры; если выключено — задаётся вручную.

### Bone Browser

- показывает объект в центре экрана (или объект, к которому привязана камера): название и количество костей;
- **Bone tree** — дерево всех костей модели; клик по кости привязывает к ней камеру. Текущая кость помечена `[*]`;
- кнопка **Detach** — отвязать камеру.

### HUD Bones

Деревья костей моделей от первого лица: рук, оружия в обеих руках, предмета с активной анимацией. Клик по кости так же привязывает камеру.

### State

- **Keyframes** — сколько ключевых кадров записано;
- **Acceleration** — включено ли ускорение;
- **Redirect input** — кому передаётся ввод: `DEMO RECORD` (камере) или `LEVEL` (персонажу).

### Actions

Кнопки, дублирующие горячие клавиши: Скриншот, Кубмап, Карта уровня (обычная и в высоком качестве).

---

## Жизненный цикл и взаимодействие фич

1. **Запуск.** Команда `demo_record` запускает запись: скрывается HUD, запоминается FOV, камера начинает с текущего вида игрока.
2. **Основной цикл.** Каждый кадр камера обновляется по текущему режиму (свободный полёт / взгляд на точку / привязка к кости), к ней применяются сглаживание, блокировки осей и текущие настройки скорости.
3. **Кейфреймы.** В любой момент можно записать ключевой кадр — он сохраняется в файл демо и помечается сферой в мире.
4. **Захваты.** Скриншот, кубмап и карта уровня — временные операции: они перехватывают камеру на несколько кадров, выполняют съёмку и возвращают управление. Пока идёт захват, движение камеры не обрабатывается.
5. **Взаимодействие режимов.** Режимы камеры исключают друг друга: привязка к кости недоступна при взгляде на точку и наоборот; выход из любого режима возвращает в свободный полёт. Окно настроек всегда отражает текущий режим и позволяет переключить его без клавиш.
6. **Завершение.** По `ESC`, гибели персонажа или истечении часа запись завершается: управление возвращается игре, HUD и FOV восстанавливаются, файл демо закрывается и остаётся в папке сохранений.
