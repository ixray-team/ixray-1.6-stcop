# Компиляторы
> [!IMPORTANT]  
> **Статус**: Поддерживается <br>
> **Минимальная версия**: 1.4

![image](https://github.com/user-attachments/assets/ef90d5a5-d2c9-4ff1-a539-a3a8e2cf5a10)

* Исправлена инициализация количества потоков
* * Создаётся кол-во равное процессору 
* Добавлена поддержка **IntelEmbree** и **CUDA** трейсинга, многократно увеличивающая скорость 
* Вывод всех отсутствующих текстур и thm 
* Удалена `net` компиляция 
* Поддержка BC7 формата 
* Поддержка разбития `level.cform` и `level.geom` на несколько файлов по размеру
* Возможность переопределять качество компиляции без запуска `Level Editor`

## LC
* Пропуск `invalid faces`
* Новый алгоритм сохранения LightMaps
* * Запекается в выбранный размер текстур с более быстрой выборкой 
* Исправлен оригинальный баг, при котором иногда MU модели становились чёрными 
* Возможность пропуска тесселяции геометрии 
* Возможность пропуска subdivide стадии 
* Оптимизирована `geometry merge` стадия 
* Многопоточная компиляция секторов на локации 
* Убрано использование QSlim для оптимизации CForm уровня (Временное решение)
* Удалён старый dx9mesh оптимизатор для геометрии
* * Теперь используется современная DirectXMesh библиотека 
* Режим сохранения LightMap:
* * Без сжатия `RBGA`
* * DX11 Only `BC7`
* * Vanilla `DXT3` 

## DO
* Трава сохраняется в DXT3 

## AI
* Реимплементирован алгоритм AStart
* Поддержка 25 bit'ной сетки
* * Компилятор основывается на формате `build.aimap` для выходного формата `level.aimap`
* Автоматическая сборка `.spawn` файла под формат **FreeMP**
