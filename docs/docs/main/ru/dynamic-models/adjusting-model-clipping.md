# Регулировка отсечения моделей
## Renderable

> [!IMPORTANT]
> **Статус**: Поддерживается <br>
> **Минимальная версия**: 1.1

Добавлена возможность установить значение для отсечения геометрии по SSA **(опционально)**. Используйте, если объект начинает частично пропадать.

```ini
ssa_dyn_factor = 0.001
ssa_d_cam      = 300.0
```
