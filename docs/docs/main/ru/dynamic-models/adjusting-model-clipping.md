# Регулировка отсечения моделей

> [!IMPORTANT]
> **Статус**: Поддерживается <br>
> **Минимальная версия**: 1.1

## Обзор

Добавлена возможность установить значение для отсечения геометрии по <abbr title="Screen-Space Culling">SSA</abbr> **(опционально)**. Используйте, если объект начинает частично пропадать.

```ltx
ssa_dyn_factor = 0.001
ssa_d_cam      = 300.0
```
