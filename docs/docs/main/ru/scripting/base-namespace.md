# Базовое пространство имён
## Обзор

> [!IMPORTANT]
> **Статус**: Поддерживается <br>
> **Минимальная версия**: 1.0

Расширение стандартного функционала Lua путём использования сторонних библиотек, **не относящихся к API X-Ray Engine**

## LuaJIT

* [ffi](https://luajit.org/ext_ffi_semantics.html)
* jit
* [bit](https://docs.gamesense.gs/docs/api/bit/)
