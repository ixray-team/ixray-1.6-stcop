
# IXR Framework (LUA Фреймворк)
> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: 1.4.0

## Модуль логирования IXR LOGS
* Предназначен для центролизованного управления логированием для скриптов с привязкой настроек к контексту вызывающего скрипта (это значит что вам больше не нужно изобретать в каждом вашем скрипте собственную систему логирования или управление уровнями логировать в файл в консоль или оба варианта сразу) 
* Данный компонент значительно упрощает управление логированием не требуя писать собственную логику в саммо скрипте
* Логи записываются по умолчанию в $logs$ путь настроенный в файле fsgame.ltx
* Для каждого вызывающего скрипта создаётся именной лог с именем этого скрипта как пример __log__my_script.txt
* * Все выполняемые методы из данного раздела привязываются к конкретному скрипту изнутри которого вы вызываете действия и не влияет на прочие логи системы, таким образом вы можете удобным способом настраивать для каждого скрипта персональное поведение логирования

Система централизованного логирования особенности:
* Настройки логирования строго изолированы друг от друга и задаются для скрипта из которого был выполнен один из методов:
* * IXRLogUseFileLog
* * IXRLogUseConsoleLog
* * IXRLogUseTimeInLog
* * IXRLogEmptyLine
* * IXRLogClear
* * IXRLog

Управление через глобальные методы:
```lua

--// Включить или отключить запись в файл для вызывающего скрипта (не глобально).
IXRLogUseFileLog(flag, custom_script)
args:
  flag (boolean)(required)          - true — включить, false — отключить.
  custom_script (string)(optional)  - идентификатор целевого скрипта (имя файла). Если не указан, используется вызывающий скрипт.
retval: (any) - результат выполнения ixr_logs.set_use_file_log.

--// Включить или отключить вывод в консоль для вызывающего скрипта (не глобально).
IXRLogUseConsoleLog(flag, custom_script)
args:
  flag (boolean)(required)          - true — включить, false — отключить.
  custom_script (string)(optional)  - идентификатор целевого скрипта (имя файла). Если не указан, используется вызывающий скрипт.
retval: (any) - результат выполнения ixr_logs.set_use_console_log.

--// Включить или отключить добавление временной метки в записи для вызывающего скрипта (не глобально).
IXRLogUseTimeInLog(flag, custom_script)
args:
  flag (boolean)(required)          - true — добавлять метку, false — не добавлять.
  custom_script (string)(optional)  - идентификатор целевого скрипта (имя файла). Если не указан, используется вызывающий скрипт.
retval: (any) - результат выполнения ixr_logs.set_use_time.

--// Записать текстовое сообщение в лог вызывающего скрипта. Учитываются текущие настройки этого скрипта (файл, консоль, метка времени), которые по умолчанию включены. Если вы предварительно отключили что-либо через соответствующие IXRLogUse…, это повлияет на вывод.
IXRLog(text, clear_log, custom_script)
args:
  text (string)(required)           - сообщение для записи.
  clear_log (boolean)(optional)     - если true, очищает лог перед записью (по умолчанию false).
  custom_script (string)(optional)  - идентификатор целевого скрипта (имя файла). Если не указан, используется вызывающий скрипт.
retval: (any) - результат выполнения ixr_logs.log.

--// Вставить одну или несколько пустых строк в лог вызывающего скрипта.
IXRLogEmptyLine(pereat_cnt, custom_script)
args:
  pereat_cnt (number)(required)     - количество пустых строк для вставки.
  custom_script (string)(optional)  - идентификатор целевого скрипта (имя файла). Если не указан, используется вызывающий скрипт.
retval: (any) - результат выполнения ixr_logs.empty_line.

--// Очистить весь лог вызывающего скрипта.
IXRLogClear(custom_script)
args:
  custom_script (string)(optional)  - идентификатор целевого скрипта (имя файла). Если не указан, используется вызывающий скрипт.
retval: (any) - результат выполнения ixr_logs.clear_log.
```

Примеры реализации:
```lua
--// Создаём переменные константы для удобства в начале файла скрипта
local USE_FILE_LOG = true
local USE_CONSOLE_LOG = false
local USE_TIME_IN_LOGS = true

--// Один раз где нибудь инициализируем настройки (можно обновлять но лучше если будет вызываться 1 раз для оптимизации либо описать логику управления полями с обновлением если нужно)
IXRLogUseFileLog(USE_FILE_LOG)
IXRLogUseConsoleLog(USE_CONSOLE_LOG)
IXRLogUseTimeInLog(USE_TIME_IN_LOGS)

--// В качестве оптимального примера будем использовать Модуль Автозагрузки чтобы единожды выполнить логику
function on_game_start()
  --// Содержимое метода автоматически выполнится при старте главного меню игры и еще раз повторно в начале симуляции локации
  IXRLogUseFileLog(USE_FILE_LOG)
  IXRLogUseConsoleLog(USE_CONSOLE_LOG)
  IXRLogUseTimeInLog(USE_TIME_IN_LOGS)
end

--// В качестве примера напишем что нибудь в лог внутри произвольной функции
function some_method()
  IXRLog("Hello world") -- с текущими настройками лог будет записан и в файл и в консоль
end

--// Для еще более прсотого примера можно вообще не указывать никаких настроек предварительно - в этом случае лог будет записан и в файл и в консоль с указанием даты и времени
--// Можно не создавать отдельных переменных а напрямую манипулировать настройками:
IXRLogUseFileLog(true)
IXRLogUseConsoleLog(true)
IXRLogUseTimeInLog(true)

--// Помним что все выполняемые методы из данного раздела привязываются к конкретному скрипту изнутри которого вы вызываете действия и не влияет на прочие логи системы, таким образом вы можете удобным способом настраивать для каждого скрипта персональное поведение логирования
```
