# IXR Framework (LUA Фреймворк)
> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: 1.4.0

Компоненты внешне похожи на модули но не требуют инициализации и поэтому действия с ними доступны в реальном времени независимо от состояния системы

### Публичные компоненты: ..\gamedata\scripts\ixr_framework\public_components\*.script
```ini
ixr_logs.script
ixr_tracy_profiler.script
```

### Системные компоненты: ..\gamedata\scripts\ixr_framework\system_components\*.script
```ini
ixr_callback_binder.script
ixr_npc_info.script
```
