# Лимиты ID

> [!IMPORTANT]
> **Минимальная версия**: 1.5

## Нововведения

В связи с тем, что существуют моды в принципе, которые ударились в лимиты по ID, в IX-Ray были расширен диапазон возможных значений для Object ID: с 65535 значений до 2^32 - 1, или около 4 миллиардов. Хотя это только расширение и лимит есть, потолок поднят настолько высоко, что практически невозможно будет к нему приблизиться.

> [!IMPORTANT]
> Расширение ID затронуло глобально все аспекты работы движка с нетпакетами, из-за чего нарушена совместимость спавна, собранного для IX-Ray, с компиляторами и движками без поддержки 32-х битных ID, а также инструментами работы с данными из нетпакетов. Однако, старые версии спавна, собранные с 16-ти битными ID по прежнему поддерживаются. 

## Невалидное значение ID

Для того, чтобы мододелу не запоминать точное значение невалидного ID, введена константа `alife_const.invalid_object_id`.

## Итерация по всем ID

Несмотря на то, что рекомендуется не использовать итерацию по всем ID, в движок введен экспорт функции `alife():last_valid_id()`, которое вернёт значение ID, которое гарантировано не меньше, чем наибольший валидный ID на текущий момент. Генератор значений ID был переписан так, чтобы генерировать значений ID как можно более плотно, поэтому даже если будет происходить итерация по ID от 0 до `alife():last_valid_id()`, будет намного меньше пробелов, чем в оригинале.
