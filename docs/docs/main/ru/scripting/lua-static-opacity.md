# Прозрачность контролов UI

> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: 1.5.0

* `SetOpacity`
* `SetTreeOpacity`
* `SetBackgroundOpacity`
* `SetBorderOpacity`

#### Описание методов:

Значения ограничиваются диапазоном от `0` до `1`.
Без вызова методов исходная альфа цветов сохраняется.

### Прозрачность выбранного контрола

Доступен у `CUIWindow` и его наследников.
Личный множитель хранится как `float`, по умолчанию равен `1`.
Применяется ко всему собственному оформлению контрола: тексту, текстуре,
заливке и рамке. Дочерние контролы не затрагиваются.
Цвета компонентов не изменяются: `0` скрывает собственное оформление,
`1` возвращает его исходную альфу с учётом множителей дерева.

```lua
--// Задать личный множитель непрозрачности контрола.
control:SetOpacity(value)
args:
  value (number) - множитель от 0 до 1; по умолчанию 1
retval: (void)
```

### Прозрачность дерева

Доступен у `CUIWindow` и его наследников.
Множитель ветки хранится отдельно, по умолчанию равен `1`.
Применяется к текущему контролу и всем его потомкам.
Личные множители и множители вложенных веток сохраняются.
Повторный вызов заменяет множитель только текущей ветки.
Контролы, добавленные в неё позже, также учитывают этот множитель.

Итоговая альфа равна альфе компонента, умноженной на личный `SetOpacity`
и все множители `SetTreeOpacity` от текущего контрола до корня дерева.
Например, два множителя ветки `0.5` дают `0.25` исходной альфы.
`SetTreeOpacity(1)` снимает влияние своего множителя, сохраняя остальные.
Перекрывающиеся контролы смешиваются по альфе в порядке отрисовки.

```lua
--// Задать множитель непрозрачности текущей ветки.
control:SetTreeOpacity(value)
args:
  value (number) - множитель от 0 до 1; по умолчанию 1
retval: (void)
```

### Прозрачность фона

Доступен у следующих классов и их наследников:

* `CUIStatic`
* `CUIFrameWindow`
* `CUIFrameLineWnd`

Меняет альфу активного фона, сохраняя RGB. При включённой установленной текстуре
меняется альфа её цвета. У статика без текстуры или после `TextureOff()` меняется
альфа заливки, заданной через `SetBackgroundColorARGB`.
Если фон не задан, метод ничего не меняет.
Текст, рамка и дочерние контролы не затрагиваются.

`0` задаёт альфу `0`, `1` задаёт `255`.
Для текстуры последний вызов `SetBackgroundOpacity` или установки её цвета
определяет альфу. Для заливки — `SetBackgroundOpacity` или `SetBackgroundColorARGB`.
Метод меняет только активный фон в момент вызова.
`SetOpacity` и `SetTreeOpacity` продолжают действовать как отдельные множители.

```lua
--// Заменить альфу активного фона контрола.
control:SetBackgroundOpacity(value)
args:
  value (number) - непрозрачность от 0 до 1; альфа округляется до целого от 0 до 255
retval: (void)
```

### Прозрачность рамки

Доступен у `CUIStatic` и его наследников, поддерживающих `SetBorder`.
Меняет только альфу цвета заданной рамки, сохраняя RGB, толщину и радиус.
Без предварительного `SetBorder` метод ничего не меняет.
`0` задаёт альфу `0`, `1` задаёт `255`.
Последний вызов `SetBorderOpacity` или `SetBorder` определяет альфу рамки.
Невидимая рамка сохраняет отсечение.
`SetOpacity` и `SetTreeOpacity` действуют как отдельные множители.

```lua
--// Заменить альфу цвета рамки.
control:SetBorderOpacity(value)
args:
  value (number) - непрозрачность от 0 до 1; альфа округляется до целого от 0 до 255
retval: (void)
```

### Примеры использований:

В примерах `child` — существующий дочерний контрол `parent`.

#### Только выбранный контрол

```lua
parent:SetOpacity(0.5) -- Прозрачность child не изменяется.
```

#### Вся ветка

```lua
parent:SetTreeOpacity(0.5)
```

#### Независимые множители вложенных веток

```lua
parent:SetTreeOpacity(0.5)
child:SetTreeOpacity(0.5) -- Ветка child получает множитель 0.25.
parent:SetTreeOpacity(1) -- Множитель ветки child снова 0.5.
```

#### Только фон

```lua
control:SetBackgroundOpacity(0.5)
```

#### Только рамка

```lua
control:SetBorderOpacity(0.5)
```

#### Порядок установки цвета текстуры

```lua
control:SetTextureColor(GetARGB(100, 255, 0, 0)) -- Альфа 100.
control:SetBackgroundOpacity(0.5)              -- Альфа 128, RGB сохранён.
control:SetTextureColor(GetARGB(60, 0, 255, 0))  -- Альфа 60 и новый RGB.
```
