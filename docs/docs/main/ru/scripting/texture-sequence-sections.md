# Именованные секции текстурных SEQ

Расширение позволяет переключать анимации текстуры из C++ и Lua. Оно не зависит от курсора: имена секций произвольны. Для разных подсистем используйте разные префиксы.

Настройка стандартного курсора, действий мыши и разминки: [анимированный курсор и состояния SEQ](../interface/animated-cursor.md).

## Формат

```ini
60
ui\original_1
ui\original_2

[cursor_grab]
frames = ui\cursor\grab_{1..24}, 80

[cursor_release]
frame = ui\cursor\release_1, 100
frames = ui\cursor\release_{2..16}, 60
next = default
```

Вне секций сохраняется оригинальное чтение: необязательная первая строка `cycled`, затем FPS, затем имена текстур до первого заголовка секции. `cycled` сохраняет исходное движение вперёд-назад, включая крайние кадры. Вне секций не используются новые ключи, комментарии и миллисекундный синтаксис. Частота переводится в целые миллисекунды по старому правилу `1000 / FPS`; для некорректного FPS выдаётся диагностика, деления на ноль нет.

В именованных секциях:

- `frame = путь, миллисекунды` добавляет отдельный кадр.
- `frames = путь_{начало..конец}, миллисекунды` разворачивает включительный диапазон с шагом 1.
- `{0..20..2}` задаёт положительный шаг. Числа выводятся без дополнения нулями. Если шаг не попадает точно в верхнюю границу, последний кадр — последний номер ниже неё.
- Строки `frame` и `frames` можно повторять и смешивать; порядок сохраняется.
- Длительность каждого кадра — положительное целое число миллисекунд. Нулевые тайминги, шаг 0 и убывающие диапазоны отклоняются. Для защиты от ошибочного диапазона больше миллиона шагов не разворачивается.
- `next = имя` переходит в другую секцию по завершении последнего кадра; `next = default` возвращает исходную последовательность.
- Без `next` последний кадр удерживается до внешней команды. `next` на собственную секцию делает цикл.
- Имена чувствительны к регистру. Пустые/повторяющиеся секции, имя `default`, неизвестный `next` и ошибочные строки дают диагностику. При ошибке расширения сохраняется исходная последовательность, дополнительные кадры не загружаются.
- Внутри секций допустимы пустые строки и комментарии после `;`.

## Управление

```lua
activate_seq_section("cursor_grab")
activate_seq_section("cursor_release", true)
deactivate_seq_section("cursor_grab")
activate_seq_section("cursor_scroll_up", false, true)
```

Сигнатуры C++:

```cpp
bool ActivateSequenceSection(const char* Name, bool WaitForEnd = false, bool Restart = false);
bool DeactivateSequenceSection(const char* Name, bool WaitForEnd = false);
```

Lua предоставляет те же необязательные аргументы. `WaitForEnd = false` переключает немедленно, `true` ждёт завершения текущего прохода. Для уже удерживаемого последнего кадра ожидание завершено. Немедленная команда сбрасывает ожидающий переход. Повторная активация активного имени без `Restart` — пустая операция; `Restart = true` перезапускает выбранную секцию; приоритет не меняется.

Методы изменяют общий реестр имён. Анимации без подходящей секции игнорируют имя. Из нескольких активных имён выбирается секция, объявленная выше остальных в SEQ. Порядок активации не влияет на приоритет. После деактивации выбирается следующая по порядку активная секция, либо `default`. Команду можно отправить до загрузки текстуры: регистрация нового ресурса применит текущее состояние реестра. `true` в результате означает изменение реестра, а не гарантию существования секции в конкретном ресурсе.

Завершение цепочки через `next = default` само не удаляет имя из общего реестра, поскольку у других ресурсов может быть другая длительность этой секции. Владелец состояния должен снимать его явно; повторный одноразовый эффект может использовать `Restart = true`. Визуальная анимация не выполняет игровые действия и не заменяет игровую логику.

## Время, ресурсы и потоки

Файл открывается один раз в загрузчике `CTexture` и закрывается до воспроизведения. Имена и диапазоны разбираются в память. Ресурсы одинаковых путей кадров внутри файла используются повторно. Сканирования файлов или реестра на каждом кадре нет: реестр уведомляет подписчиков только при командах/регистрации, команда передаётся в рендер через защищённый буфер. Из Lua не выполняются GPU-вызовы.

Время новых секций считается по разнице реальных миллисекунд `Device.dwTimeContinual`, сохраняется остаток при переходах; несколько вызовов отрисовки за один момент не ускоряют анимацию. При просадках пропущенные кадры не растягивают движение, циклы пропускаются целиком с сохранением фазы. Невозможно отобразить каждый промежуточный кадр при недостаточном FPS. После выгрузки текстуры повторная загрузка читает файл заново.

Состояние воспроизведения принадлежит ресурсу `CTexture`: объекты с одной текстурой воспроизводятся совместно. Все кадры одной последовательности должны иметь согласованные размеры и формат. Память под дополнительные уникальные изображения расходуется при загрузке.

Расширенные файлы требуют обновлённого движка: старый загрузчик воспримет строки секций как имена текстур. Старые файлы без секций продолжают работать в обновлённом загрузчике.

### Повторение секций

`loop = true` повторяет кадры секции по кругу. `loop = false` (по умолчанию) проигрывает один проход: без `next` удерживает последний кадр, с `next` переходит в указанную секцию. `loop = true` нельзя сочетать с переходом в другую секцию или default. Старый способ `next = имя_этой_же_секции` также создаёт цикл. Исходный блок вне секций не изменён.

```ini
[cursor_select]
loop = true
frames = ui\hand_select_{1..4}, 120

[cursor_grab]
loop = false
frames = ui\hand_grab_{1..8}, 80

[cursor_release]
loop = false
frames = ui\hand_release_{1..8}, 80
next = default
```

Повторение задаётся в SEQ; внешняя команда может сменить секцию. Ручные активации снимает вызывающий код или скрипт.
