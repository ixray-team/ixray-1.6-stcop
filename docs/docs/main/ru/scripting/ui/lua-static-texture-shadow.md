# Отбрасывание теней от текстур статиков

> [!IMPORTANT]
> **Статус**: Реализовано в исходниках текущей ветки<br>
> **Доступность**: Рендерер D3D11 (R4), требуются совместимые модули движка и шейдеры основной gamedata.

* `SetBlurredTextureShadow`
* `SetBlurredTextureShadowHeight`
* `SetBlurredTextureShadowLightRadius`
* `SetBlurredTextureShadowFalloff`
* `SetBlurredTextureShadowOpacityRange`
* `SetBlurredTextureShadowColor`
* `GetBlurredTextureShadowEnabled`

#### Описание методов:

### Тень по альфа-каналу текстуры

Методы доступны у `CUIStatic` и его наследников. Тень повторяет непрозрачные области основной текстуры, проецируется от заданного источника и размывается. Прозрачные отверстия текстуры учитываются. Это UI-проекция силуэта на принимающую плоскость, а не расчёт теней геометрии игрового мира.

Методы не требуют включения фонаря, маски света или бленда двух текстур. Тень не является тенью всего поддерева: текст, заливка и дочерние контролы не включаются автоматически в силуэт основной текстуры. У дочерних статиков могут быть собственные тени.

```lua
--// Включить проецируемую тень и задать параметры размытия и источник.
control:SetBlurredTextureShadow(enabled, blur, opacity, radius, light_x, light_y)
args:
  enabled (boolean) - включение тени; по умолчанию выключена
  blur (number) - ширина гауссового размытия, 0..128; 0 отключает размытие
  opacity (number) - максимальная интенсивность тени, 0..1
  radius (number) - радиус области размытия в единицах UI, 0..128; 0 даёт резкий силуэт
  light_x (number) - горизонтальная координата источника в корневом UI, -8192..8192
  light_y (number) - вертикальная координата источника в корневом UI, -8192..8192
retval: (void)

--// Получить флаг включения тени, независимо от наличия видимого результата.
control:GetBlurredTextureShadowEnabled()
args: нет
retval: (boolean) - флаг включения тени у этого статика
```

Эффективная непрозрачность зависит также от альфы исходной текстуры, цвета статика и цвета тени. Отключённая текстура или отсутствие действующего шейдера не дают тени. Регионы атласов учитываются без захвата соседних изображений.

### Высота статика и источника

```lua
--// Задать виртуальные высоты над принимающей плоскостью UI.
control:SetBlurredTextureShadowHeight(height, light_height)
args:
  height (number) - высота отбрасывающего тень статика, 0..1024; по умолчанию 4
  light_height (number) - высота источника, 1..4096; по умолчанию 300
retval: (void)
```

Размер и смещение проекции определяет отношение `light_height / (light_height - height)`. При нулевой высоте силуэт совпадает с исходной текстурой и может полностью скрываться за ней. При приближении высоты статика к высоте источника проекция сильно растёт. Если `height >= light_height`, тень не рисуется.

Координаты источника задаются в корневом UI, а не относительно статика. Положение, размер и повороты статика учитываются при расчёте проекции. Высота является параметром эффекта: она не меняет порядок отрисовки или действительное положение UI-объекта в 3D.

### Размер источника и мягкость полутени

```lua
--// Включить расчёт полутени от источника конечного размера.
control:SetBlurredTextureShadowLightRadius(radius)
args:
  radius (number) - виртуальный радиус источника, 0..4096; по умолчанию 0
retval: (void)
```

При положительном радиусе источника, положительных `blur` и `radius` мягкость полутени зависит от геометрии проекции и угла луча к плоскости. При `light_radius = 0` используется обычное размытие силуэта. Это не тот же параметр, что `radius` в `SetBlurredTextureShadow`: один задаёт размер источника, другой — область обычного размытия.

### Спад и интенсивность

```lua
--// Управлять ослаблением мягкого края тени.
control:SetBlurredTextureShadowFalloff(falloff)
args:
  falloff (number) - параметр спада, 0..12; по умолчанию 0
retval: (void)

--// Задать максимальную интенсивность и обработку слабого хвоста тени.
control:SetBlurredTextureShadowOpacityRange(minimum, maximum)
args:
  minimum (number) - порог слабого хвоста, 0..maximum; по умолчанию 0
  maximum (number) - максимальная интенсивность тени, 0..1
retval: (void)
```

`maximum` заменяет значение `opacity`, установленное основным методом. `minimum` не задаёт нижнюю границу непрозрачности: слабый хвост ниже порога плавно гасится, а не поднимается до этого значения. При `minimum = 0` дополнительное гашение хвоста выключено, поэтому `falloff` сам по себе не меняет результат. Спад использует степень `max(falloff / 3, 1)`: значения до 3 не усиливают его дополнительно.

При повторном вызове `SetBlurredTextureShadow` максимальная интенсивность снова берётся из `opacity`, а сохранённый минимальный порог ограничивается новым максимумом. Сначала вызывайте основной метод, затем настраивайте диапазон.

### Цвет тени

```lua
--// Назначить цвет и дополнительный альфа-множитель тени.
control:SetBlurredTextureShadowColor(color)
args:
  color (number) - упакованный ARGB, например GetARGB(255, 0, 0, 0); по умолчанию непрозрачный чёрный
retval: (void)
```

Для обычной затемняющей тени используйте чёрный RGB. Альфа цвета умножает интенсивность тени; она не заменяет альфу текстуры. Не используйте светлый цвет для имитации обычного затемнения: это цветное наложение силуэта.

### Порядок отрисовки и вложенность

Обычно тень рисуется непосредственно перед собственной текстурой статика. Она влияет на уже нарисованное содержимое и не переносится автоматически поверх последующих элементов. Это порядок UI, а не проверка физических высот принимающих объектов.

В изолированном контейнере размытая тень сохраняет альфа-покрытие принимающей поверхности: она не создаёт непрозрачный силуэт в прозрачных отверстиях. Собственная тень изолированного статика отрисовывается в родительском слое до открытия его промежуточной цели; тени потомков остаются в обычном порядке внутри контейнера.

Несколько текстурных кусочков, вместе образующих непрозрачную панель, могут принимать непрерывную тень, если нарисованы раньше отбрасывающего её элемента в общем принимающем контейнере. Нижние независимые слои за прозрачными отверстиями изолированного контейнера не получают тени его потомков. Подробнее: [изоляция контейнера и тени](lua-static-volumetric-light.md#изоляция-контейнера-и-тени).

Силуэт берётся из основной текстуры даже при включённом бленде двух текстур. Изменение силуэта по проявляющейся альтернативной текстуре сейчас не реализовано. Маска фонаря также не является маской силуэта тени.

### Примеры использований:

`control` — уже отображаемый статик с текстурой.

```lua
--// Включить тень от источника над правой частью UI.
control:SetBlurredTextureShadow(true, 3.5, 0.65, 9, 855, 158)
--// Небольшой подъём статика над принимающей поверхностью.
control:SetBlurredTextureShadowHeight(3, 300)
--// Задать конечный размер источника для мягкой полутени.
control:SetBlurredTextureShadowLightRadius(5)
--// Настроить плавное исчезновение слабого края.
control:SetBlurredTextureShadowOpacityRange(0.01, 0.65)
--// Дополнительно ослабить хвост.
control:SetBlurredTextureShadowFalloff(6)
--// Сохранить обычный чёрный цвет тени.
control:SetBlurredTextureShadowColor(GetARGB(255, 0, 0, 0))
```

Перемещение источника выполняет скрипт; отдельного автоматического слежения за курсором у тени нет:

```lua
--// Передать позицию UI-курсора как новое положение источника, сохраняя параметры тени.
local cursor = GetCursorPosition()
control:SetBlurredTextureShadow(true, 3.5, 0.65, 9, cursor.x, cursor.y)
```

Отключение:

```lua
--// Выключить отрисовку тени.
control:SetBlurredTextureShadow(false, 3.5, 0.65, 9, 855, 158)
```

### Настройка через XML

Вложенный узел `blurred_shadow` внутри описания статика задаёт те же параметры. При отсутствии узла тень выключена. `opacity_max`, если указан, имеет приоритет над `opacity`. Цвет читается стандартным XML-механизмом цветов UI.

```xml
<static x="0" y="0" width="200" height="200" stretch="1">
    <texture>ui\example\panel</texture>
    <blurred_shadow enabled="1" blur="3.5" radius="9"
                    opacity="0.65" opacity_min="0.01" opacity_max="0.65"
                    light_x="855" light_y="158" height="3" light_height="300"
                    light_radius="5" falloff="6" />
</static>
```

Размытие требует дополнительных выборок текстуры. Стоимость большого числа перекрывающихся теней следует проверять на целевом разрешении. Тени текстур не заменяют существующие методы обводки текстуры или тени текста.
