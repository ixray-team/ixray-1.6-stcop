# Рамка и скругление статика

> [!IMPORTANT]
> **Статус**: Поддерживается<br>
> **Минимальная версия**: 1.5.0

* `SetBorder`

#### Описание методов:

### Рамка и отсечение содержимого

Метод доступен у `CUIStatic` и его наследников.
Рамка рисуется внутрь контура поверх содержимого. Скругление отсекает заливку,
текстуру, текст и дерево дочерних контролов. Вложенные маски пересекаются.
Дочерний статик может иметь собственную текстуру, рамку и радиус скругления.
Его содержимое и рамка отсекаются контуром родителя; рамка родителя рисуется сверху.
Контур совпадает с областью заливки или отображаемой текстуры.
Края сглаживаются. Маска и рамка учитывают локальный и каскадный поворот,
включая плавный переход угла. Наведение и нажатия учитывают отсечённые углы.
В экранном UI толщина и радиус используют вертикальный масштаб UI по обеим осям:
рамка имеет одинаковую толщину, дуги не растягиваются по ширине.
Внутренний радиус равен внешнему радиусу минус толщина рамки, минимум `0`.

Нулевая толщина или альфа скрывают рамку, сохраняя отсечение содержимого.
Радиус `0` задаёт прямоугольный контур. Радиус ограничивается половиной
меньшей стороны: у квадратного на экране контрола максимальный радиус даёт круг.
Для круга с одинаковыми заданными шириной и высотой включите
`control:SetUseAspectRatioCorrection(true)` и задайте радиус не меньше половины
стороны. Коррекция сохраняет пропорции при смене разрешения и соотношения сторон.
Без вызова `SetBorder` рамка и отсечение не включены.

```lua
--// Настроить рамку и форму отсечения статика.
control:SetBorder(thickness, radius, color)
args:
  thickness (number) - толщина рамки в единицах UI; отрицательное значение заменяется на 0; максимум — половина меньшей стороны
  radius (number) - радиус скругления в единицах UI; отрицательное значение заменяется на 0; максимум — половина меньшей стороны
  color (number) - цвет рамки с альфой, например GetARGB(255, 255, 0, 0)
retval: (void)
```

### Примеры использований:

`control` — уже созданный отображаемый статик.

#### Видимая рамка

```lua
control:SetBorder(2, 16, GetARGB(255, 255, 0, 0))
```

#### Скругление без видимой рамки

```lua
control:SetBorder(0, 24, GetARGB(0, 0, 0, 0))
```

#### Круг с коррекцией пропорций

```lua
control:SetWndSize(vector2():set(200, 200))
control:SetUseAspectRatioCorrection(true)
control:SetBorder(4, 100, GetARGB(255, 255, 255, 255))
```

#### Скругление вложенных контролов

`control` — уже отображаемый родительский статик.

```lua
control:SetBorder(2, 24, GetARGB(255, 255, 0, 0))

local xml = CScriptXmlInit()
local child = xml:InitNoXmlStatic("child", 180, 100, 160, 120, control)
child:SetBorder(2, 12, GetARGB(255, 255, 255, 255))
```
