# Маскированное смешивание текстур

> [!IMPORTANT]
> **Статус**: Реализовано в исходниках текущей ветки<br>
> **Доступность**: Экранный UI, D3D11 (R4). Требуются совместимые модули движка и шейдеры основной gamedata.

* `InitAltTexture`
* `SetTextureBlendMask`
* `SetTextureBlendMaskPosition`

#### Описание методов:

### Две текстуры одного статика

Методы доступны у `CUIStatic` и его наследников. Основная текстура задаётся обычным `InitTexture`, альтернативная — `InitAltTexture`. Шейдер смешивает их по красному каналу отдельной маски: чёрный оставляет основную, белый проявляет альтернативную, серый даёт промежуточный результат. Прозрачность смешивается через premultiplied alpha, чтобы прозрачные участки не создавали цветные ореолы.

Механизм независим от света, тональной обработки, луча и пыли. Подходит для проявления изображений, шкал, индикаторов и переключения состояний. Текстуры сопоставляются по локальным координатам исходного изображения; поддерживается пересчёт прямоугольников атласов. Маска — целая растровая текстура, не имя региона атласа.

```lua
--// Назначить альтернативную текстуру; пустая строка отключает альтернативу.
control:InitAltTexture(texture)
args:
  texture (string) - путь или зарегистрированное имя альтернативной текстуры; пустая строка отключает альтернативу
retval: (void)

--// Назначить маску смешивания, её размеры, масштаб и источник координат.
control:SetTextureBlendMask(texture, x, y, width, height, scale, is_use_mouse_position)
args:
  texture (string) - путь к текстуре маски; пустая строка отключает маску для этого поддерева, включая наследуемую
  x (number) - горизонтальный центр относительно левого верхнего угла статика, -8192..8192
  y (number) - вертикальный центр относительно левого верхнего угла статика, -8192..8192
  width (number) - ширина маски в единицах UI, 0..8192
  height (number) - высота маски в единицах UI, 0..8192
  scale (number) - масштаб размеров, 0..64
  is_use_mouse_position (boolean) - автоматически брать центр из позиции UI-курсора
retval: (void)

--// Переместить маску смешивания относительно статика и отключить привязку к курсору.
control:SetTextureBlendMaskPosition(x, y)
args:
  x (number) - горизонтальный центр относительно статика, -8192..8192
  y (number) - вертикальный центр относительно статика, -8192..8192; вызов отключает привязку к курсору
retval: (void)
```

Альфа маски не используется. За её прямоугольником коэффициент равен нулю. Нулевой размер или масштаб отключает маску. Без действующей маски или без альтернативной текстуры статик отображается обычным способом. Реализация предназначена для экранных статиков, не для мирового 3D UI.

### Наследование и независимые маски

Маска родительского статика наследуется потомками. Каждый потомок задаёт свою пару текстур. Собственная маска ребёнка заменяет родительскую только внутри его поддерева. После отрисовки восстанавливается прежняя маска, поэтому соседние статики могут одновременно иметь разные маски, размеры и позиции.

Маска использует экранные координаты. Ручной центр преобразуется с учётом положения статика; её прямоугольник остаётся экранным. Не следует считать её произвольно вращаемой или перспективно деформируемой маской поверхности.

### Примеры использований:

```lua
--// Назначить основную текстуру статика.
control:InitTexture([[ui\gauges\empty]])
--// Назначить альтернативную текстуру; пустая строка отключает альтернативу.
control:InitAltTexture([[ui\gauges\filled]])
--// Назначить маску смешивания, её размеры, масштаб и источник координат.
control:SetTextureBlendMask([[ui\masks\soft_rectangle]], 50, 100, 100, 200, 1, false)

--// Двигать мягкую границу шкалы независимо от остальных статиков.
control:SetTextureBlendMaskPosition(50, 140)
```

Для нескольких шкал можно использовать один файл маски, задавая каждому статику собственный центр. Чтобы видеть только одну движущуюся границу прямоугольной маски, противоположную границу расположите за пределами шкалы.

Пример проявления от курсора:

```lua
--// Назначить маску смешивания, её размеры, масштаб и источник координат.
control:SetTextureBlendMask([[ui\masks\radial]], 0, 0, 300, 300, 1, true)
```

Тени текстуры в текущем проходе строятся по основной текстуре: динамическое изменение силуэта тени вслед за альфой альтернативы не реализовано.
