#### Описание методов:

### Коррекция пропорций

Метод доступен у `CUIWindow` и его наследников. По умолчанию выключен.
Коррекция умножает экранную позицию X относительно родителя и ширину на
`ui.get_current_kx()`. Позиция Y и высота сохраняются.
Геттеры возвращают исходные значения; сеттеры не требуют пересчёта.
Текущий коэффициент применяется при отрисовке и проверке мыши.
При изменении разрешения или соотношения сторон используется новый коэффициент;
повторный вызов метода не требуется. Размеры и позиции можно менять любыми
доступными сеттерами: коррекция не накапливается.
Текст, текстуры, заливка и рамка отображаются с учётом коррекции.

Коррекция распространяется на дочерние контролы. Повторное включение в той же
ветке не умножает коэффициент повторно. `false` снимает собственный флаг;
коррекция родителя продолжает действовать.
Локальные и каскадные повороты учитывают исправленные пропорции без перекоса.
Метод применяется к экранному UI.

```lua
--// Включить или выключить коррекцию пропорций при отображении.
control:SetUseAspectRatioCorrection(enabled)
args:
  enabled (boolean) - true включает коррекцию; false отключает собственный флаг; по умолчанию false
retval: (void)
```

### Прозрачность

Доступны у `CUIWindow` и его наследников.
Личный множитель действует только на оформление выбранного контрола.
Множитель дерева действует также на всех потомков.
Оба хранятся отдельно, по умолчанию равны `1` и не изменяют альфу в цветах.
Множители вложенных веток перемножаются, сохраняя личные настройки контролов.

```lua
--// Задать личный множитель непрозрачности.
control:SetOpacity(value)
args:
  value (number) - множитель от 0 до 1; по умолчанию 1
retval: (void)

--// Задать множитель непрозрачности текущего контрола и всех потомков.
control:SetTreeOpacity(value)
args:
  value (number) - множитель от 0 до 1; по умолчанию 1
retval: (void)
```

### Видимость и наведение

`IsShown` проверяет собственную видимость.
`IsCursorOverWindow(true)` учитывает вложенность и перекрытие;
без аргумента проверяется попадание в прямоугольник при обновлении.
Обе проверки наведения и события входа/выхода учитывают поворот контрола
и его родителей, а также отсечение скруглёнными контурами.
Прозрачные пиксели текстуры не учитываются.

```lua
--// Показать или скрыть контрол.
control:Show(visible)
args:
  visible (boolean) - true показывает и включает контрол; false скрывает и отключает
retval: (void)

--// Получить собственный флаг видимости.
control:IsShown()
retval: (boolean) - собственная видимость контрола; видимость родителей не проверяется

--// Проверить наведение с необязательной проверкой перекрытия.
control:IsCursorOverWindow(precise)
args:
  precise (boolean, optional) - true проверяет текущие координаты, вложенность, перекрытие, захват мыши и активный диалог; false или отсутствие аргумента возвращает наведение, рассчитанное при Update с учётом поворота
retval: (boolean) - true, если условие наведения выполнено; дочерний контрол считается частью родителя
```

### Порядок отображения

Доступны у `CUIWindow` и его наследников.
`ToFront` и `ToBack` меняют порядок отображения и приоритет мыши среди детей
одного родителя. Контрол перемещается вместе со своими дочерними элементами.
Вложенность, координаты и компоновка сохраняются.

```lua
--// Поднять контрол над соседями текущего родителя.
control:ToFront()
retval: (boolean) - true при допустимом общем родителе; false для корневого окна или отсутствия в списке детей

--// Опустить контрол под соседей текущего родителя.
control:ToBack()
retval: (boolean) - true при допустимом общем родителе; false для корневого окна или отсутствия в списке детей
```

### Порядок отображения дерева

Доступны у `CUIWindow` и его наследников.
`ToFrontTree` и `ToBackTree` перемещают контрол со всеми вложенными элементами,
затем содержащую его ветку среди соседей её родителя и так до корня дерева UI.
Это позволяет поднять или опустить вложенный контрол относительно других веток.
Родительские контейнеры перемещаются вместе с остальными своими детьми.
Порядок дочерних элементов внутри выбранного контрола сохраняется.
Вложенность, координаты и компоновка сохраняются; порядок отдельных диалогов
не меняется.

Методы не принимают аргументов. Повторный вызов сохраняет выбранный порядок
и возвращает `true`, если все связи с родителями корректны.
Для корневого окна без родителя возвращается `false`.

```lua
--// Поднять контрол с вложенными элементами и содержащие его ветки до корня.
control:ToFrontTree()
retval: (boolean) - true, если ветка перемещена; false для корневого окна или некорректной связи с родителем

--// Опустить контрол с вложенными элементами и содержащие его ветки до корня.
control:ToBackTree()
retval: (boolean) - true, если ветка перемещена; false для корневого окна или некорректной связи с родителем
```

### Локальный поворот статика

Методы доступны у `CUIStatic` и его наследников.

`SetHeading` поворачивает текстуру или заливку, не меняя текст и дочерние элементы.
Для поворота всей ветки используется `SetTreeHeading`.
Наведение и события мыши учитывают оба вида поворота.
Угол задаётся в радианах.

`point` задаёт точку вращения в единицах UI от левого верхнего угла текстуры:
X вправо, Y вниз. Для размера 200 × 100 центр — `(100, 50)`,
левый верхний угол — `(0, 0)`, правый нижний — `(200, 100)`.
`offset` дополнительно переносит текстуру и точку вращения в экранных осях.
Для обычного вращения передавайте `fixedLT = false`.

`ResetHeadingPivot` возвращает автоматический центр, но сохраняет угол и `offset`.
Явно заданная точка не пересчитывается при изменении размера.

```lua
--// Проверить, включён ли режим вращения текстуры.
control:Heading()
retval: (boolean) - true, если вращение включено

--// Задать угол; вращение отдельно включается EnableHeading(true).
control:SetHeading(angle)
args:
  angle (number) - угол в радианах; math.pi / 2 = 90 градусов; положительный угол против часовой стрелки, отрицательный по часовой
retval: (void)

--// Получить текущий угол текстуры, включая промежуточный при сглаживании.
control:GetHeading()
retval: (number) - текущий угол в радианах

--// Задать точку вращения и перенос текстуры; все аргументы обязательны.
control:SetHeadingPivot(point, offset, fixedLT)
args:
  point (vector2) - точка относительно левого верхнего угла отображаемой текстуры в единицах UI; x вправо, y вниз; не UV-координаты
  offset (vector2) - дополнительный перенос всей текстуры после вращения в единицах UI; x вправо, y вниз; сам вектор не вращается
  fixedLT (boolean) - false для обычного вращения; true меняет местами ширину и высоту растягиваемой текстуры при включённом вращении
retval: (void)

--// Вернуть автоматический центр и выключить fixedLT; угол и offset сохраняются.
control:ResetHeadingPivot()
retval: (void)

--// Задать флаг постоянного направления для кода маркеров карты.
control:SetConstHeading(enabled)
args:
  enabled (boolean) - true запрещает автоматический пересчёт направления маркером карты; false снимает флаг; не отключает анимации и SetHeading
retval: (void)

--// Получить флаг постоянного направления.
control:GetConstHeading()
retval: (boolean) - установлен ли флаг постоянного направления
```

### Каскадный поворот

`SetTreeHeading` поворачивает весь контрол с текстом и дочерними элементами.
Локальные позиции и углы сохраняются. Повороты вложенных веток складываются.
`EnableHeading` — общий переключатель локального и каскадного поворота:
отключение сохраняет параметры обоих способов.
Контуры, заданные через `SetBorder`, учитывают поворот ветки.

```lua
--// Задать целевой угол ветки, точку вращения и смещение одним вызовом.
control:SetTreeHeading(angle, pivot, offset)
args:
  angle (number) - угол в радианах; положительный против часовой стрелки
  pivot (vector2) - точка вращения от левого верхнего угла контрола в единицах UI
  offset (vector2) - дополнительное смещение всей ветки; x вправо, y вниз
retval: (void)

--// Включить или отключить оба способа поворота, сохранив настройки.
control:EnableHeading(enabled)
args:
  enabled (boolean) - true включает повороты; false отключает локальный и каскадный поворот этого контрола
retval: (void)
```

### Плавность поворота

`SetSmothRotate` настраивает оба способа поворота этого контрола.
По умолчанию `factor = 1.0`: угол меняется мгновенно.
Скорость перехода учитывает межкадровую дельту и не зависит от FPS.

При смене целевого угла переход продолжается от текущего угла.
Полные обороты сохраняются. Сглаживается только угол; точка вращения
и смещение меняются сразу. Переход выполняется при обычном обновлении UI.
`EnableHeading(false)` приостанавливает движение до включения поворота.

```lua
--// Задать общий режим сглаживания локального и каскадного поворота.
control:SetSmothRotate(enabled, factor)
args:
  enabled (boolean) - true включает сглаживание; false сразу устанавливает целевые углы
  factor (number) - резкость от 0 до 1; 0 удерживает текущий угол, 1 меняет его мгновенно; чем ближе к 1, тем быстрее переход
retval: (void)
```

### Примеры использований:

#### Включение и отключение коррекции

```lua
control:SetWndPos(vector2():set(200, 100))
control:SetWndSize(vector2():set(200, 200))
control:SetUseAspectRatioCorrection(true)

local position = control:GetWndPos() -- x = 200, y = 100.
local width = control:GetWidth()    -- 200.
local height = control:GetHeight()  -- 200.

control:SetWidth(300) -- Геттер вернёт 300; при отрисовке ширина корректируется.
control:SetUseAspectRatioCorrection(false)
```

#### Коррекция дочерних контролов

```lua
window:SetUseAspectRatioCorrection(true)

--// Дочерний контрол уже наследует коррекцию окна.
child:SetUseAspectRatioCorrection(true) -- Дополнительного сжатия не будет.
child:SetUseAspectRatioCorrection(false) -- Коррекция окна продолжает действовать.

window:SetUseAspectRatioCorrection(false) -- Оба собственных флага выключены.
```

#### Локальный поворот

```lua
control:EnableHeading(true)
control:SetHeading(math.rad(45))
```

#### Вращение вокруг угла

```lua
control:EnableHeading(true)
control:SetHeadingPivot(vector2():set(0, 0), vector2():set(0, 0), false)
control:SetHeading(math.pi / 4)
```

#### Видимость

```lua
control:Show(true)
local visible = control:IsShown()
```

#### Проверка наведения

```lua
local hovered = control:IsCursorOverWindow()
local precise_hovered = control:IsCursorOverWindow(true)
```

#### Порядок отображения среди соседей

```lua
control:ToFront() -- Поднять контрол с его детьми среди детей текущего родителя.
control:ToBack()  -- Опустить контрол с его детьми среди детей текущего родителя.
```

#### Порядок отображения вложенной ветки

В примере `parent` — дочерний контрол корневого окна, `child` — дочерний
контрол `parent`. У каждого из них могут быть свои соседи и вложенные элементы.

```lua
child:ToFrontTree() -- Поднять child внутри parent, затем parent внутри корневого окна.
child:ToBackTree()  -- Опустить child внутри parent, затем parent внутри корневого окна.
```

Дочерние элементы `child` перемещаются вместе с ним, сохраняя свой порядок.
Остальные дети `parent` также перемещаются вместе с `parent`.

#### Поворот ветки вокруг нижней середины

```lua
control:SetWndSize(vector2():set(200, 100))
control:SetTreeHeading(
    math.rad(45),
    vector2():set(100, 100),
    vector2():set(0, 0)
)
control:EnableHeading(true)
```

#### Локальный угол дочернего элемента

```lua
child:EnableHeading(true)
child:SetHeading(math.rad(15))
```

#### Отключение обоих поворотов

```lua
control:EnableHeading(false)
```

#### Плавный поворот ветки

```lua
control:EnableHeading(true)
control:SetSmothRotate(true, 0.1)
control:SetTreeHeading(
    math.rad(90),
    vector2():set(100, 100),
    vector2():set(0, 0)
)
```

#### Плавный локальный поворот

```lua
control:EnableHeading(true)
control:SetSmothRotate(true, 0.1)
control:SetHeading(math.rad(90))
```

#### Мгновенный поворот

```lua
control:SetSmothRotate(true, 1.0)
control:SetHeading(math.rad(45))
```
