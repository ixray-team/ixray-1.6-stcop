## Обзор

Редактор диалогов был реализован на системе нод.
<br>Для доступа к нему перейдите в папку `configs/gameplay/` в **Content Browser** и откройте файл с диалогом:

![image](https://github.com/user-attachments/assets/66aa365f-9441-4ec5-b158-f77a912c7d4a)

> Система читает `system.ltx` и получает оттуда список поддерживаемых файлов

В режиме без выделенной ноды окно `Properties` показывает глобальные свойства текущего диалога

![image](https://github.com/user-attachments/assets/9456fd2d-7d87-4f33-877a-6492f4cb9d51)
