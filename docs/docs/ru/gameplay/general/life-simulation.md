# Симуляция жизни

## Посиделки у костра

> [!IMPORTANT]
> **Статус**: Поддерживается <br>
> **Минимальная версия**: 1.3

### Обзор

Восстановлена схема поведения `xr_kamp` из оригинальных игр "Тень Чернобыля" (ТЧ) и "Чистое Небо" (ЧН), позволяющая NPC собираться у костра для отдыха и общения.

### Требования к настройке

Для работы системы необходимо создать два основных элемента на уровне:

#### 1. Way Point (путевая точка)
- **Имя**: Должно соответствовать шаблону `(SmartTerrainName)_kamp_(id)`
- **Назначение**: Определяет точку, куда NPC приходят для посиделок

#### 2. Camp Zone (зона костра)  
- **Тип**: Обычная camp_zone в редакторе уровней
- **Назначение**: Определяет область вокруг костра, где NPC взаимодействуют

### Пример настройки

Допустим, у вас есть смарт-террейн с именем `jup_a6`. Настройка будет выглядеть следующим образом:

```
Way Point: jup_a6_kamp_1
Camp Zone: [любое имя, но логично назвать jup_a6_camp_1]
```

### Особенности работы

- NPC автоматически находят подходящие точки для посиделок по шаблону имен
- Система интегрируется в общий цикл жизни NPC
- Не требует дополнительного скриптинга или конфигурации
