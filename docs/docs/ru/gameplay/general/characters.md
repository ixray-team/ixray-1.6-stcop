## Случайный ранг у НПС

Необходимо открыть профиль НПС и прописать минимальное и максимальное значение для тега `rank`

```xml
   <rank min="0" max="100" />
```

## Случайная репутация у НПС

Необходимо открыть профиль НПС и прописать минимальное и максимальное значение для тега `reputation`

```xml
   <reputation min="-100" max="100" />
```

## Случайный лут
Добавлена система случайного лута из CoC. Для этого требуется прописать `spawn_loadout` в профиле NPC.

**Пример:**
```ini
[spawn_loadout] \n
wpn_ak74 = 1 \n
wpn_spas12 = 1 \n

[spawn_loadout2] \n
wpn_pb = 1, silencer \n
wpn_pm = 1 \n
wpn_sig220 = 1 \n
```

## Улучшение схем поведенения 

- Улучшена схема поведения при бое в помещении: NPC больше не будут смотреть в пол или потолок, если враг находится на другом этаже
- Улучшена схема обнаружения NPC противников, исправлена проблема с преждевременным обнаружением врагов
- Добавлена схема обхода машин для NPC
- Добавлена возможность включить реакцию NPC на аномалии (`EnableAiDieInAnomaly`)
- Добавлена возможность включить слежение NPC за главным героем в определенном радиусе (`NPCLookAtActor`)
