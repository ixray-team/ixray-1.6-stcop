Система якорей и раскладки UI (Alpha-версия)

Руководство по системе позиционирования элементов интерфейса

РАЗДЕЛ 1. ОБЗОР И НАЗНАЧЕНИЕ

Система якорей позволяет позиционировать элементы UI относительно углов родительского контейнера с помощью нормализованных координат. Координаты задаются в диапазоне от 0 до 1, где (0,0) соответствует левому верхнему углу родителя, а (1,1) правому нижнему.

Основные преимущества:
- Один XML-файл (конкретно maingame.xml) работает для соотношений сторон (4:3, 16:9)
- Отсутствует необходимость в дублировании maingame_16.xml и подобных файлов
- Элементы автоматически пересчитывают позицию при изменении размера экрана
- Поддержка вырезов экрана, скруглённых углов и ультрашироких мониторов

Базовая сетка координат: 1024x768 пикселей. Все смещения и размеры задаются в этих единицах и масштабируются движком. Гибридность


РАЗДЕЛ 2. РЕЖИМЫ ПОЗИЦИОНИРОВАНИЯ

Legacy (устаревший режим):
Элементы без атрибутов anchor и anchor_min используют традиционные координаты x, y, width, height. Позиция жёстко привязана к пикселям в пространстве 1024x768. При смене разрешения такие элементы могут смещаться или обрезаться.

Anchored (режим якорей):
Элементы с атрибутами anchor или anchor_min используют новую систему. Позиция вычисляется относительно углов родителя. Один и тот же XML корректно отображается на 4:3, 16:9 и 21:9 без дополнительных файлов.


РАЗДЕЛ 3. ПРЕСЕТЫ ЯКОРЕЙ

Пресет задаётся атрибутом anchor. Доступные значения:

top-left        Верхний левый угол
top-center      Верхний центр
top-right       Верхний правый угол
center-left     Центр слева
center          Центр экрана
center-right    Центр справа
bottom-left     Нижний левый угол
bottom-center   Нижний центр
bottom-right    Нижний правый угол
stretch-h       Горизонтальное растяжение на всю ширину, вертикально по центру
stretch-v       Вертикальное растяжение на всю высоту, горизонтально по центру
stretch-full    Заполнение всего родителя

Для фиксированных точек (не stretch) элемент привязывается одной точкой. Для stretch элементы растягиваются между двумя якорями.

РАЗДЕЛ 4. АТРИБУТЫ XML

4.1. Фиксированная позиция

Элемент привязывается к одной точке экрана. Пример:

      <element anchor="top-right" offset_x="-44" offset_y="0" width="33" height="35"/>

Атрибуты:
- anchor: имя пресета (см. раздел 3)
- offset_x, offset_y: смещение от точки якоря (или компактный offset="x,y", см. 4.5)
- width, height: размер элемента в пикселях

4.2. Явные якоря

Для тонкой настройки используйте anchor_min и anchor_max вместо anchor:

    <element anchor_min="1,0" anchor_max="1,0" offset_x="-44" offset_y="350" width="33" height="35"/>

Формат координат: "x,y" где x и y от 0 до 1.
Одинаковые anchor_min и anchor_max дают фиксированную точку.
Разные значения создают растягивание по соответствующей оси.

4.3. Режимы растяжения

Для stretch-режимов используйте offset_left, offset_top, offset_right, offset_bottom как отступы от краёв:

    <element anchor="stretch-full" offset_left="10" offset_top="10" offset_right="10" offset_bottom="10"/>

4.4. Расчёт смещения при миграции

Переход с legacy на anchored: для элемента с x="980" у правого края (1024) offset_x вычисляется как 1024 - 980 = 44. Поскольку смещение влево от правого края отрицательное, offset_x = -44.

Было (legacy):
    <indicator_starvation x="980" y="350" width="33" height="35"/>

Стало (anchored):
    <indicator_starvation anchor="top-right" offset_x="-44" offset_y="350" width="33" height="35"/>

4.5. Компактный формат offset

Атрибут offset позволяет задавать смещения в формате Fvector2 или Thickness (как в XAML):

| Формат        | Значение |
|---------------|----------|
| offset="x,y"  | left=x, top=y, right=0, bottom=0 (для точки) |
| offset="L,T,R,B" | left=L, top=T, right=R, bottom=B (Thickness) |
| offset="V"    | все четыре стороны равны V |

Примеры:
    <element anchor="top-right" offset="-44,350" width="33" height="35"/>
    <element anchor="stretch-full" offset="10,10,10,10"/>
    <element anchor="stretch-full" offset="10"/>

При наличии offset атрибуты offset_x, offset_y, offset_left и т.д. игнорируются. При отсутствии offset используется прежняя схема.


РАЗДЕЛ 5. РАСКЛАДКИ КОНТЕЙНЕРОВ

Контейнеры могут автоматически размещать дочерние элементы с помощью атрибута layout.

5.1. Горизонтальный стек (stack_h)

Элементы выстраиваются в ряд слева направо:

    <panel anchor="bottom-left" offset_x="20" offset_y="108" layout="stack_h" spacing="11" width="367" height="41">
        <item width="31" height="41"/>
        <item width="31" height="41"/>
    </panel>

spacing задаёт расстояние между элементами в пикселях.

5.2. Вертикальный стек (stack_v)

Элементы выстраиваются столбиком сверху вниз:

    <panel layout="stack_v" spacing="8" padding_top="10" padding_left="5">
        <item width="100" height="20"/>
        <item width="100" height="20"/>
    </panel>

5.3. Атрибуты раскладки

layout          stack_h или stack_v
spacing         расстояние между потомками в пикселях
padding_left    отступ слева
padding_top     отступ сверху
padding_right   отступ справа
padding_bottom  отступ снизу
layout_reverse  порядок потомков в обратную сторону

5.4. Сетка (grid)

    <grid layout="grid" cols="5" cell_width="50" cell_height="50" 
          cell_spacing_x="2" cell_spacing_y="2" padding_left="10">
        <cell width="50" height="50"/>
        <cell width="50" height="50"/>
    </grid>

cols            число столбцов
rows            число строк (0 = авто по количеству потомков)
cell_width      ширина ячейки
cell_height     высота ячейки
cell_spacing_x  расстояние по горизонтали
cell_spacing_y  расстояние по вертикали


РАЗДЕЛ 6. РАЗМЕР ПО СОДЕРЖИМОМУ

Атрибуты width="auto" и height="auto" позволяют элементу подстраивать размер под содержимое:

    <label x="10" y="10" width="auto" height="auto"/>
    <list_panel layout="stack_v" width="200" height="auto"/>

width="auto"   ширина по содержимому (текст, иконка)
height="auto"  высота по содержимому
min_width      минимальная ширина при auto
min_height     минимальная высота при auto

Работает в обоих режимах (legacy и anchored). Контейнеры с layout вычисляют auto-размер до позиционирования потомков.


РАЗДЕЛ 7. РЕЖИМЫ МАСШТАБИРОВАНИЯ

Атрибут scale_mode влияет на масштабирование элемента:

    <icon scale_mode="widescreen" anchor="bottom-right" offset_x="-100" width="50" height="50"/>

Значения:
default    стандартное масштабирование (zx, zy)
widescreen применение коэффициента kx к горизонтали для коррекции соотношения сторон
none       без дополнительного масштабирования


РАЗДЕЛ 8. SAFE AREA (БЕЗОПАСНАЯ ЗОНА)

8.1. Назначение

Параметры safe_area_inset_* задают отступы от краёв экрана в пикселях (база 1024x768). Они нужны для экранов с вырезами (notch), скруглёнными углами, ультрашироким форматом - элементы UI, заякоренные к краям, смещаются внутрь на эти значения, чтобы не попадать в нечитаемые зоны.

8.2. Параметры (engine_external.ltx, секция [ui])

    safe_area_inset_left   = 0   ; Отступ от левого края
    safe_area_inset_top    = 0   ; Отступ от верхнего края
    safe_area_inset_right  = 0   ; Отступ от правого края
    safe_area_inset_bottom = 0   ; Отступ от нижнего края

Значения задаются в пикселях относительно разрешения 1024x768. Движок масштабирует их под текущее разрешение. 
p.s. Пусть пока что будет так

8.3. Применение

- Элементы с anchor (anchored mode), привязанные к корню экрана, позиционируются внутри прямоугольника, уменьшенного на эти отступы.
- Legacy-элементы (без anchor) не учитывают safe area и продолжают использовать полный экран.
- Типичные сценарии: вырез камеры (notch), скруглённые углы дисплея, overscan на ТВ, ультраширокие мониторы с зонами, где контент может обрезаться.

8.4. Отладка

В UI Debugger включите опцию "Show safe area" для визуализации границ безопасной зоны при разработке.


РАЗДЕЛ 9. ПРИВЯЗКА К СОСЕДНЕМУ ЭЛЕМЕНТУ

Атрибут anchor_to позволяет привязать элемент не к родителю, а к соседнему элементу (sibling) по его window_name:

    <parent>
        <reference_window anchor="top-right" offset_x="-100" width="50" height="50">
            <window_name>reference_window</window_name>
        </reference_window>
        <child anchor="top-right" anchor_to="reference_window" offset_x="-60" offset_y="0" width="50" height="50"/>
    </parent>

Соседний элемент должен иметь дочерний узел window_name с идентификатором. Элемент child будет позиционироваться относительно reference_window.
