# Компоненты документации

## Раскрывающиеся параметры — ParameterDetails

Компонент зарегистрирован в общей теме VitePress и доступен на любой странице `.md` без импорта. Названия, значения и описания задаются в Markdown страницы. Стандартные подписи автоматически берутся из настроек текущей локализации VitePress.

### Один параметр

```md
<ParameterDetails
  title="Громкость звука"
  parameter="sound_volume"
  normal="1.0"
>

Множитель громкости. В описании доступны **выделение**, `код`, ссылки и списки.

</ParameterDetails>
```

### Два режима

```md
<ParameterDetails
  title="Скорость движения"
  parameter="walk_speed"
  zoom-parameter="sprint_speed"
  normal="3.0"
  zoom="6.0"
  normal-label="Ходьба"
  zoom-label="Бег"
>

Скорость персонажа в каждом режиме.

</ParameterDetails>
```

Свойства `zoom` и `zoom-parameter` обозначают второе значение и второе имя параметра. Для отдачи оружия подпись второго значения по умолчанию — «Прицеливание»; для других систем её можно изменить через `zoom-label`.

### Формат значения

```md
<ParameterDetails
  title="Цвет текста"
  parameter="text_color"
  format="R, G, B, A"
  format-note="(четыре числа)"
>

Компоненты цвета и прозрачность.

</ParameterDetails>
```

### Настройки

- `title` — название в свёрнутом пункте.
- `parameter` — полное имя параметра внутри раскрытого пункта.
- `normal` — первое значение; необязательно.
- `zoom` — второе значение; необязательно.
- `zoom-parameter` — второе имя параметра; необязательно.
- `normal-label` — подпись первого значения. По умолчанию «По умолчанию», а при двух значениях — «Обычно».
- `zoom-label` — подпись второго значения. По умолчанию «Прицеливание».
- `format` — формат вместо значений по умолчанию.
- `format-label` — подпись формата. По умолчанию «Формат».
- `format-note` — дополнительная подсказка после формата; необязательно.
- `open` — открыть пункт при загрузке страницы; необязательно.

Содержимое между тегами — обычный Markdown. Оставляйте пустую строку после открывающего тега и перед закрывающим. Свойства `normal-label`, `zoom-label` и `format-label` переопределяют стандартные переводы для конкретного блока и задаются на языке страницы.

## Переводы стандартных подписей

Переводы находятся в `themeConfig.parameterDetails` файлов локализации:

- Русский: `docs/config/.vitepress/locales/ru.mts`.
- Английский: `docs/config/.vitepress/locales/en.mts`.

При добавлении языка добавьте в его `themeConfig` блок с четырьмя подписями:

```ts
parameterDetails: {
  defaultValue: 'Default',
  normalMode: 'Normal',
  zoomMode: 'Aiming',
  format: 'Format',
},
```

Компонент получает эти подписи через `useData().theme`, поэтому они меняются вместе с локализацией VitePress. Названия, пояснения и `format-note` остаются в соответствующих `.md` страницах.
