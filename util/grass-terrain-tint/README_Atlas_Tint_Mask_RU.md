# Маска tint атласа Detail

Необязательный файл рядом с атласом: `gamedata\levels\zaton\build_details_tint.dds` для `build_details.dds`.
Для другого атласа используется то же имя с суффиксом `_tint` перед `.dds`.
Поиск: папка текущей локации, затем gamedata\textures, как у текстуры атласа.

- Нет файла: прежний tint без ограничений.
- Непрозрачное (Alpha=255): полный эффект с учётом глобальных настроек.
- Полностью прозрачное (Alpha=0): исходный цвет.
- Полупрозрачное: частичная сила; Alpha=128 означает примерно 50%.
- Читается только альфа-канал маски. RGB игнорируется; прозрачность самой травы по-прежнему берётся из исходного атласа.

Делайте маску в той же раскладке UV и с теми же пропорциями, что и атлас; рекомендуется то же разрешение. Изначально сделайте маску непрозрачной. Стирайте участки, которые нужно защитить от tint; полупрозрачность задаёт промежуточную силу. Для цветка можно оставить листья непрозрачными, а лепестки сделать прозрачными. Если модели используют один участок UV, маска повлияет на обе.

Сохраняйте DDS как линейные данные (UNORM, без sRGB): несжатый RGBA8 или BC3/DXT5 с плавной альфой. BC1/DXT1 и BC4 не подходят для плавной альфа-маски. Для наиболее точных границ подходит несжатый RGBA8. Рекомендуется полная цепочка mip-уровней; оставляйте поля вокруг островков атласа, чтобы на расстоянии соседние области не смешивались. THM не требуется.

После добавления, замены или удаления маски полностью перезапустите игру: шейдерный вариант и текстура выбираются при загрузке. Команда r__grass_tint_rebuild перестраивает карту терейна, а не маску атласа.

Проверка: cfg_load grass_tint_strong. Для проверки цветов поверхности: cfg_load grass_tint_check — прозрачные области маски сохранят исходную текстуру. Диагностика debug 3/4 намеренно игнорирует маску, чтобы проверять шейдер и покрытие.
В логе при найденной маске будет строка Grass terrain tint: atlas mask с полным путём. Маска не создаётся автоматически: целиком непрозрачная лишь повторяет поведение без неё.

Обновление движка: распакуйте комплект в корень тестовой игры и запустите Build_Install_GrassTint_Mask.cmd. Он обновит чистый отдельный checkout v0.2, соберёт движок и выполнит тесты перед установкой. Существующий NuGet и результаты сборки сохранятся. Локацию перекомпилировать не нужно. Маска пользователя не перезаписывается установщиком.
