# Маска tint атласа Detail

Необязательный файл рядом с атласом: `gamedata\levels\zaton\build_details_tint.dds` для `build_details.dds`.
Для другого атласа используется то же имя с суффиксом `_tint` перед `.dds`.
Поиск: папка текущей локации, затем gamedata\textures, как у текстуры атласа.

- Нет файла: прежний tint без ограничений.
- Белое (R=255): полный эффект с учётом глобальных настроек.
- Чёрное (R=0): исходный цвет.
- Серое: частичная сила; R=128 означает примерно 50%.
- Читается красный канал. Альфа маски не используется; прозрачность травы берётся из исходного атласа.

Делайте маску в той же раскладке UV и с теми же пропорциями, что и атлас; рекомендуется то же разрешение. Изначально залейте белым и закрасьте чёрным участки моделей, которые нужно защитить. Для цветка можно оставить листья белыми, а лепестки сделать чёрными. Если модели используют один участок UV, маска повлияет на обе.

Сохраняйте DDS как линейные данные (UNORM, без sRGB): BC4 либо несжатый R8/RGBA8. Для наиболее точных границ подходит несжатый RGBA8. Рекомендуется полная цепочка mip-уровней; оставляйте поля вокруг островков атласа, чтобы на расстоянии соседние области не смешивались. THM не требуется.

После добавления, замены или удаления маски полностью перезапустите игру: шейдерный вариант и текстура выбираются при загрузке. Команда r__grass_tint_rebuild перестраивает карту терейна, а не маску атласа.

Проверка: cfg_load grass_tint_strong. Для проверки цветов поверхности: cfg_load grass_tint_check — чёрные области маски сохранят исходную текстуру. Диагностика debug 3/4 намеренно игнорирует маску, чтобы проверять шейдер и покрытие.
В логе при найденной маске будет строка Grass terrain tint: atlas mask с полным путём. Маска не создаётся автоматически: целиком белая лишь повторяет поведение без неё.

Обновление движка: распакуйте комплект в корень тестовой игры и запустите Build_Install_GrassTint_Mask.cmd. Он обновит чистый отдельный checkout v0.2, соберёт движок и выполнит тесты перед установкой. Существующий NuGet и результаты сборки сохранятся. Локацию перекомпилировать не нужно. Маска пользователя не перезаписывается установщиком.
