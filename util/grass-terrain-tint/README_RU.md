# Grass Terrain Tint 0.2 — цвет травы от грунта

Одна и та же detail-трава получает сухой жёлтый оттенок над песком и зелёный над зелёным грунтом. Новый режим переносит основной цвет земли, сохраняя яркостный рисунок травинок и прозрачность исходного атласа. Освещение, ветер и форма модели продолжают работать обычным способом.

Для R4 / Direct3D 11. Перекомпилировать локацию и менять `level.details` не требуется. Поддерживается стандартный четырёхслойный материал террейна BmmD. База движка: `a2a67539f4a437c52a4ef918f1934166647971c1`.

## Установить готовое обновление

1. Закрой игру.
2. Распакуй **весь** `COP_Detail_terrain_tint_Update_v0.2.zip` в `D:\ixray\game\COP_Detail_terrain_tint\`.
3. Запусти `Install_GrassTint_Update.cmd`. Установщик сам выбирает `bin` или `bin\Release`, проверяет SHA256 всех файлов и сохраняет предыдущие файлы в `_grass_tint_backup_v0.2_<дата>`. Старые параметры подкрашивания заменяются новыми; настройки видео и остальные игровые параметры сохраняются.
4. Запусти `Run_GrassTint.cmd`, загрузи сохранение или локацию.

Обновление содержит новый `xrRender_R4.dll`, соответствующие шейдеры, запускатель и пресеты. Требуется уже установленная тестовая игра с остальными бинарниками и gamedata из этой ветки. Архив не содержит оригинальные данные игры.

## Готовые настройки

В консоли загруженной локации:

| Команда | Результат |
| --- | --- |
| `cfg_load grass_tint_default` | Новый основной режим: сильная передача цвета, умеренное влияние яркости |
| `cfg_load grass_tint_strong` | Максимальная передача цвета на всю высоту травы, повышенные яркость и насыщенность |
| `cfg_load grass_tint_soft` | Прежний мягкий способ подкрашивания |
| `cfg_load grass_tint_check` | Диагностика: цвет земли напрямую на траве |
| `r__grass_tint 0` / `r__grass_tint 1` | Сравнение выключенного и включённого эффекта |
| `r__grass_tint_info` | Фактический размер карты, размер исходного террейна, метры на пиксель и параметры |

Пресеты находятся в `_appdata_grass_tint_`, где `cfg_load` их находит. Обычные `default` / `strong` сохраняют рисунок травинок. `check` служит для проверки захвата и не является игровым режимом.

## Регулировка

| Команда | По умолчанию | Назначение |
| --- | --- | --- |
| `r__grass_tint 0/1` | `1` | Включение. Также принимаются `off/on` |
| `r__grass_tint_mode 0/1` | `1` | `1` — перенос цвета грунта; `0` — прежнее мягкое умножение оттенка |
| `r__grass_tint_strength 0..1` | `0.9` | Доля нового цвета. При `1` и `tips 1` исходный зелёный/бурый тон полностью заменяется тоном грунта |
| `r__grass_tint_brightness 0..1` | `0.35` | Влияние светлоты грунта. `0` сохраняет яркость травы; `1` полностью применяет ограниченный множитель яркости поверхности |
| `r__grass_tint_saturation 0..2` | `1.1` | Насыщенность нового тона: `0` — серый, `1` — как у грунта, выше — насыщеннее |
| `r__grass_tint_contrast 0.25..2` | `1` | Контраст сохранённого рисунка травинок в режиме переноса. При `1` исходные перепады яркости сохраняются |
| `r__grass_tint_tips 0..1` | `0.9` | Относительное влияние на верхушки: `0` оставляет их исходными, `1` окрашивает так же сильно, как основание |
| `r__grass_tint_green_only 0/1` | `0` | По желанию ограничивает эффект зелёными пикселями. Для перекраски сухой травы в зелёную оставь `0` |
| `r__grass_tint_radius 0..32` | `0.25` | Примерный размер усреднения цвета в метрах. `0` сохраняет максимальную детализацию карты |
| `r__grass_tint_resolution 0..8192` | `0` | `0` — автоматически по исходным DDS террейна; положительное значение — ручной размер, округлённый вверх до степени двойки, минимум 256 |
| `r__grass_tint_resolution_scale 1..4` | `1` | Дополнительное увеличение выбранного размера карты; итог ограничен 8192 |
| `r__grass_tint_height 0.1..10` | `1.5` | Допустимое расхождение высоты корня и поверхности, в метрах |
| `r__grass_tint_rebuild` | — | Пересоздать карту вручную |
| `r__grass_tint_debug 0..4` | `0` | Обычный вид / цвет грунта на траве / карта целиком / розовая трава / проверка покрытия |

Цвет, яркость, насыщенность, контраст, верхушки и сглаживание меняются сразу. Размер и множитель разрешения автоматически пересоздают карту при следующем отрисованном кадре. Для сохранения индивидуальных настроек используй `cfg_save grass_tint_my`; загрузка — `cfg_load grass_tint_my`.

Пример сильного эффекта с увеличенной картой:

```text
cfg_load grass_tint_strong
r__grass_tint_resolution 0
r__grass_tint_resolution_scale 2
r__grass_tint_info
```

После смены размера закрой консоль на один кадр, затем вызови `r__grass_tint_info`, чтобы увидеть уже построенную карту.

## Точность карты

Движок при загрузке локации отрисовывает сверху базовый цвет террейна вместе с четырьмя материалами, смешанными маской, без освещения и теней. Трава считывает цвет у своего основания. Карта общая для террейна локации; исходные UV материалов учитываются при её построении.

Режим `resolution 0` читает **оригинальный заголовок DDS** базовых текстур и масок использованного террейна, до снижения качества текстур в видеонастройках. Из них выбирается наибольшее измерение. При отсутствии доступного DDS используется размер загруженной текстуры, затем резерв 2048. Таким образом, террейн/маска 2048 даёт карту 2048, 4096 — карту 4096. `resolution_scale 2` увеличивает её вдвое, до максимума 8192.

Это совпадение по числу пикселей, а не гарантия взаимно однозначного соответствия пикселей для любой UV-развёртки. Несколько отдельных текстур, плотный UV-тайлинг и крутые склоны могут требовать большей карты. Повторяющиеся detail-материалы земли участвуют в цвете, но каждая мелкая деталь повторяющегося материала не обязана занимать отдельный пиксель глобальной карты. Для границ песка и травы основную роль играют базовый цвет, маска, размер карты и радиус усреднения.

Видеопамять карты цвета с mip-уровнями и высоты: примерно 37 МиБ при 2048, 149 МиБ при 4096 и 597 МиБ при 8192. При построении дополнительно нужна временная карта глубины: 16 / 64 / 256 МиБ соответственно. Цвет хранится в sRGB RGBA8 с фильтрацией в линейном пространстве; высота — R32F. Одинаковое преобразование цвета применяется в legacy/PBR lighting. Карта хранится в памяти и строится заново при смене локации или сбросе устройства.

## Проверка в игре

Сравни одну и ту же модель над песком и зелёным грунтом, включение/отключение на одном месте, границы цветовых пятен, ветер, склоны и переход между локациями. Подкрашивание не меняет форму травинок, их alpha-прозрачность, геометрию или ID моделей.

`debug 3` окрашивает detail-объекты в розовый независимо от террейна. В `debug 4` зелёный — корректная выборка, жёлтый — превышение разницы высот, красный — нет захваченного террейна, синий — корень вне карты, серый — выключено/карта ещё не готова. Для игры верни `debug 0`.

Эффект относится к detail-объектам. При `green_only 0` он также влияет на цветные элементы общих detail-атласов. Карта хранит верхнюю поверхность в каждой точке XZ, поэтому многоэтажный террейн требует проверки высоты. Пользовательские материалы террейна, R1 и R2 не охвачены.

## Сборка и автоматические проверки

Если Actions отключены, распакуй комплект `Build_Install_GrassTint_v02.cmd/.ps1` в корень игры и запусти CMD. Он скачает закреплённые исходники `4d005d67968089e4c8148cf953c39d893ca59baf` в `D:\ixray\IXRay-GrassTint-v02-src`, выполнит сборку и проверки, затем установит согласованный комплект бинарников и шейдеров с резервной копией прежних файлов. Нужны Git for Windows и Visual Studio 2022 с C++; CMake найдётся в установке Visual Studio. Исходники других проектов не изменяются.

Из этой ветки: `Build_GrassTint.cmd -GameRoot "D:\ixray\game\COP_Detail_terrain_tint"`. Нужны Visual Studio 2022 с C++, Windows SDK и CMake 3.26+. Для отдельной тестовой папки доступны `Prepare_GrassTint.ps1` / `Run_Precompiled.cmd`; готовый Actions-артефакт содержит бинарники, все шейдеры и util.

Workflow компилирует 15 реальных вариантов HLSL через FXC, выполняет реальные шейдеры захвата и окраски на D3D11 WARP, затем собирает движок MSVC x64. GPU-тесты проверяют смену зелёной травы на жёлтую над песком и сухой на зелёную над зелёным грунтом, сохранение рисунка, яркость, насыщенность, контраст, верхушки, диагностику и старую ошибку viewport. Проверяются выбор разрешения, PowerShell 5.1, обе структуры bin, целостность установки, резервные копии и перенос настроек.

Статус конкретной сборки смотри в GitHub Actions этой ветки. Автоматические тесты не заменяют проверку целой игровой сцены на твоей видеокарте; замеры FPS и фактического времени GPU в этот комплект не входят.
