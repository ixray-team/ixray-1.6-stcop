# Подкрашивание травы от террейна — тестовая версия 0.1

В R4/D3D11 движок один раз при первом отрисованном кадре загруженной локации строит карту базового цвета террейна. Трава получает мягкий оттенок поверхности под своим корнем. При переходе на другую локацию карта строится заново. Компиляция самой локации и правки `level.details` не нужны.

База: `ixray-team/ixray-1.6-stcop`, коммит `a2a67539f4a437c52a4ef918f1934166647971c1`. Поддерживается стандартный четырёхслойный материал террейна `BmmD`. Пользовательские материалы и варианты R1/R2 этой версией не охвачены.

## Скомпилировать и проверить

Нужны Git, Visual Studio 2022 с C++ и Windows SDK, CMake 3.26 или новее, доступ в интернет для зависимостей. Скрипт найдёт и CMake, поставляемый вместе с Visual Studio.

Если игра расположена в `D:\ixray\sdk`, запусти `Build_GrassTint.cmd`. Скрипт подготовит отдельные исходники, соберёт Release x64 с R4, выполнит проверки и подготовит запуск:

```text
D:\ixray\IXRay-GrassTint-Test\Run_GrassTint.cmd
```

Для другой папки игры:

```bat
Build_GrassTint.cmd -GameRoot "D:\Games\My IXRay"
```

`GameRoot` — папка с `fsgame.ltx` или `fs.ltx` и данными запускаемой игры. SDK, содержащий только редактор и исходную сцену, для игрового теста не подходит. При необходимости укажи `-FilesystemConfig "D:\Games\My IXRay\fs.ltx"`.

Из исходников ветки сборку запускают той же командой из `util\grass-terrain-tint`. Скрипт автоматически использует эту копию репозитория. Из автономного пакета он скачивает закреплённую базу и применяет комплектный патч с проверкой контрольных сумм. Существующую несовпадающую копию исходников скрипт отклонит. Другие пути задаются параметрами `-SourceRoot`, `-TestRoot`; только сборка — `-BuildOnly`.

## Если уже скачана готовая сборка из Actions

Распакуй весь артефакт с сохранением папок и запусти `util\grass-terrain-tint\Run_Precompiled.cmd`. Для другой игры передай `-GameRoot`, как в примере выше. Этот вариант не требует компилятора.

## Как устроен тестовый запуск

Бинарники, полный комплект шейдеров и пользовательские настройки помещаются в отдельный `TestRoot`. Исходный `user.ltx` копируется при первом запуске, после чего тестовые настройки сохраняются независимо. Сохранения не копируются: для первого теста начни новую игру или самостоятельно скопируй нужное сохранение в тестовый `userdata`.

В корне игры создаётся **один новый** файл `fs_grass_tint_<метка>.ltx`. Это нужно, потому что IX-Ray определяет корень игровых данных по расположению файла файловой системы. Исходный `fsgame.ltx`/`fs.ltx` сохраняется. Исходные бинарники, шейдеры и файлы локации остаются прежними. Удаление тестового каталога и созданного файла `fs_grass_tint_*.ltx` полностью убирает этот способ запуска.

## Быстрая проверка в игре

1. Запусти `Run_GrassTint.cmd`, загрузи локацию с террейном и detail-травой.
2. В консоли введи `r__grass_tint_debug 2`. Должна появиться карта цвета земли без освещения, построек и травы. Шахматный фон означает отсутствие захваченного террейна. Верни `r__grass_tint_debug 0`.
3. Сравни `r__grass_tint off` и `r__grass_tint on`. Для хорошо заметного сравнения временно поставь `r__grass_tint_strength 0.6`; рабочее начальное значение — `0.2`.
4. Проверь границы зелёной земли, песка/бурой почвы, движение камеры, ветер, смену локации. Оттенок должен оставаться привязан к корню растения.

| Команда | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `r__grass_tint on/off` | `on` | Мгновенное включение/отключение |
| `r__grass_tint_strength 0..1` | `0.2` | Сила оттенка |
| `r__grass_tint_radius 0..32` | `2` | Примерный размер сглаживания в метрах |
| `r__grass_tint_height 0.1..10` | `1.5` | Допустимая разница высоты корня и земли |
| `r__grass_tint_resolution 256..2048` | `1024` | Размер карты, округляется вверх до степени двойки |
| `r__grass_tint_green_only on/off` | `on` | Ограничить окраску преимущественно зелёными пикселями |
| `r__grass_tint_debug 0/1/2` | `0` | Обычный вид / цвет земли на траве / карта целиком |
| `r__grass_tint_rebuild` | — | Принудительно пересоздать карту |

В логе успешный захват начинается с `Grass terrain tint: 1024x1024`, затем указаны число поверхностей, границы и время отправки GPU-команд. Это время не является замером полной работы GPU. Если подходящего террейна нет, появится `no supported terrain surfaces`; трава сохранит исходные цвета.

## Ограничения первого варианта

Захват использует базовую текстуру и четыре слоя террейна, без освещения, теней, мокроты и параллакса. Сохраняет исходную яркость травы и добавляет оттенок; эффект специально слабый. Опция `green_only` использует цветовую эвристику, поэтому не гарантирует защиту каждого цветка или предмета в общем атласе.

Карта хранит верхнюю поверхность в каждой точке XZ. Для многоэтажной геометрии она не заменяет отдельные карты по высоте; проверка высоты отключает ошибочный оттенок под другой поверхностью. На очень больших локациях разрешение и допустимую разницу высот стоит проверить на склонах. Карта 1024 занимает примерно 15 МиБ постоянной видеопамяти, ещё около 4 МиБ временно нужно для глубины при построении. Карта не записывается на диск и пересоздаётся после сброса устройства.

## Проверки

Автоматические проверки включают граничные случаи размера/сглаживания карты, компиляцию 15 реальных вариантов игровых шейдеров, проверку слотов VS `t1/t2` и неизменного размера instance-данных травы 48 байт, подготовку тестовой папки и сохранность исходных файлов. Локально шейдеры проверяются через glslang; workflow Windows дополнительно использует настоящий FXC из Windows SDK и компилирует движок MSVC. Итоговый статус Windows смотри в Actions для этой ветки.

Визуальная проверка на твоих игровых данных остаётся необходимой. Это тестовая реализация; измерения FPS, фактического времени GPU и скриншоты из игры в этом комплекте отсутствуют.
